데스트레자는 발사/명중 시각과 5개 중 어느 레이피어가 어떤 대상을 관통하는지 입력할 수 있다. 강제 충격·베기, 이후 타격의 컨오, 명중 순간 준비 동작과 콤보, 직접 처치의 변신 보너스를 연결했다. 기본 상태 확률은 위키에 없으므로 기본 화면은 무작위 상태를 제외한 부분 계산으로 명시한다. 상확을 직접 지정하면 확인값과 구분한 조건부 결과다.

최신 범위·검증·원문 제한 목록은 [검증 기록](docs/VALIDATION.md), 작업 세부 사항은 [구현 상태](docs/IMPLEMENTATION_STATUS.md)를 기준으로 한다. 아래 버전별 기록은 과거 상태이며 현재 지원 범위와 구분한다.

## v0.6.0 수식과 근접 규칙

수식은 Windows의 Cambria Math로 렌더링하고 한글 이름·단위 설명은 Wanted Sans로 유지한다. 모드·아케인·스탠스·진화·방어력 조건에 호버하거나 키보드로 포커스를 주면, 해당 입력을 제외해 재계산한 값과 비교하여 실제로 달라지는 항만 강조한다. 강조는 160ms 진입/190ms 복귀, 20→24 DIP의 실제 글자 크기와 금색으로 표현한다. 확대에 필요한 폭을 먼저 확보하므로 호버 중 레이아웃이 움직이지 않는다. 경량 모드와 Windows 애니메이션 해제에서는 즉시 전환한다. Cambria Math 파일은 재배포하지 않고 설치된 Windows 글꼴을 사용한다.

수식의 단계는 기본 피해 → 가산 피해·CO → 동작·별도 배수 → 팩션 → 원소·물리 → 치명 기대값 → 대상 방어층 → 시간이다. 각 단계의 값은 엔진에서 계산한다. 여러 타격으로 구성된 스탠스는 타격별 결과를 합산한 단계 사이의 비율을 표시하며, 모든 타격에 같은 개별 배수가 적용된다고 가정하지 않는다. 방어력 항의 상세에는 `DR = 0.9 × √(A / 2700)`과 방깎·팩션·실드·오버가드 적용 조건이 표시된다.

- 고정 원본 506건의 URL·개정·시각·SHA-256과 원문을 보존한다. 250개 근접 프로필은 자료이며 실제 선택 가능한 일반 근접은 228개다.
- 152개 모드 규칙을 분류했다. PvP 및 실제 옵션·극성·수용량 입력이 연결되지 않은 리벤은 계산을 거부한다. 조건부/보조 효과와 미구현 전투 이벤트를 구분해서 표시한다.
- 기본 피해·CO·강공격·슬램·텐노카이·팩션·상태 피해의 브라켓, 일부 투사체의 별도 CO 적용, 인카논 진화와 조건, 리치 추가 원소, 기존 상태 중첩을 처리한다.
- 14개 적 팩션 프로필과 중립을 제공한다. 고정된 기존 상태에서 부식/화염 방깎·바이러스·자성, 실드·오버가드·독성 우회를 적용한다. 적 레벨별 스탯 생성이나 보스별 감쇠 모델은 포함하지 않는다.
- 상태 피해는 1중첩당 피해·유효 틱·지속 시간·공격당 기대 중첩을 별도 표시한다. 전파/범위 효과는 단일 대상 직접 DPS에 합치지 않는다.
- 저장 스키마 5는 근접 규칙 버전과 공격·조건·진화·추가 원소·엑실러스를 보존한다. 이전 저장 파일을 새 규칙으로 변환한 경우 사용자에게 재계산 사실을 표시한다.

**남은 범위:** 동적 상태 피해 TTK, 타격 중 상태/CO/콤보 변화, 조우 조립·엑소디아 실제 조합, 엑절티드/의사 엑절티드, 일부 무기 고유 전투 이벤트, 리벤 실제 모딩 입력. 하모니의 상태 소모·탈리스 가시·스피너렉스 처치 폭발 등은 해당 무기의 수식 하단과 자료실에 미반영 표시한다. 자료를 읽어 왔거나 유한한 값이 계산된다는 이유만으로 정확도 검증 완료로 간주하지 않는다. 에너지 채널의 반복 충전·피해 유형이 확정되지 않은 경우 반복 TTK를 제공하지 않는다.

현재 검증 기록과 화면은 배포 폴더의 검증 보고서를 참조한다. 구버전 회귀 경로와 확장 근접 경로의 성능 측정을 구분한다. WPF 비표시 렌더링·100/125/150% 배율 검사 및 자동 계산 검증은 실제 게임 병행 부하나 실제 모니터의 가독성 검증을 대신하지 않는다.

## 이전 UI 변경 기록

v0.5.4는 도넛의 한글 라벨을 11→14 DIP로 키우고, 범례 14 DIP·그래프 눈금 13 DIP를 적용한다. 실제 글자 폭으로 가운데를 정렬하고 원과 눈금 영역을 조정한다. Wanted Sans와 맑은 고딕을 같은 배경·렌더링·배율로 비교한 후 Wanted Sans를 유지했다. 상세 기록은 `docs/UI_TYPOGRAPHY_054.md`에 있다.

v0.5.3은 정렬 방향 아이콘, 모드 등급별 배경, 커서를 따라가는 툴팁과 글자 렌더링을 수정한다. 정렬 상태·벡터 아이콘·설명을 한 경로에서 갱신한다. 위키 내부 ID의 등급/분류를 기준으로 구리·은·금·백금·리벤 등의 정적인 카드 마감을 적용한다. 툴팁은 모니터 가장자리에서 반전하고 드래그·스크롤·화면 전환 시 닫힌다. 상세 기록은 `docs/UI_INTERACTION_053.md`에 있다.

v0.5.2는 상단 **모드 · 리벤 · 자료 · 개발** 탭과 검정·금색 대시보드를 적용한다. 큰 둥근 패널을 제거하고 제목과 얇은 구분선으로 작업 영역을 나눈다. 입력·드래그 카드·버튼에만 작은 모서리와 경계를 남겼다. 주요 수치는 넓은 창에서 한 줄, 작은 창에서 2×2로 배치한다. 설정은 상단 버튼에서 연다.

기본 1520×1000에서는 보관함 20개/5줄, 1920×1080에서는 30개/6줄, 최소 1240×730에서는 6개/2줄이 온전히 보인다. 무기·스탠스·수용량 설정은 98 DIP이며 장착 슬롯과 보관함 내부 스크롤을 유지한다. 자세한 변경·검사는 `docs/UI_LAYOUT_052.md`에 기록한다.

**UX 제1원칙은 ‘상세한 정보를 제공하되 사용법 설명 없이 쉽게 쓰게 한다’이다.** 익숙한 UI 언어로 조작·흐름·피드백을 구성한다. 자세한 기준은 `docs/UX_PRINCIPLES.md`에 기록한다.

## v0.5 당시 자료와 계산 범위 (이력)

| 구분 | 자료실 등록 | 계산 연결 |
|---|---:|---|
| 무기 | 62개 클래스, 911개 항목 | 일반 근접 228개의 기본 직접 피해 |
| 스탠스 | 134개 표, 상속 포함 1,248개 동작 | 시간·직접 타격 규칙을 처리하는 232개 동작 정의. 실제 일반 근접 호환 조합에서는 1,990건 계산, 5,902건 명시적 거부 |
| 아케인 | 166개 | 10개의 피해·공속·치명타·초기 콤보 규칙, 4개의 일반 타격 비적용 규칙 |
| 모드 | 1,550개 | 일반 근접 보관함 122개, 그중 34개의 일반 직접 피해 관련 수치 처리 |

911개는 변형·모듈 부품·레일잭·동반자 등을 포함한 위키 데이터 행 수다. 911개의 완성 무기를 모두 계산한다는 뜻이 아니다. 134개 스탠스 표에는 무기군 공통 동작·PvP·어빌리티 전용 자료도 포함되며 실제 스탠스 모드 항목은 84개다. 전체 숫자는 고정한 위키 모듈 스냅샷 기준이다.

정지, 전진, 방어+정지, 방어+전진을 무기와 스탠스에 맞게 선택한다. 강공격·슬라이드·공중·벽타기·마무리·슬램 등의 자료도 함께 보여주지만 시간 누락·슬램·투사체·미구현 규칙이 있으면 계산을 거부한다. 일반 검에 엑절티드 스탠스를 장착할 수 없다.

아케인은 근접 1칸과 워프레임 2칸, 랭크, 발동 여부와 조건을 저장한다. Fury·Strike·Avenger·Blade Charger·Exposure·Retaliation·Doughty·Duplicate·Careen·Crescendo를 고정 조건으로 처리한다. Fortification·Vortex는 단일 대상 직접 피해에 보너스를 주지 않으며, Animosity·Assimilation은 강공격 전용이므로 현재 일반 타격에 보너스를 주지 않는다고 표시한다. 나머지 효과는 자료만 등록했으며 선택하면 계산을 차단한다. 발동까지의 시간과 유지율은 자동 추정하지 않는다.

## 사용법

- **모드**: 무기군 → 무기 → 스탠스 → 동작을 선택하고 모드를 4×2 슬롯에 드래그한다. 슬롯 사이 드래그는 랭크를 보존한 교환이다. 보관함으로 반환하거나 우클릭/Delete로 해제한다.
- **수용량 / 포르마 설정**: 수용량 버튼으로 상세 설정을 연다. 무기 랭크, MR, 카탈리스트, 스탠스 장착과 극성을 편집한다. 40랭크 무기는 해당 한도를 사용한다. `8칸 비우기`는 슬롯 극성과 스탠스를 보존한다. 초과 빌드는 장착 불가를 표시하면서 계획용 수치를 계산한다.
- **모드 보관함**: 이름·코스트·극성만 표시하고 호버/키보드 포커스로 상세 설명을 확인한다. 이름/코스트/극성 양방향 정렬, 한국어·영문 검색, 효과 필터를 제공한다. 계산하지 못하는 모드는 해당 이유를 표시한다.
- **아케인·발동 조건**: 가운데 상황 설정 패널에서 펼친다. 익스포저 중첩, 실드/오버실드, 마무리 처치 횟수와 대상 동결을 입력한다.
- **자료**: 모든 자료를 한국어·영문·분류로 검색하고 수치·랭크별 설명·위키 출처를 확인한다. 지원 무기는 모드 탭으로 바로 보낸다.
- **저장/불러오기**: 새 빌드는 스키마 5에 아케인·수용량·슬롯 극성·스탠스·동작을 저장한다. 식별 가능한 v0.4 데이터 빌드는 슬롯을 보존해 새 위키 값으로 재계산하고 변환 사실을 표시한다. 알 수 없는 버전은 거부한다.
- **리벤**: 접합 후보와 사용자가 입력한 기준 범위 내 위치를 확인한다. 무기별 자동 상·하옵 판정이나 접합 결과 수치 시뮬레이션은 아직 구현되지 않았다.

직접 피해 구성 도넛, 방어력-DPS 선·면 그래프, 타격 순서별 피해 막대그래프와 치명타 단계별 확률 막대를 제공한다. 그래프와 툴팁은 실제 계산값을 사용한다. 피해 속성과 치명타 단계에는 기존 의미 색상을 유지한다. TTK는 직접 피해만 대상으로 하며 스탠스의 개별 타격 시각이 없으므로 처치 타격이 속한 콤보 시작~종료 범위로 표시한다. 미처치 표본을 분위수에서 제외하지 않는다.

## v0.5 정확도와 제한 (이전 기록)

WF Wiki를 스탠스와 계산 규칙의 정답 기준으로 삼는다. 사용자 게임 실측을 개발 선행 조건으로 요구하지 않는다. 228개 무기 기본 수치와 1,248개 동작 배열을 고정 원문에 전수 대조한다. 공식 ko Public Export는 내부 ID로 연결하며 번역이 없는 무기 56개·아케인 5개·모드 53개는 임의 번역하지 않고 원문 이름을 표시한다.

상태 피해·강제 상태 효과·바이러스 증폭·동적 CO/콤보, 적 실드·오버가드·보스 감쇠, 강공격·슬램·특수 투사체, 리벤 장착, 인카논 진화·무기 고유 발동, 쿠바/테넷/코다 추가 원소, 조우 조립은 미지원이다. 현재 무기는 기본 수치만 사용하며 모든 효과를 포함한 실전 DPS로 해석하면 안 된다. 사거리·콤보 지속 시간 등은 명중률 100%의 고정 일반 타격 모델에 피해 보너스로 더하지 않는다.

Wanted Sans를 유지하고 96 DPI의 작은 글자는 Display, 고배율은 Ideal 메트릭으로 배치한다. Grayscale과 픽셀 정렬을 적용하며 정렬·검색·필터는 14 DIP를 사용한다. 배포 EXE에 PerMonitorV2 DPI 매니페스트를 추가했다. PNG 150% 렌더링 검사는 실제 다른 모니터 사이 창 이동 검증을 대신하지 않는다.

## 구조와 자료 재현

- `src/TennoForge.Core`: 기본 피해·스탠스·아케인·TTK·수용량·빌드 변환·리벤 후보.
- `src/TennoForge.Desktop`: WPF 편집·차트·자료실·저장·폰트·윈도 프레임.

- `tests/TennoForge.Checks`: 손계산·경계값·전수 원문 대조·호환 조합 검사.
- `tools`: 고정 자료 다운로드와 AST 기반 정규화. 원격 Lua 코드는 실행하지 않는다.

```powershell
python -m pip install -r tools/requirements-data.txt
python tools/download_reference_sources.py --cache artifacts/wiki-cache
python tools/import_full_catalog.py --cache artifacts/wiki-cache
```

자료 라이선스·저작자 표기는 `data/WF-WIKI-NOTICE.txt`, `data/PUBLIC-EXPORT-NOTICE.txt`, 기존 WFCD 라이선스와 폰트 OFL을 보존한다. 자세한 범위는 `docs/DATA_COVERAGE.md`, 검사 방식은 `docs/VALIDATION.md`, 제품 계획은 `docs/DEVELOPMENT_SPEC.md`에 기록한다.
