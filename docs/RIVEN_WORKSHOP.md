# 리벤 작업대

이번 범위는 기존 계산 엔진에 연결된 일반·조우·인카논 근접무기 리벤이다. 보조/주무기 리벤 및 게임 화면 자동 인식은 포함하지 않는다.

## 수치와 접합

- 무기 변형별 기질, 랭크, 양옵/음옵 구성에 따른 최소·최대 표시 수치와 범위 내 위치를 표시한다. 음옵은 수치 크기가 작을수록 불이익이 작다고 별도로 안내한다.
- 범위 내 위치는 실제 확률 백분위가 아니다. 표시 소수점 반올림의 불확실성을 유지한다.
- 공식 44.1.0의 14종 근접 접합 조합을 제공한다. 두 원래 롤 중 큰 롤을 계승하는 구간을 계산하며, 음옵의 유리함을 나타내는 방향과 원래 롤의 크기를 혼동하지 않는다.
- 미소비 옵션 순서를 유지하고 접합/대체 옵션을 해당 위치에 놓는다. 실제 장착 계산에서는 기존 엔진의 리벤 원소 결합 순서와 별도 브라켓을 사용한다.

## 순환과 작업 기록

현재 순환 횟수와 예산 횟수로 쿠바 비용을 계산한다. 순환 비용은 900, 1,000, 1,200, 1,400, 1,700, 2,000, 2,350, 2,750, 3,150, 이후 3,500이다. 첫 10회 합계는 19,950이다. 일반 옵션 하나를 고정하면 비용이 2배다. 접합 옵션 보존 자체는 무료이며 일반 고정과 공존한다.

새 예시를 생성하면 비용과 횟수가 즉시 증가한다. 현재 옵션을 유지해도 소비 기록은 되돌리지 않는다. 결과를 결정하기 전에는 옵션·고정·구성 편집을 잠근다. 접합 보존을 해제하고 새 순환 결과를 채택하면 접합을 제거한다.

`.wfriven` 파일에 현재 옵션, 미채택 결과, 순환 횟수, 소비 쿠바와 접합기 수를 저장한다. 일반 옵션 고정은 게임 메뉴 세션에 종속되므로 파일을 다시 불러올 때 해제한다. 입력 값·규칙 버전·고정 옵션·구성의 일관성을 검증한다.

## 비교

기준 리벤을 지정한 뒤 후보를 입력하거나 접합/순환 예시를 채택한다. 모드 탭의 무기와 일치해야 하며, 선택한 장착 슬롯만 교체하고 다른 모드·적·방어층·스탠스·교전 조건·표본 수를 유지한다.

직접 피해와 상태 피해, 각각의 DPS와 합계 DPS를 구분한다. 시간 경로가 지원되면 TTK 중앙값/P10/P90, 구간 내 처치 비율, 표본 수와 표본 평균의 95% 오차폭을 표시한다. 타격 시각이 미확정인 스탠스는 기존 엔진의 직접 피해 범위와 제한을 그대로 표시한다. 첫 접촉 0초를 나누어 DPS를 만들지 않는다. 수용량 초과는 게임 장착 불가인 가정 계산으로 표시한다. 계산 중 진행 표시와 취소를 제공하며 동시 비교 작업은 하나로 제한한다.

## 확인되지 않은 부분

실제 게임의 옵션 선택·옵션 구성·수치 추첨 확률분포는 이번 고정 원문에서 검증하지 못했다. 따라서 예시 추첨은 명시적인 균등분포 가정이며, 접합 계승 구간의 중앙값을 예시 수치로 쓴다. 목표 옵션 획득 확률이나 필요한 쿠바의 확률적 기대값을 확정적으로 제시하지 않는다. 예산은 사용자가 지정한 시도 횟수의 정확한 비용이다.
