# 작업 보존 · 실제 파일 창 · 모니터 · 한국어 표시 검증

기존 업데이트 전용 작업 복원을 일반 실행으로 확장했다. 사용자가 요청한 저장·불러오기, 재실행 후 빌드와 비교 기준 보존, 실제 모니터 이동, 한국어 게임 표기를 대상으로 한다. 기존 미커밋 작업과 계산 규칙은 보존했다.

## 일반 종료와 재실행

- 작업 변경 후 1초 동안 추가 변경이 없으면 자동 저장하고, 정상 종료 시 다시 저장한다. 상시 폴링은 사용하지 않는다.
- 저장 위치: `%LOCALAPPDATA%\WF Labs\workspace.json`. 근접·주무기·보조무기 빌드, 비교 기준, 총기 A/B 계산 결과, 리벤 작업/입력 초안, 선택 화면, 테마, 경량 모드, 계산 표본 수를 포함한다.
- 같은 폴더에 임시 파일을 완전히 기록한 후 교체하며, 이전 저장본은 `workspace.json.bak`으로 보존한다. 읽지 못한 파일은 `.unreadable-시각` 사본으로 남긴 뒤 백업 복원을 시도한다. 원본 사본을 보존할 수 없는 경우에는 자동 저장을 중지하고 오류를 표시한다.
- 총기 비교 결과에는 Core 어셈블리 해시를 저장한다. 엔진 또는 내장 데이터가 달라지면 기준 빌드는 유지하지만 이전 수치로 증감률을 표시하지 않는다. 다시 저장하고 실행해도 오래된 결과가 유효해지지 않는다.
- 입력 중인 잘못된 숫자는 계산 오류로 표시하며 마지막 유효 빌드를 자동 저장한다. 리벤의 입력 중 텍스트는 기존 초안 저장 구조로 보존한다.
- 테스트는 별도의 artifacts 폴더를 사용하며 실제 사용자 자동 저장 파일을 수정하지 않는다.

## 실제 저장·불러오기 창

`NativeSessionChecks`는 WPF UI Automation의 Invoke로 버튼을 누르고, 별도 UIA 작업에서 Windows 파일 선택 창의 파일 이름 입력과 확인·취소 버튼을 조작한다. 파일 경로를 콜백으로 주입해 대화상자를 건너뛰지 않는다.

근접·주무기·보조무기 저장, 한국어 파일 경로, 불러오기 후 모든 필드 일치, 저장/불러오기 취소, 손상 파일/필드 누락/슬롯 오류/다른 무기 구분 파일의 거부를 검사한다. 총기 왕복 저장에는 모드·랭크·포르마 극성·아케인 중첩·거리·레벨·강철의 길·엑시무스·교전 구간을 포함한다. 실패한 불러오기는 현재 빌드를 변경하지 않는다.

## 실제 모니터 이동과 DPI의 검증 범위

실제 HWND를 `SetWindowPos`로 모니터 작업 영역 사이에 이동하고, `MonitorFromWindow`와 `GetDpiForWindow`, WPF `VisualTreeHelper.GetDpi`를 비교했다. 테스트 HWND는 숨겨 사용자 화면과 초점을 방해하지 않는다. 보고서 PNG는 WPF 시각 트리 렌더링이며 실제 화면 픽셀 캡처와 구분한다.

| 연결 화면 | 픽셀 해상도 | 실제 확인한 DPI |
|---|---:|---:|
| DISPLAY1 | 3440 × 1440 | 96 / 100% |
| DISPLAY2 · 세로 | 1080 × 1920 | 96 / 100% |
| DISPLAY3 | 1920 × 1080 | 96 / 100% |

세로 모니터에서 창이 화면 밖으로 넘지 않도록 현재 모니터의 작업 영역과 DPI로 최소 창 크기를 다시 제한한다. 작은 화면에서는 내부 가로 스크롤로 기존 모딩 작업 공간에 접근하며, 넓은 화면으로 돌아오면 불필요한 스크롤을 해제한다. 창 이동/DPI 변경 시 열려 있던 앱 팝업을 닫아 이전 화면에 남지 않도록 했다. 기존 Ideal/ClearType 글꼴 렌더링은 유지한다.

**실제 서로 다른 배율의 모니터 간 전환은 미검증이다.** 연결된 세 화면이 모두 100%이므로 실제 DPI 변경 이벤트는 0회였다. OS 배율을 임의로 변경하지 않았다. 125%/150% 검사는 기존 smoke의 WPF 시각 트리 DPI 검사이며 실제 모니터 전환으로 주장하지 않는다.

## 한국어 이름과 설명

- 해시가 고정된 DE 한국어 Public Export 세 파일을 재확인하고 내부 ID 대응을 보완했다. 공식 데이터의 정확한 ID 또는 고유한 공식 태그로 연결하며, 유사한 이름으로 자동 추정하지 않는다.
- 참조 자료의 이름 **24개**, 기본 동작/고유 무기 동작을 포함한 스탠스 표시 이름 **52개**를 수정했다. 저장된 빌드의 ID와 계산 필드는 변경하지 않았다.
- `Flawed Rifle Aptitude` → `라이플 앱티튜드`, `Flawed Sure Shot` → `슈어 샷`, `Magnetic Strafe` → `마그네틱 스트레이프`, `Primed Steady Hands` → `프라임드 스테디 핸즈` 등을 반영했다. 손상된 모드도 공식 Export에 기록된 이름을 그대로 사용한다.
- 총기 모드 458개 중 일반 모드 455개는 현재 랭크의 공식 한국어 효과 설명을 사용한다. 리벤 3종은 한국어 편집 안내를 사용한다. 총기 아케인 툴팁도 선택한 랭크의 공식 한국어 설명을 사용한다.
- 위키 공격 구성요소 이름은 별도의 UI 번역으로 표시한다. 이것은 공식 아이템 이름 번역과 구분하며 내부 AttackName/ID는 변경하지 않는다.
- `클래싱 포레스트`는 Export에서 대응 항목을 찾지 못해 [공식 업데이트 39 한국어 패치 노트](https://www.warframe.com/ko/patch-notes/pc/39-0-0)의 목성 교차점 보상 표기를 확인했다. 근거는 `data/korean-name-overrides.json`에 보존한다.
- 자료실은 삭제된 항목, 어빌리티, 범위 밖 장비까지 보유한다. 공식 대응을 확인하지 못한 항목은 `한국어 미확인 / 원문`으로 구분한다. `AX-52`처럼 공식 이름 자체가 영문인 항목도 있으므로 영문 포함 여부만으로 임의 번역하지 않는다. 원문 항목 명단은 `artifacts/korean-audit/verification.json`에 있다.

## 검증 산출물

최종 결과: Release 경고/오류 0개, 계산 1,519개 통과, 실제 파일 창 20항목 통과, 상호작용 128항목 통과, UI smoke 153 PNG와 통과 보고서 10개(별도 드래그 좌표 JSON 1개). 일반 종료·재실행은 서로 다른 프로세스에서 검사했다. 통합 결과와 실행 어셈블리 해시는 `artifacts/workspace-dpi-korean-verification.json`에 기록했다.

- `artifacts/session-final-build.log`: Release 빌드.
- `artifacts/session-final-core.json`: 계산 회귀 1,519개 통과, 실패 0개.
- `artifacts/native-files-verified/native-file-check.json`: 실제 Windows 저장·불러오기 검사.
- `artifacts/workspace-verified/`: 서로 다른 두 프로세스의 정상 종료/재실행, A/B 결과, 초안, 자동 저장, 백업, 엔진 변경 결과 무효화 검사.
- `artifacts/monitors-verified/monitor-check.json`: 실제 모니터 핸들·좌표·DPI·스크롤 및 렌더링 상태.
- `artifacts/session-interaction-verified/checks.json`: 실제 버튼/팝업/슬롯/랭크/극성/수용량 상호작용 검사.
- `artifacts/session-smoke-verified/`: 최종 UI smoke와 100%/125%/150% 렌더링.
- `artifacts/korean-audit/verification.json`: 이름 변경, 원본 ID·계산 필드 불변 대조, 남은 자료실 원문 이름.

설치 파일 생성, 공개 배포, Git 커밋/푸시는 이 작업에 포함하지 않았다.
