# 일정 오버레이·성유물 균열 알림

## 변경 내용

- 마스터리 도넛을 120 × 120 DIP로 고정하고 수치·`마스터리 완료` 문구의 중심선과 여백을 통일했다. 글꼴·기존 자연스러운 렌더링 설정은 보존했다.
- 상단 메뉴의 키보드 초점 사각형을 없앴다. 선택은 2 DIP 언더바, 키보드 초점은 3 DIP 언더바로 표시한다.
- 중재 미션 유형은 여러 체크박스로 선택한다. 모두 선택/모두 해제를 지원하고, 제외 유형은 커뮤니티 등급에 관계없이 목록·현재 S 강조·다음 S 타이머에 동일하게 적용한다. 팩션 필터와는 AND 조건이다. 제외 목록을 저장한다.
- 각 지역 주기, 다음 S, 현재 중재, 테넷·코다 상점에 게임 오버레이 표시 체크박스를 추가했다. 상단의 `게임 오버레이` 스위치로 전체 표시를 켜고 끈다.
- `오버레이 · 성유물 알림`에서 추가 표시 항목, 위치·크기, 성유물 알림을 설정한다. 현재 시간과 선택 일정을 별도 네이티브 창으로 표시한다.
- 성유물 알림 조건은 미션 유형 × 경로(전체/강철의 길/일반/보이드 폭풍) × 등급(전체/리스~옴니아)이다. 여러 조건은 OR이며, 한 균열이 여러 조건에 맞아도 알림은 한 번이다. 팝업·소리를 각각 끌 수 있다.
- 알림 조건에 맞는 균열들을 오버레이에도 자동 표시할 수 있다. 현재 균열 목록에서 특정 균열 하나만 체크해 고정할 수도 있다. 해당 균열이 끝나면 오버레이에서 사라진다.

## 동작과 저장

오버레이는 워프레임이 전경일 때 표시한다. 평소에는 클릭이 게임으로 통과한다. `위치·크기 조정`에서 아래 손잡이로 이동하고 오른쪽 아래 손잡이로 크기를 바꾼 다음 `위치·크기 저장`으로 완료한다. 설정 창을 닫아도 편집 위치를 저장한다. 위치는 게임 클라이언트의 남은 영역에 대한 비율이며 크기는 DIP로 저장한다. 다른 크기·배율에서도 영역 안으로 배치한다.

일정 페이지의 클라이언트와 1초 로컬 타이머를 재사용한다. 게임 화면을 캡처하거나 OCR을 돌리지 않는다. 온라인 자료는 1분 간격이며, 오버레이 또는 알림을 켜 놓으면 다른 탭에서도 갱신한다. 저장 설정에 기능이 켜져 있으면 앱 시작 때부터 감시한다. 둘 다 끄면 일정 화면을 벗어날 때 타이머를 중지한다.

설정은 `%LOCALAPPDATA%\WF Labs\schedules\preferences.json`, 이미 전달한 균열은 같은 폴더의 `delivered.json`에 만료 시각과 함께 저장한다. 같은 균열에 대한 반복 타이머·연결 복구·앱 재시작 알림을 방지한다. 조건을 처음 등록했을 때 이미 진행 중인 균열도 최초 한 번 알린다. 만료한 기록은 정리한다. 기본 알림 조건은 비어 있다.

자료가 3분 이상 지연되거나 연결 실패로 캐시를 사용할 때는 알림을 내지 않는다. 주기 자료가 아직 유효하더라도 균열 자료가 지연되면 공식 자료로 보완한다. 미래 균열의 발생 시각은 예측하지 않는다.

## 자료 근거

- PC 월드 상태: https://api.warframestat.us/pc?language=ko
- 공식 보완: https://api.warframe.com/cdn/worldState.php 의 `ActiveMissions`, `VoidStorms`, `Hard`, `Modifier`, `ActiveMissionTier`, `Activation`, `Expiry`.
- API 구조 확인: https://github.com/WFCD/warframe-worldstate-parser/blob/master/lib/models/Fissure.ts . 구현 코드는 자체 작성했으며 upstream 코드를 복사하지 않았다.
- 공식 게임 문자열을 정규화한 public-export-plus의 ExportRegions·dict.ko·dict.en 를 사용한다. `/Lotus/Language/Missions/MissionName_VoidCascade`는 **보이드 범람**, `MissionName_Corruption`은 **보이드 홍수**다.
- 새 정규화 자료: `data/schedule-regions.json` — 354개 노드, 39개 미션 라벨. 원본 파일별 URL·SHA-256 포함. 생성기 `tools/import_schedule_regions.py`. 기존 MIT 라이선스 고지를 따른다.

화면 검수는 전환하지 않는 별도 Win32 데스크톱에서 BelowNormal로 실행했다. 게임 키 입력·실제 화면 캡처·포커스 전환은 하지 않았다. 사운드는 Windows의 알림음을 사용하며, 자동 검수에서는 실제 소리를 내지 않았다. 사용자가 `알림 테스트`를 누르면 선택한 팝업/소리가 실행된다.

## 제한

앱이 실행 중이어야 감시·표시한다. 게임의 독점 전체화면에서 실제 합성 여부와 실제 모니터 이동은 이번 검수에 포함하지 않았다. 테두리 없는 창/창 모드에서 사용을 권장한다. 네트워크·원본 월드 상태 지연으로 알림이 늦어질 수 있으며, 오래된 자료를 최신 알림으로 보이지 않게 차단한다. 오버레이에 많은 항목을 넣으면 편집 중 높이를 늘리거나 표시 항목을 조정해야 한다.

최종 실행본: `artifacts/riven-auto-side-app/WFLabs.exe`. 이전 폴더는 날짜가 붙은 백업으로 보존하며 전체 파일의 SHA-256을 대조한다. 배포 기록은 `artifacts/schedule-overlay-deployment.json`이다. 앱을 자동 실행하거나 공개 릴리스를 발행하지 않았다.
