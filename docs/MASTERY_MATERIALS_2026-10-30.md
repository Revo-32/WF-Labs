# 마스터리 필요 재료 · 2026-10-30

`내 장비 → 필요 재료`에서 아직 최대 랭크에 도달하지 않은 제작 장비를 모두 숙련하는 데 필요한 재료를 합산한다. 기존 제작·구매 추천 목록과 파밍 목표는 유지한다.

## 화면과 사용 흐름

1. 게임 동기화 또는 저장 목록으로 마스터리 이력과 보유품을 불러온다.
2. **필요 재료**를 누르면 필드론·뮤타젠 매스·데토나이트 인젝터의 부족 수량과 총 필요·보유·제작 중 수량을 확인할 수 있다.
3. 아래 표에는 전체 재료의 **총 필요 / 보유 / 부족** 수량을 표시한다. 검색과 **부족한 재료만**으로 범위를 좁힌다.
4. 재료를 선택하면 해당 재료를 사용하는 장비를 펼쳐볼 수 있다. 추가 설계도는 별도 펼침 목록에서 확인한다.
5. 이미 가진 장비를 재료로 사용하는 계획을 원하면 **보유 장비를 제작 재료로 사용**을 켠다. 실제 인벤토리를 변경하거나 장비를 소모하는 기능은 아니다.

마스터리 이력을 확인하지 못한 경우 모든 장비를 미숙련이라고 가정하지 않는다. 보유 목록이 불완전하면 부족 수량을 잠정 수량으로 안내한다.

## 계산 규칙

- 고정 제작식이 있는 미숙련 장비를 각각 한 번 숙련하는 계획이다. 이미 보유하거나 제작 중인 목표 장비는 다시 만들지 않는다.
- 선행 무기가 다른 장비의 제작 재료인 경우 **먼저 랭작한 후 다음 제작에 소비**할 수 있으므로, 선행 무기의 숙련용 사본을 불필요하게 하나 더 만들지 않는다.
- 모든 목표를 함께 계산한다. 여러 제작식이 공유하는 재료·완성 부품의 재고는 한 번만 차감한다.
- 제작 결과가 여러 개이면 제작 횟수를 올림해 계산한다. 재사용 설계도는 한 개, 소모 설계도는 필요한 제작 횟수만큼 계산한다.
- 필드론·뮤타젠 매스·데토나이트 인젝터·포르마 등 완성 재화의 수량을 보여준다. 이 재화의 자체 제작 원료까지 분해해 사용자가 찾는 완성 재화 수량을 숨기지 않는다.
- 워프레임의 섀시·시스템·뉴로옵틱스 등 제작 부품은 보유·제작 중 수량을 먼저 반영하고, 부족한 부품만 하위 제작식으로 펼친다.
- 기본값은 기존 장비를 보존한다. 재료로 사용되는 장비는 `장비 보존` 수량을 표시하고 부족분에서 차감하지 않는다. 명시적으로 사용을 허용하면 보유·제작 중 장비를 먼저 반영한다.
- 최대 랭크 40 장비는 최대 랭크까지 추가로 필요한 포르마를 별도 합산한다. 제작식 자체의 포르마와 구분하고, 해당 장비의 기존 포르마 횟수를 반영한다.
- 제작 크레딧과 **가격이 확인된 크레딧 설계도 구매 비용**을 구분한다. 가격을 모르는 설계도의 구매 비용을 임의로 만들어내지 않는다.

## 범위와 한계

카탈로그의 기본 제작식 기준이다. 대체 제작식이 여러 개면 첫 기본 제작식을 적용하고 화면에 개수를 안내한다. 모든 대체 제작식 중 최저 비용을 탐색하는 최적화는 수행하지 않는다. 순환 제작식은 중단하고 영향을 받는 항목을 표시한다.

고정 제작식이 없는 모듈러 장비의 모든 조합, 도금·평판·획득 미션의 기회비용까지 포함한 완전한 계정 재화 장부는 아니다. 재료 사용 장비 목록에는 중간 제작식 경로의 목표가 함께 표시될 수 있다.

선행 무기 중복 제작 방지, 공통 재고 차감, 제작 중 수량, 묶음 제작, 재사용 설계도, 보유 장비 보호, 미확인 이력, 완성 재화 유지, 설계도 크레딧 비용과 실제 카탈로그 합산을 검사했다. 전체 Core 검사 **1,784개 통과 / 0개 실패**.

최신 독립 실행 파일의 장비 UI 검사 **538개 통과**. 필요 재료 탭은 1760×920, 1600×960, 150% 렌더링에서 글자·컨트롤 경계를 검사하고 이미지를 직접 확인했다. 검색·부족분 필터·전체 요약 복귀를 UI Automation으로 확인했다. 사용자의 실제 게임 입력·포커스·저장 인벤토리는 변경하지 않았다.

같은 날의 [강화 UI·UX 검수](UI_UX_PERFORMANCE_REVIEW_2026-10-30.md)에서 1280×688·150% 및 사용 장비·설계도를 모두 펼친 상태까지 추가 검사했다. 작은 창에서는 페이지를 스크롤하면서 재료 표의 공간을 유지한다. 검색 결과 없음에는 필터 초기화를, 추가 재료가 없는 경우에는 전체 요약 복귀를 제공하며, 일부 보유 목록의 잠정 수량 경고는 요약 옆에도 표시한다. 검색 중 설계도 전체를 다시 생성하지 않는다.
