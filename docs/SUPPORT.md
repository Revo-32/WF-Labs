# 설치·사용·문제 해결

## 지원 기준

- Windows x64용 설치형·압축형 앱입니다. 개발 SDK는 필요하지 않습니다.
- 게임 화면 인식의 주 지원 범위는 PC 한국어·FHD 이상입니다. 작은 카드·강한 애니메이션·부분 가림·특이한 UI 배율에서는 미인식이 발생할 수 있습니다.
- 오버레이는 창 모드·테두리 없는 창에서 우선 검수합니다. 독점 전체화면·원격 데스크톱·HDR·서로 다른 DPI 모니터는 별도 환경 검증 항목입니다.
- 확정 계산과 근사 효과는 표시를 확인하세요. TTK는 선택한 적·레벨·상태·전투 구간에 따른 계산값입니다. 전체 어빌리티·익절티드 시뮬레이션은 현재 완료 범위 밖입니다.

## 처음 사용할 때

1. **모드**에서 무기와 모드를 고르고, 하단 상황 설정에서 적·레벨·전투 구간을 정합니다.
2. **성유물 / 리벤** 상단의 자동인식 스위치를 켭니다. 켜짐·대기는 읽는 중과 다른 상태입니다. 게임의 해당 화면이 보이면 판독하며, 실패한 내용은 앱에서 수정할 수 있습니다.
3. **내 장비 → 게임에서 동기화**로 보유 목록을 확인합니다. 게임 프로세스의 인벤토리 사본을 읽는 방식이며 읽은 시각을 표시합니다. 실패하면 마지막 목록을 유지합니다. JSON 가져오기도 가능합니다.
4. 목표를 등록하면 예약·성유물 추천·목표 미션 알림·보상 강조에 연결됩니다. 해금 조건·부품 거래 후 제작은 상세에서 확인합니다.

## 자주 만나는 상태

| 상태 | 확인할 내용 |
|---|---|
| 자동인식 화면 대기 | 게임이 전경인지, 보상/리벤 카드가 충분히 보이는지 확인합니다. |
| 이전 결과·변경 확인 중 | 전환 애니메이션이 끝난 다음 판독을 기다립니다. 계속 남으면 진단 정보와 전환 순서를 제보합니다. |
| 시세 없음·시세 확인 | 0 P가 아닙니다. 네트워크·거래자 조건과 조회 시각을 확인하고 갱신합니다. |
| 인벤토리 동기화 실패 | 게임 로딩·계정 변경 중일 수 있습니다. 저장 목록의 읽은 시각을 확인하고 다시 동기화하거나 목록을 가져옵니다. |
| 자동 업데이트 사용 불가 | 압축·개발본은 앱 내 설치 업데이트 대상이 아닙니다. 설치형 배포본을 사용합니다. |
| 압축본을 더블클릭해도 열리지 않음 | ZIP을 폴더 전체로 풀었는지 확인합니다. `WF Labs.exe`, `Update.exe`, `current/sq.version`을 함께 유지하세요. EXE만 따로 이동하지 마세요. RC4 초기 검수본의 메타데이터 누락은 수정본에서 복구했습니다. |
| 업데이트 연결 실패 | 현재 버전은 계속 사용할 수 있습니다. 나중에 확인하거나 공개 릴리즈에서 설치 파일을 받습니다. |

## 문제 제보

OCR은 글자 판독·옵션 구성 확인이 끝난 결과만 수율·등급·접합 평가에 사용합니다. 인식 확인이 필요한 값은 앱에서 수정할 수 있습니다. 리벤 등급은 해당 옵션 범위 안에서의 수치 품질이며 무기 빌드의 DPS 점수나 획득 확률이 아닙니다. 원본 글자가 사라진 작은 압축 이미지는 지원 기준인 FHD 게임 화면과 다릅니다.

인벤토리 동기화는 실험 지원입니다. 읽은 시각은 게임 서버가 목록을 갱신한 시각을 보장하지 않습니다. 부분 목록·오래된 목록으로 보이는 경우 마지막 저장 상태와 비교하고, 목록 가져오기로 보완하세요. 실제 계정의 제작/획득 후 연속 갱신은 별도 검증 항목입니다.

[GitHub 문제 제보](https://github.com/Revo-32/WF-Labs/issues/new/choose)에서 앱 버전, 화면 이름, 재현 순서, 기대 결과와 실제 결과를 적어주세요. OCR·오버레이 문제는 게임 해상도·화면 모드·Windows 배율도 포함하면 도움이 됩니다.

**업데이트 → 문제 진단 → 진단 정보 저장**에서 JSON을 내보낼 수 있습니다. 파일 내용을 확인한 뒤 필요한 경우 직접 첨부합니다. 계정 비밀번호·토큰·전체 인벤토리·게임 로그 전체는 공개 이슈에 첨부하지 마세요. [데이터 처리 범위](PRIVACY.md)를 참조하세요.

## 외부 서비스·게임 연동

WF Labs는 Digital Extremes나 warframe.market의 공식 앱이 아니며 해당 기관의 승인·지원이 확인되었다고 표시하지 않습니다. 게임 연동은 [Warframe의 제3자 소프트웨어 안내](https://support.warframe.com/hc/en-us/articles/360030014351-Third-Party-Software-and-You)를, 시세 조회는 [warframe.market API 규칙](https://docs.warframe.market/docs/rules/overview/)을 확인하세요.

정식 출시 전 검수 상태와 실제 환경에서 남은 항목은 [출시 준비 기록](RELEASE_READINESS_2026-10-27.md)에 구분합니다.
