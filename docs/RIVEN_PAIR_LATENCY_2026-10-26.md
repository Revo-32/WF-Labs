# 리벤 전후 비교 반응 시간 개선

2026-10-26. 사용자가 비교 행 자체는 정상이라고 정정했으므로 행의 구성·배치·등급 표현은 변경하지 않았다. 두 카드의 OCR 처리와 변경 감지 대기를 개선했다.

## 변경

- 이전/새 카드의 순차 OCR을 최대 두 개의 독립 Tesseract 컨텍스트로 병렬 처리한다. 컨텍스트마다 세마포어와 엔진을 소유하며, 모델을 재사용한다. 두 번째 컨텍스트는 두 카드 비교에서 필요할 때만 초기화한다.
- 동일한 자르기, 밝기 보정, 한국어 판독, 대체 판독, 수치·부호 교차 확인을 유지한다. 결과 순서는 작업 완료 순서와 무관하게 왼쪽/오른쪽에 고정한다. 불확실한 판독을 확정으로 바꾸지 않았다.
- 한국어 ONNX 판독의 기존 동기화를 유지한다. 진단 이미지 저장도 직렬화하고 왼쪽/오른쪽 파일 이름을 구분한다.
- 확대된 리벤이 있는 동안 시각 감지는 750ms에서 400ms 간격으로 확인한다. 카드가 없거나 게임이 전경이 아니면 기존 750ms로 복귀한다. OCR이 진행 중일 때 새 요청을 쌓지 않는다.
- 변경 후 OCR 최소 간격을 1,800ms에서 600ms로 줄인다. 두 관측의 안정성 검사, 순간적인 변화 무시, 내용이 같을 때 재판독하지 않는 규칙과 제한된 재시도는 유지한다.
- 완전히 같은 화면 서명은 위치 보정 비교를 반복하지 않고 즉시 일치로 처리한다.

## 동일 화면 교차 측정

사용자가 제공한 2119×1086 인노뎀 순환 화면을 사용했다. 이전/새 카드가 각각 4옵션인 실제 스크린샷이다. 다른 무거운 검수를 중단하고 한 프로세스에서 모델 준비 후 순차→병렬→병렬→순차→순차→병렬 순서로 측정했다. `WF_LABS_RIVEN_SERIAL=1`은 비교 검수용 설정이며 앱 기본 동작은 병렬이다.

| 중앙값, 각 3회 | 순차 | 병렬 |
| --- | ---: | ---: |
| 화면 후보 탐색 + 두 카드 인식 | 2.745초 | 2.091초 |
| OCR 내부 처리 | 2.656초 | 1.994초 |
| 프로세스 CPU 시간 | 2.953초 | 3.547초 |

화면 후보 탐색부터 두 카드 판독 완료까지의 경과 시간은 **23.8% 감소**했다. 병렬 3회의 전체 경과 시간은 1.884~2.114초였다. 이 프로세스의 모델 준비는 0.467초, 준비 후 첫 판독은 2.569초였다.

전체 6회의 양쪽 옵션 키·값·부호를 화면에서 읽은 정답과 비교했다.

- 왼쪽: 치명타 확률 +218.3%, 상태이상 피해 +110.1%, 근접 피해 +177.7%, 강공격 효율 −65.7%.
- 오른쪽: 공격 속도 +56.6%, 상태이상 피해 +110.1%, 화염 +99.3%, 마무리 피해 −116.4%.

모든 실행이 근접/8랭크로 판별되었고 여덟 옵션이 일치했으며 양쪽 모두 교차 확인을 통과했다. 원문 OCR 이름의 정확도를 개선했다거나 새 모델을 학습했다는 의미는 아니다.

## 해석과 한계

- 화면 캡처, 실제 게임 전환, 자동 감지 대기와 오버레이 출력까지 포함한 실전 종단 측정은 아니다. 저장 화면을 사용한 동일 조건 비교다. 게임에 표시되는 전체 지연은 이 측정값보다 길 수 있다.
- 병렬 처리의 CPU 시간 중앙값은 증가한다. 지속 점유가 아니라 카드 변경 시의 작업이며 동시 OCR 컨텍스트는 둘로 제한한다. 사용자 게임과 병행할 때의 프레임 영향은 별도 실전 확인이 필요하다.
- 동일 프로세스에서 순차/병렬을 교차 측정했으므로 작업 집합 수치를 이전 버전 대비 메모리 절감으로 해석할 수 없다. 추가 컨텍스트는 메모리를 사용한다.
- 기존 한국어 줄 인식을 우선하는 별도 빠른 경로도 실험했으나 안정적인 시간 단축이 없어 최종 구현에서 제거했다. 이번 변경은 학습 데이터나 인식 검증 기준을 완화하지 않는다.
- 검수는 사용자 입력 데스크톱으로 전환하지 않은 별도 Win32 데스크톱에서 수행했다. 게임 포커스나 입력을 조작하지 않았다.

측정 원본: `artifacts/riven-pair-latency-final/checks.json`, `summary.json`, `recognition-0.json`~`recognition-5.json`, `timing.jsonl`.

최종 자체 포함 실행 파일에서 리벤 검수 102개를 통과했다(`artifacts/farming-ready-riven/`). 어두운 이전 카드/밝은 새 카드 분리, 자동 종류 판별, 변경 후 갱신·이탈 시 닫힘, FHD/울트라와이드/4K 및 100%/150% 배율의 양쪽 오버레이 경계, 한 카드↔두 카드 전환을 포함한다. 전체 Core 회귀 1,737개와 전체 앱 smoke도 통과했다. 게임을 조작한 실전 테스트와는 구분한다.
