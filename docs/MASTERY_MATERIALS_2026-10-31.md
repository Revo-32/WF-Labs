# 필요 재료 분류·게임 아이콘 · 2026-10-31

후속 요청으로 화면은 [카테고리별 3·4열 단일 페이지](MASTERY_MATERIAL_GALLERY_2026-10-31.md)로 통합했다. 아래 분류·수량 계산·아이콘 출처와 앞선 표 형태 검수는 해당 버전의 기록으로 보존한다.

`내 장비 → 필요 재료`를 남은 제작 계획 전체의 재료 목록으로 확장했다. 기존 마스터리 추천·개인 목표·인벤토리 파일을 변경하지 않는다.

## 표시와 조작

- 기본은 **전체 재료**다. 부족한 항목뿐 아니라 이미 수량을 충족한 항목도 표시하며, 전체 종류·부족 종류·현재 표시 종류를 구분한다.
- **가공 재료 / 오픈월드 가공 재료 / 희귀 재화 / 일반 재화 / 부품·선행 장비**로 필터한다. 분류 미확인 항목을 위한 기타 재료도 유지한다.
- 실제 게임 아이콘, 한국어 이름, 분류, **총 필요 / 보유 / 제작 중 / 부족**을 한 행에서 확인한다. 보존하는 장비 수량은 보유 아래에 별도 표시한다.
- 기본 **준비 난도순**은 가공·희귀 재료를 일반 수집 재료보다 먼저 둔다. 같은 분류에서는 부족 항목을 먼저 두고 이름·내부 ID로 안정 정렬한다. 부족 수량순·이름순으로 변경해도 항목과 합계는 보존한다.
- 재료 선택 후 상세를 펼치면 분류 이유와 사용 장비를 확인한다. 검색·분류·부족 필터의 빈 결과는 필터 초기화 버튼으로 복구한다.
- 중복 제목과 큰 요약 영역을 줄여 최소 창에서도 재료 두 행을 완전히 표시한다. 제작비·보유 장비의 재료 사용 설정은 **계산 기준·제작비·장비 재료 사용 설정**에서 펼치고, 현재 보존/사용 상태는 위 요약에 항상 표시한다.

이 분류 순서는 WF Labs의 준비 계획용 기준이다. 게임의 공식 희귀도 전체 등급이나 수치화한 예상 파밍 시간·최단 획득 경로가 아니다. 일반 재화에는 지역 전용 원물과 비일반 자원도 포함하며, 모든 지역 재료가 같은 드롭 확률이라는 뜻이 아니다. 오픈월드 가공 재료는 제작식이 있는 합금·보석 등으로 한정하고 원물과 구분한다.

## 수량 계산 보완

기존 계산은 일부 일반 자원의 선택적 제작법을 기본 제작으로 펼쳤다. 오로킨 셀·뉴럴 센서·뉴로드·갈륨·모르픽스·컨트롤 모듈은 이제 **수집할 재료 자체**로 집계한다. 예를 들어 셀 3개가 필요하고 1개 보유 중이면 셀 부족 2개이며, 셀 제작용 수만 개의 일반 자원으로 대체하지 않는다.

반대로 `Resources`로 분류된 이쿼녹스 데이·나이트 부품, 네크라메크·해당 아크윙 총기 제작 부품은 내부 ID로 제작 부품임을 구분해 부족분만 제작한다. 완성 부품 재고를 먼저 차감하고 남은 수량에만 하위 제작 재료·제작비·설계도를 합산한다.

필드론·뮤타젠 매스·데토나이트 인젝터·포르마·정제된 광물은 완성 재료 수량을 유지한다. 원물과 완성품을 이중 합산하지 않는다. 고정 기본 제작식·장비 보존·공유 재고·불완전한 보유 목록 안내 등 [기존 합산 규칙](MASTERY_MATERIALS_2026-10-30.md)을 유지한다. 모든 대체 제작법의 전역 최적화와 조립식 장비의 모든 조합은 계산 범위 밖이다.
