# 필요 재료 · 카테고리별 단일 페이지 · 2026-10-31

사용자 요청에 따라 상단 연구 재료 3종 요약과 하단 표를 합쳤다. [앞선 분류·게임 아이콘·수량 계산](MASTERY_MATERIALS_2026-10-31.md)을 유지하면서 표시 구조를 바꾼다.

## 화면

- 상단에는 검색·분류·부족한 재료 필터와 전체/부족/현재 표시 종류 수만 둔다.
- **카테고리 제목 → 가로 3~4개 재료 → 다음 카테고리**가 이어지는 하나의 세로 스크롤이다. 카테고리 사이에는 얇은 구분선을 사용한다.
- 넓은 창은 4열, 최소 창은 3열이다. 사용 가능한 너비에서 스크롤바 공간을 미리 제외해 스크롤바 출현 때문에 열 수가 반복해서 바뀌지 않도록 한다.
- 각 타일에는 기존 게임 이미지·한국어 이름·강조한 부족량과 총 필요/보유/제작 중 수량을 표시한다. 보존하는 장비 수량도 해당 항목에 남긴다.
- 기본 가공 재료는 필드론·뮤타젠 매스·데토나이트 인젝터·포르마를 먼저 배치한다. 같은 재료를 별도 상단 요약에 중복 표시하지 않는다.
- 정렬은 카테고리를 유지한 채 분류 안에서 적용한다. 준비 난도순·분류 내 부족량순·분류 내 이름순을 지원한다.
- **사용 장비** 버튼에서 분류 근거와 사용 장비를 상세 팝업으로 확인한다. 긴 설명 때문에 주 페이지의 타일 높이가 지나치게 커지지 않도록 한다. 상세를 닫거나 주 페이지를 스크롤·이동·숨기면 팝업도 닫힌다.
- 추가 설계도는 같은 페이지 하단에서 펼치며, 설계도도 3~4열의 작은 행으로 나누어 표시한다. 계산 기준·제작비·보유 장비 재료 사용 설정은 마지막에 유지한다.

## 구현과 성능

`MaterialGallery`는 가상화된 세로 목록의 한 항목을 재료 3~4개가 담긴 가로 행으로 구성한다. 카테고리 제목·재료 행·펼친 설계도 행·계산 설정이 같은 pixel scroll을 공유한다. 기본 타일에 별도의 ScrollViewer를 넣거나 수백 개 타일을 한 번에 생성하지 않는다. 상세 팝업의 긴 장비 설명은 주 페이지와 분리된 보조 스크롤을 사용한다.

검색·분류·정렬은 합산 결과의 항목과 수량을 변경하지 않는다. 보유 장비 사용 설정과 인벤토리가 같으면 합산 결과·설계도 배열을 재사용한다. 아이콘과 OCR 모델은 변경하지 않는다.

창 너비 변경 시 가능한 한 현재 보던 재료를 기준으로 복원한다. 필터 변경과 명시적인 맨 위 이동이 이전의 지연된 스크롤 복원에 덮어써지지 않도록 요청 순서를 구분한다. 목록 컨테이너의 접근성 이름에는 내부 record 문자열 대신 카테고리·재료 이름을 제공한다.

## 검수 중 발견한 문제

첫 시안은 긴 사용 장비 설명을 타일 안에서 펼쳤다. 최소 창·수백 개 재료에서 큰 가변 높이 행과 가상화 스크롤이 정체되는 경우가 있어 해당 격리 QA 프로세스만 종료하고 상세 팝업으로 변경했다. 설계도 수백 개를 하나의 큰 footer에 넣는 시안도 제거하고 작은 가상화 행으로 나눴다. 첫 실패·정체 실행과 수정 후 검수를 별도 폴더에 보존한다.
