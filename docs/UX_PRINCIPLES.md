드래그는 WPF 포인터 캡처로 처리하고 미리보기 카드를 독립 렌더링한다. 장착 직후 재생성된 카드의 빈 이미지 문제를 재현·수정했다. 보관함→슬롯 장착, 슬롯→슬롯 이동, 슬롯→보관함 해제, 취소 및 유효하지 않은 위치의 상태 보존을 검증한다. 드래그 중 해제 영역을 강조한다. 세부 출처·검증 한계는 `ENEMY_TARGETS.md`와 `VALIDATION.md`에 있다.

이하 내용은 이전 버전 기록이며 충돌 시 위 최신 상태가 우선한다.

## 대상과 교전 선택 (0.6.2)

대상은 팩션·적·표시 레벨·난이도로 선택한다. 체력과 방어력을 외워 입력하지 않도록 자동 산출하며, 직접 입력은 별도 선택으로 노출한다. 숫자가 있는 선택창도 용도 이름을 보이고 단위·뜻을 명시한다. 펼침 화살표는 텍스트 글꼴에 의존하지 않는 벡터로 배치하고, 접힘 상태와 방향을 일치시킨다. 선택한 대상은 계산 결과의 제목 아래에도 표시한다.

## 설계 기준

- 상단의 모드·리벤·자료·개발 탭으로 페이지를 전환한다. 활성 탭은 금색 밑줄로 표시하며 테마·경량 모드는 설정 메뉴에 둔다.
- 검정에 가까운 무채색 바탕에 금색 강조를 사용한다. 큰 정보 영역은 제목과 구분선으로 나누며 둥근 패널 안에 패널을 반복하지 않는다. 조작 가능한 모드 카드·입력·버튼의 경계는 유지한다.
- 그래프는 실제 데이터로 그린다. 방어력-DPS는 선·면, 개별 타격 피해는 막대, 피해 구성은 도넛, 치명타 단계 확률은 수평 막대로 표현한다. 의미가 없는 장식용 추세·히트맵을 만들지 않는다.

- 무기군·무기는 한 줄의 선택창, 스탠스 모드는 슬롯 편집 도구 옆, 동작과 교전 조건은 가운데 상황 설정에 둔다. 선택과 결과의 관계가 가까운 위치에서 보이게 한다.
- 모드 보관함은 검색·정렬·필터와 카드 목록을 사용한다. 드래그로 장착·이동·교환하고, 이름·코스트·극성으로 항목을 식별한다. 상세 효과는 호버와 키보드 포커스로 확인한다.
- 모드를 찾는 동안 무기 설정과 장착 슬롯을 화면에 유지한다. 보관함 내부만 스크롤한다. 최소 지원 창에서도 모드 카드 두 줄 이상이 온전히 보여야 한다.
- 수용량 사용/최대·초과 여부는 바로 보인다. 랭크·카탈리스트·극성 등 상세 설정은 열기 표시가 있는 버튼을 통해 팝업에서 조작한다. 상세 설정이 기본 작업 공간을 밀어내지 않게 한다.
- 선택·발동·오류는 익숙한 컨트롤 상태와 짧은 문구로 알린다. 계산 미지원이나 용량 초과 같은 중요한 정보는 툴팁에만 숨기지 않는다.
- 애니메이션은 상태 변화를 이해시키는 짧은 피드백이 필요할 때 사용한다. 작업과 관계없는 상시 애니메이션을 추가하지 않는다. 경량 모드와 입력 반응성을 우선한다.
- 정보가 많아지면 처음부터 모두 펼치기보다 핵심 결과와 상세 근거를 단계적으로 보여준다. 조작 방법을 설명하는 긴 문구를 추가하기 전에 조작부 자체를 개선한다.

## 제출 전 확인

기능 핸들러가 실행되거나 PNG 파일이 생성됐다는 사실만으로 UI 검증을 끝내지 않는다. 실제 지원 창 크기의 렌더링을 보고 다음을 확인한다.

1. 무기 선택·장착 슬롯·검색·보관함을 한 화면에서 사용할 수 있는가.
2. 보관함의 카드가 두 줄 이상 완전히 보이고, 목록을 스크롤해도 장착 슬롯은 고정되는가.
3. 긴 한국어 이름·두 줄 효과·계산 오류가 겹치거나 화면 밖으로 밀리지 않는가.
4. 입력창이 옆 설명의 높이에 맞춰 불필요하게 늘어나지 않는가.
5. 원본 수치·계산 조건·미지원 범위를 확인할 수 있는가.

v0.5.1에서는 이 기준에 맞춰 왼쪽 940 DIP 고정 높이와 전체 스크롤을 제거하고, 설정·카드·보관함 공간을 다시 배분했다. 창 크기별 카드 가시성과 내부 스크롤을 자동 검사하고 생성한 화면을 별도로 눈으로 확인한다.
