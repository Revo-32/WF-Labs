# RC4 출시 검수 · 2026-10-27

후속 배포 검수 후보는 `1.0.0-rc.5`로 분리한다. 아래 RC4 로컬 완료 기록과 RC5 후속 검증을 구분하며, 사용자 실험 폴더는 보존한다.

현재 후보는 `1.0.0-rc.4`이며 정식 1.0 발행과 구분한다. 사용자 연속 게임 검증을 방해하지 않는 범위에서 패키징·자동 검사·설치 전이를 준비한다. 기존 RC4 실험 폴더와 원본 저장소의 HEAD·인덱스는 보존한다. 별도 GitHub 준비 사본은 `E:/CODEX/Workspaces/WF-Labs-Release-RC4-20261027`이다.

## 이번 보강

- 최상위 실행기에서 앱 프로세스·보이는 창·기능 검사·정상 종료까지 확인한다. `sq.version` 누락 및 버전 불일치를 실행 전에 차단한다.
- 설치 업데이트 패키지와 압축본의 전체 앱 파일을 SHA-256으로 비교한다. Velopack이 루트로 옮기는 updater/stub도 대응 경로에서 비교한다.
- 정수형 모델 메타데이터 반복문의 변수 이름이 nuspec XML 변수를 덮어쓰던 검수 도구 오류를 수정했다. 실행 실패가 아니라 패키지 검수 단계의 오류였다.
- 메타데이터 누락·다른 payload를 가진 사본을 만들고 체크섬은 맞게 갱신해, 더 깊은 배포 검사가 이를 거부하는지 검사한다. 원본 패키지는 변경하지 않는다.
- GitHub Windows 및 배포 초안 workflow에 실제 압축본 실행·OCR·전체 UI·배포 Core DLL 검사를 필수 단계로 추가했다. 소스 빌드와 최종 배포 DLL의 검수 대상을 구분한다.
- 인벤토리 자체 메모리 검사의 앞선 synthetic JSON이 다음 탐색에 발견되는 간섭을 진단했다. 무작위 영역 탐색 전에 해당 fixture 하나만 만들도록 테스트 순서를 고쳤다. 제품의 목록 선택 규칙이나 성공 조건은 낮추지 않았다.
- 첫 원격 검사에서 UI Automation의 클릭 이벤트·비동기 시세 갱신 완료 전에 구매 비교를 관찰하는 순서 문제가 드러났다. 실제 UI 요청의 완료를 기다리고 지연된 응답으로 검사하도록 수정했다. 구매 금액·여분·절약 결과의 성공 조건은 유지했다.

## 설치 전이

별도 QA ID `WFLabs.Verify`, 바로가기 없음, private Win32 desktop에서 검수한다. 대상 payload는 RC4 앱이고 설치 메타데이터만 QA 버전 `1.0.0-qa.5`로 분리한다. 실제 사용자 설치본을 업데이트하거나 게임을 재시작하지 않는다.

- 이전 공개 코드 기반 `0.10.0-qa.21` → `1.0.0-qa.5`: 다운로드·적용·재시작·빌드/리벤 복원·제거, 실제 사용자 시작 설정/작업 해시 보존 통과.
- 개인 목표 지원 `1.0.0-qa.2` → `1.0.0-qa.5`: 위 항목과 목표·예약 재계산·오버레이 설정 복원 통과.

근거는 `artifacts/release-rc4-20261027/{legacy-install,planning-install}/installer-verification.json`이다. 이는 QA ID의 로컬 업데이트 feed 전이이며 공개 서버에서 1.0이 검색된다는 뜻은 아니다.

## 최종 결과 위치

`artifacts/release-rc4-20261027`의 완료 보고서를 따른다. 원본 첫 실패·재실행·후속 패키지 검수의 provenance를 보존한다. 초기 동시 빌드의 파일 잠금 실패, 인벤토리 fixture 간섭, 검수 도구의 모델 메타데이터 변수 오류를 성공한 검사로 바꾸어 기록하지 않는다.

## 계속 남는 외부 조건

- 사용자가 진행 중인 실제 게임의 연속 성유물/리벤 전환, 화면 이탈 및 장시간 자원·FPS 검증.
- 실제 Windows 로그인과 게임 실행에 따른 자동 시작, 물리 모니터 이동·DPI·HDR·독점 전체화면.

- 외부 한국어 리벤 원문 12장의 최종 7장 일치·5장 실패는 유지한다. 이번 배포 검수로 OCR 일반 정확도가 개선됐다고 주장하지 않는다.

추가 기능·메커니즘이나 OCR 가중치를 이번 출시 준비에서 변경하지 않는다. 사용자 테스트를 완료했다고 대신 판정하지 않으며 정식 발행은 별도 단계다.
