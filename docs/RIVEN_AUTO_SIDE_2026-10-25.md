# 리벤 자동 감지·좌우 오버레이 검수

기존 `RIVEN_OVERLAY_2026-10-25.md` 이후 변경 사항이다. 단축키·로그 중심 감지를 작은 화면의 시각 변화 감지로 확장하고, 하단 오버레이를 좌우 두 창으로 교체했다.

## 동작

- 자동 인식을 켜면 워프레임이 전경일 때 750ms 간격으로 가로 640px 미리보기를 확인한다. 보라색 글자의 색·연결 요소·행 배치만 검사하며 이 단계에서 OCR을 실행하지 않는다.
- 카드가 안정적으로 나타나거나 글자 영역이 바뀔 때 해당 영역을 고해상도로 읽는다. 같은 화면은 다시 읽지 않는다. 판독 실패 재시도는 두 번으로 제한한다. 로그는 보조 신호이며 필수 조건이 아니다.
- 카드가 사라지거나 다른 앱으로 이동하면 오버레이를 닫는다. 자동 오버레이는 카드가 유지되는 동안 표시하며 수동 재인식만 30초 후 닫는다. 게임 활성화·키 입력·옵션 자동 채택을 하지 않는다.
- 카드 한 장: 좌측 끝에 옵션별 수율·범위, 우측 끝에 접합 가능 조합·대체 옵션 종류 수를 표시한다. 두 장: 화면의 좌우 카드에 대응해 각각 수율과 접합 요약을 표시한다. 현재/새 옵션을 임의로 단정하지 않는다.
- 각 창은 게임 너비의 최대 23%, 아래 15% 바깥에 배치한다. 하단 쿠바 버튼 영역을 비우고 클릭은 게임으로 통과한다. 내용이 짧으면 창 높이를 줄인다.
- 종류와 랭크는 설정 기준이다. 자동 판별하지 않는다. 수율은 최소~최대 범위 안의 위치이며 획득 확률·빌드 점수가 아니다. 음옵은 수치의 절대 크기를 나타낸다.

## 실제 첨부 화면 OCR 수정

밝은 보라색 배경과 검은 카드 위의 글자를 분리했다. 한국어·숫자 판독을 행별로 조합하고 두 전처리 결과를 대조한다. 줄바꿈된 옵션 이름과 문장 뒤의 부호·수치를 함께 읽으며, 값이나 부호를 임의로 채우지 않는다.

사용자 첨부 인노뎀 화면의 확인 결과(근접·8랭크 설정):

| 옵션 | 인식 수치 | 범위 내 위치 |
|---|---:|---:|
| 상태 이상 지속 시간 | +118.8% | 78.1% |
| 상태 이상 확률 | +108.1% | 83.8% |
| 화염 | +106.4% | 75.4% |
| 슬라이드 치명타 확률 | -100% | 13.0% |

이 구성의 접합 가능한 조합은 0개다. 기존 리벤 범위·접합 엔진을 재사용했다.

## 검수 결과

- Release 빌드·publish 성공. 전체 Core 1,574개 통과, 리벤 집중 검사 44개 통과.
- 최종 publish 파일에서 리벤 OCR·UI·자동 감지 검사 43개 통과. 실제 WPF Automation으로 창 열기, 교정·실패 차단·복구, 랭크 변경, 네 종류 리벤 작업실 가져오기를 확인했다.
- 실제 첨부 화면에서 네 옵션의 이름·부호·수치와 전처리 간 일치를 확인했다. 동일 화면을 유지하는 상태 재생 120초 동안 추가 OCR 요청은 0회였다.
- 첨부 이미지를 원래 픽셀 크기로 1920×1080, 3440×1440, 3840×2160 검은 캔버스에 배치한 시험에서도 최종 한 카드·네 옵션이 정확하게 일치했다. 이는 해상도별 실제 게임 캡처 세 장을 시험했다는 의미가 아니다.
- 실제 첨부 이미지의 해당 실행 OCR 시간은 3.41초. 해상도별 시험 배치는 각각 3.24 / 1.82 / 3.40초. 안정화 대기·네이티브 화면 캡처·게임 병행 비용을 포함한 전체 지연은 아니다.
- 640×406 미리보기 분석 10회 평균 15.53ms, 최대 18.83ms. 네이티브 화면 캡처 비용 제외.
- 좌우 창의 100%·150% 배율 배치, 하단 영역 비움, 클릭 통과·비활성 스타일, 실제 성유물 화면과 빈 화면에서 리벤 판독을 시작하지 않는 조건을 확인했다.
- WPF 전체 smoke 통과. 성유물 자동 감지 회귀 검사도 통과했다.
- UI 검사는 별도 Windows 데스크톱에서 실행했고 사용자 데스크톱으로 전환하지 않았다. 실행 중인 게임과 기존 WF Labs를 종료·재시작하지 않았다.
