# 일정 오버레이 자동 세로 순환

2026-10-26 사용자 요청에 따라 오버레이의 수동 스크롤바를 제거하고 전광판 형태의 자동 세로 순환으로 바꿨다.

## 표시 동작

- 현재 시각은 상단에 고정한다.
- 아래 일정·얼럿·성유물 균열·안내 문구는 하나의 본문으로 이동한다. 가로형 배치에서도 두 영역이 같은 속도로 움직인다.
- 본문이 표시 영역을 넘을 때만 위쪽으로 천천히 흐른다. 영역 안에 모두 들어오면 정지한다.
- 시작과 마지막 항목이 들어온 위치에서 각각 2.5초 정지한다. 이동 속도는 기본 12 DIP/초이며 설정한 글자 크기에 비례한다.
- 마지막 이후에는 같은 본문의 사본이 자연스럽게 이어진다. 빈 화면을 크게 남기거나 처음 위치로 되감는 애니메이션을 사용하지 않는다.
- 매초 시각·남은 시간 갱신은 기존 행을 갱신하며 순환을 재시작하지 않는다. 창 크기·글자 크기가 바뀌면 이동 거리를 다시 계산한다.
- 위치·크기 편집 중에는 정지한다. 오버레이를 숨기거나 닫으면 애니메이션 clock을 제거하고, 다시 표시할 때 시작 부분부터 읽는다.

## 구현

`VerticalMarquee`가 본문과 반복 사본을 관리한다. 스크롤바가 숨겨진 viewport에서 `TranslateTransform`의 WPF animation만 움직인다. 직접 프레임 타이머·렌더링 이벤트·화면 캡처 폴링을 추가하지 않았다. 애니메이션은 최대 30 fps로 제한하며, 내용이 길고 실제 표시 중일 때만 활성화한다. 기존 클릭 통과·비활성 오버레이·배경 투명도·글자 그림자를 유지한다.

`ScheduleOverlayView`의 시각 영역은 이동 대상 밖에 있다. 두 본문은 같은 데이터로 갱신되어 순환 경계에서도 남은 시간이 동일하다. 위치 편집의 완료 버튼과 강철의 길 필터는 기존 방식대로 조작한다.

## 검수

- `artifacts/schedule-marquee-final-ui-1` ~ `-3`: 31개 항목을 3회 통과. 실제 시간 진행과 지정 시점의 위치, 현재 시각 고정, 매초 갱신 시 순환 유지, 끝 정지·연결, 좁은/가로형·글자 배율 변경, 짧은 목록 정지, 편집 완료 UIA, 숨김 후 정지, 클릭 통과와 native alpha를 확인했다.
- `artifacts/schedule-marquee-schedule-ui`: 기존 일정·필터·설정·오버레이 회귀.
- `artifacts/schedule-marquee-alpha`: 편집·크기 변경·다시 표시 후 native 합성 바탕과 배경 alpha 회귀.
- `artifacts/schedule-marquee-core.log`: 계산·데이터 회귀.
- `artifacts/schedule-marquee-smoke`: 실제 self-contained 실행 파일의 전체 앱 smoke.

검수는 전환하지 않은 별도 Windows 데스크톱에서 진행했다. 사용자 게임 화면·입력·포커스는 건드리지 않았다. 실제 게임 위의 표시를 새로 캡처한 검사는 아니다.

검증한 실행본은 `artifacts/schedule-marquee-final-app`에 보존했다. 사용자 앱이 종료된 것을 확인한 뒤 기존 실행 경로 `artifacts/riven-auto-side-app/WFLabs.exe`에 반영했다. 513개 파일의 SHA-256 대조와 이전 실행 폴더 백업은 `artifacts/schedule-marquee-deployment.json`에 기록했다. 이후 무기 순환 UI 빌드에도 같은 구현을 포함한다. 실행 중인 사용자 앱을 강제 종료하거나 자동 실행하지 않았다.
