# 데이터와 개인정보

2026-10-27 기준. WF Labs는 독립적으로 개발한 Windows 보조 앱입니다.

## 로컬 처리

- 성유물·리벤 화면 인식은 PC에서 수행합니다. 화면 이미지와 인식 원문을 OCR 서버로 전송하지 않습니다.
- 자동인식은 게임 상태와 화면 변경을 감지해 필요한 때에 판독합니다. 게임 보상 선택·리벤 채택·거래 입력은 사용자가 합니다.
- 인벤토리 동기화는 실행 중인 Warframe 프로세스에 읽기 권한으로 접근해 인벤토리 JSON 사본을 찾습니다. 프로세스 쓰기·코드 주입·계정 비밀번호 입력은 사용하지 않습니다. 게임 로그 전체가 공식 인벤토리 API라는 뜻은 아닙니다.
- 가져오기·내보내기는 사용자가 선택한 JSON 파일을 처리합니다. 인벤토리 파일을 공개 이슈에 첨부하면 보유 정보 등이 노출될 수 있습니다.

## 저장 위치

기본 데이터 폴더는 `%LocalAppData%\WF Labs`입니다. 빌드·비교 기준·리벤 입력, 인벤토리·마스터리 사본, 개인 목표, 일정·알림·오버레이 설정, 가격 캐시, 업데이트 복원 자료와 일부 진단 상태가 저장됩니다. 손상 복구용 `.bak` 또는 `.invalid-*` 파일에도 이전 자료가 남을 수 있습니다. 앱 제거와 사용자 데이터 삭제는 별개입니다.

데이터를 모두 지우려면 앱과 자동 시작 도우미를 종료하고 위 폴더를 직접 삭제합니다. 필요한 빌드·목표는 먼저 백업하세요. 이 동작은 되돌릴 수 없습니다. 앱의 자동 실행은 설정에서 끌 수 있습니다.

## 외부 요청

- `api.warframe.market`: 공개 품목·판매 호가. 품목 ID와 선택한 플랫폼·거래자 상태·크로스플레이 조건을 전송합니다. 인벤토리 파일·게임 계정 이름·OCR 이미지·리벤 원문은 요청에 첨부하지 않습니다. 연결 상대는 일반 인터넷 연결 정보(IP 등)를 볼 수 있습니다.
- 공개 일정 공급원: 게임 일정·미션·상점·주간 순환 자료를 조회합니다.
- GitHub: 버전 확인·릴리즈 노트·업데이트 다운로드. 앱의 자동 확인·다운로드를 설정에서 제어할 수 있습니다.
- 출처 열기·문제 제보 링크는 기본 웹 브라우저로 해당 사이트를 엽니다.

WF Labs 자체 분석 서버로 사용 기록이나 계정 정보를 자동 업로드하는 기능은 없습니다. 외부 서비스의 응답·가용성과 개인정보 처리는 각 서비스 정책의 적용을 받습니다.

## 진단 정보 저장

업데이트 설정의 **진단 정보 저장**은 앱 버전, 런타임·Windows 버전, 화면 크기, 자체 메모리 사용량, OCR 구성 파일의 존재·크기를 JSON으로 저장합니다. 파일은 사용자가 선택한 위치에만 생성하며 자동 전송하지 않습니다. 사용자 이름·프로필 경로·계정·인벤토리·리벤 입력·인식 원문·화면 이미지를 포함하지 않습니다.

별도로 사용자가 캡처한 스크린샷이나 수동으로 첨부한 파일은 이 제한과 다릅니다. 제보 전 직접 확인하세요.
