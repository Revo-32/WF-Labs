# 개인 파밍 목표 · 재료 예약 · 세트 구매 비교

2026-10-26 개발 기록. 기존 모딩·마스터리·성유물·일정 흐름에 개인 목표를 연결한다. 공개 0.10.0-preview.1과 별개인 차기 개발본이다.

## 사용 흐름

- 모딩의 **제작 목표 +**, 마스터리 장비 상세의 **제작·수집 목표에 추가**, **내 장비 → 내 목표**의 검색에서 등록한다.
- 목표 수량은 최종 보유할 수량이다. 이미 가진 장비와 제작 중인 장비를 반영한다. 목록 위쪽 목표부터 재료와 크레딧을 예약하며 위로/아래로, 수량, 일시 정지, 삭제를 지원한다.
- 목표 상세는 **재료·예약 / 구매 비교**로 나눈다. 부족 재료를 먼저 표시하고 획득처·설계도 조건은 펼쳐 확인한다. 오른쪽 성유물 추천은 선택한 목표 또는 전체 목표의 부족 부품에 연결한다.
- 보유 성유물의 정련도·잔영 비용·개인 또는 동일 성유물 분대의 목표 획득 확률을 기존 계산기로 비교한다. 보유하지 않은 성유물을 이미 가진 것처럼 추천하지 않는다.
- 해당 보유 성유물을 사용할 수 있는 현재 균열에 **목표**를 표시한다. 일정 설정의 **내 목표** 경로, 목표 알림 켜기, 일반/강철의 길/보이드 폭풍, 미션 유형 필터를 지원한다. 같은 균열에 수동 알림과 목표 알림이 겹쳐도 한 번만 알린다.
- 성유물 보상 카드와 게임 오버레이에 **목표 부품 · N개 필요**, 보유량 또는 예약량을 표시한다. 보상을 자동 선택하거나 인벤토리에 임의로 추가하지 않는다.

## 예약과 구매 계산

- 실제 보유 스냅샷을 변경하지 않는 별도 예약 계산이다. 다른 목표에 예약한 수량은 추가 마스터리 제작 추천의 가용 재료에서도 제외한다.
- 이미 제작에 들어간 항목의 재료를 다시 예약하지 않는다. 재사용 설계도는 공유하며 구매 비용을 중복 청구하지 않는다. 묶음 제작에서 생길 예정인 여분과 실제 보유량을 구분한다.
- 목표로 확보한 장비도 다른 제작의 재료로 소모하지 않도록 보호한다. 미숙련 장비를 재료로 소비하는 경로에는 먼저 숙련할 것을 알린다.
- 보유 목록이 일부만 읽혔으면 구매 수량과 판매 여유를 확정하지 않는다. 예약 외 거래 부품에는 미숙련 장비를 제외한다. 이 목록은 자동 판매 지시가 아니다.
- 낱개와 세트의 확인된 판매 호가를 고정한 후, 구성 수량을 충족하는 최소 지출 조합을 정확 탐색한다. 서로 연결되지 않은 세트군을 분리하고, 중첩 세트는 A*로 비교한다. 계산은 UI 밖에서 실행하며 취소할 수 있다.
- 세트에 같은 부품이 두 개 들어가는 경우와 일부 제작 부품만 거래 세트에 포함되는 경우를 반영한다. Aklex Prime의 거래 세트를 제작식 전체와 동일시하지 않는다.
- 시세 없는 항목을 0 P로 처리하지 않는다. 확인된 등록 호가 기준이며 거래 체결·판매 수량을 보장하지 않는다. 구매 후 여분의 예상 재판매 수익은 비용에서 빼지 않는다. 크레딧·비거래 재료·해금 조건은 별도로 표시한다.

## 자료와 저장

- `data/inventory-market-bundles.json`: warframe.market v2의 231개 세트, 813개 고유 구성품. `setRoot`, `setParts`, `quantityInSet`, `gameRef`를 사용한다. 이름 추정으로 구성품을 연결하지 않는다.
- 원본: https://api.warframe.market/v2/items 및 `/v2/items/{slug}`. 원본 응답 1,045개의 URL과 SHA-256을 정규화 파일에 보존한다. 수집 실패로 빠진 세트는 없다.
- Omnia는 Lith/Meso/Neo/Axi만 허용하며 Requiem은 제외한다. 공식 Update 35.5: https://www.warframe.com/de/patch-notes/switch/35-5-0
- 기존 제작식·보상표·한국어 명칭 및 획득처의 라이선스와 출처를 유지한다. 목표 자료는 `%LocalAppData%\WF Labs\planning\goals.json`에 저장하고 정상 백업을 유지한다. 손상 파일은 덮어쓰기 전에 별도 보존한다.
- 시세는 기존 공유 캐시·주기 갱신을 재사용한다. 세트 구성을 배포 데이터로 내장하므로 보상 인식 순간 세트 구성 API를 호출하지 않는다.

## 검증

- Core 전체 회귀 1,737개 통과, 실패 0. 신규 파밍 검증 29개에는 예약 우선순위, 큐 중복 소모 방지, 재사용 설계도, 세트 수량, 미확인 시세, 취소, 미션 알림 중복 방지가 포함된다.
- 중첩 세트 계산은 독립 완전 탐색 정답기와 무작위 50개 사례에서 비교했다.
- 새 목표 UI 검사 36개: 실제 UI Automation으로 추가·수량·순서·삭제·일시 정지·구매 비교·시세 갱신·알림 조작 및 실제 파일 저장/복원/손상 복구를 검사했다.
- 기존 장비 UI 558개, 일정 UI 614개, 성유물 UI 73개 검사를 통과했다. 전체 앱 smoke 렌더링을 완료했다.
- 다크/라이트, 1760×920(100%)와 1280×720 DIP(150%)의 실제 뷰포트에서 검수했다. 테스트용 Win32 데스크톱은 사용자 화면으로 전환하지 않았다. 실전 게임 알림 수신이나 물리 모니터 이동을 수행했다는 의미는 아니다.
- 실제 자체 포함 실행 파일에서도 목표 UI 36개와 리벤 캡처·비교 회귀 102개를 통과했다. 비교 OCR 반응 시간 개선은 [별도 측정 기록](RIVEN_PAIR_LATENCY_2026-10-26.md)을 참조한다.
- 자체 포함 실행 파일의 전체 앱 smoke 렌더링도 종료 코드 0으로 완료했다(`artifacts/farming-ready-smoke/`). 최종 Release 빌드는 경고 0개·오류 0개다. 로컬 후보는 `artifacts/farming-ready-app/WFLabs.exe`, 버전은 `0.11.0-preview.1`이며 공개 릴리즈를 발행한 것은 아니다. 기존 HEAD·Git 인덱스를 보존했다.

## 범위

목표 등록부터 추천·알림·보상 강조까지 구현했다. 실제 제작/거래/보상 선택은 게임에서 사용자가 진행한다. 새 인벤토리를 읽으면 예약과 부족 수량을 다시 계산한다. 퀘스트·클랜·평판 해금 전체 자동 판정, 공개 분대 구성 예측, 거래 상대 확보까지 포함하는 최적화는 제공하지 않는다.
