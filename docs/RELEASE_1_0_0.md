# WF Labs 1.0.0 배포 안내

2026-10-31 · Windows x64 · PC 한국어

## 설치와 업데이트

[공식 릴리즈](https://github.com/Revo-32/WF-Labs/releases/tag/v1.0.0)의 Setup으로 설치하거나 Portable을 완전히 압축 해제한 뒤 최상위 `WF Labs.exe`로 실행합니다. .NET 런타임은 포함하며 OCR용 Visual C++ x64 런타임은 설치 프로그램에서 확인합니다. 기존 설치본은 앱 상단 업데이트에서 확인·다운로드 후 적용합니다. 정식판은 공개된 안정 채널을 사용합니다.

사용자 결정에 따라 인증서는 사용하지 않습니다. 설치 파일은 미서명이며 Windows의 게시자/SmartScreen 경고가 나올 수 있습니다. `SHA256SUMS.txt`로 다운로드 무결성을 확인할 수 있습니다. 체크섬은 인증서 서명을 대신하지 않습니다.

## 포함한 기능

모딩·DPS/TTK, 리벤 수율·접합·순환, 한국어 성유물·리벤 OCR와 오버레이, 일정·알림·무기 순환, 마스터리 추천·개인 목표·재료 예약·구매 조합·필요 재료 갤러리를 포함합니다. 실제 재료 이미지의 출처·해시는 자산 고지에 유지합니다.

## 검증 범위

최종 배포 검증 결과는 소스의 Windows Actions와 릴리즈 게시 후 검증 기록을 확인하세요. 사용자 강철의 길 범람 적 레벨 9,999까지의 성유물 연속 사용 통과는 `USER_ACCEPTANCE_2026-10-30.md`에 버전·범위를 명시했습니다. 모든 환경과 모든 OCR 입력을 통과했다는 뜻은 아닙니다.

격리 데스크톱의 자동 검수는 새 Windows PC, 실제 로그인·게임 시작 자동 실행, 물리 모니터 이동·HDR·독점 전체화면 실험과 구분합니다. 해당 환경 전체를 자동 검사로 검증했다고 주장하지 않습니다.

## 지원 범위와 데이터

- 자동 게임 캡처는 FHD 이상을 기준으로 합니다. OCR은 로컬 처리하고 불확실한 결과를 임의 확정하지 않습니다.
- 시세는 저장 시각을 표시하는 참고 호가입니다. 실제 거래·품목 선택은 사용자가 결정합니다.
- 인벤토리 직접 읽기는 읽기 전용 시험 기능이며 게임 변경에 따라 실패할 수 있습니다. 공식 API·승인된 연동이라고 표시하지 않습니다.
- 근사 계산은 근사 표시·근거·영향 범위를 확인하세요. 워프레임 전체 어빌리티와 익절티드 시뮬레이션은 이번 범위에 포함하지 않습니다.
- 자체 코드는 공개 열람용이며 재사용 라이선스를 부여하지 않습니다. 위키 데이터·폰트·모델·런타임·게임 이미지는 각 제3자 고지를 유지합니다.

자세한 사용·제보는 `SUPPORT.md`, 데이터 처리는 `PRIVACY.md`, 계산 근사는 `RANGED_APPROXIMATIONS.md`를 참조하세요.
