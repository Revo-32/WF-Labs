# 실제 순환 화면의 어두운 이전 카드 누락 수정

사용자가 보낸 1966×906 실제 순환 화면을 회귀에 추가했다. 이전 카드는 작고 어둡고 새 카드는 밝고 크게 표시되어 있었다. 기존 자동 경로에서는 MR 하단의 고정 밝기 기준 때문에 이전 카드가 빠져 한 카드 결과만 남았다. 이 화면은 이전에 검사한 동일 크기의 합성 두 카드와 다른 사례다.

## 변경

- MR·인접 R·하단 구분선·어두운 배경을 함께 검사하는 기준점 탐색에 낮은 밝기 경로를 추가했다. 보통 밝기의 기준점을 우선하며 같은 카드를 중복으로 세지 않는다.
- 어두운 카드로 제한한 입력을 픽셀 밝기로 보정한다. OCR 문자열의 숫자·소수점·부호를 바꾸거나 범위에 맞춰 끼워 넣지 않는다. 잠긴 흰색 옵션도 같이 읽는다.
- 타이머의 보라색 감지 기준을 화면 전체에서 낮추는 방식은 실전 16프레임 검사에서 반복 OCR 5회를 유발해 제외했다. 낮은 기준은 MR 하단이 확인된 어두운 카드 영역에만 적용한다.
- 한 카드의 글자만 추적하던 중 다른 열에 카드가 나타나도 변경 신호에 포함한다. 추가 영역도 MR 근거를 요구하므로 배경 이펙트를 새 카드로 취급하지 않는다.
- 두 카드의 위치를 유지하며 각각 판독·수치 교차 확인한다. 실패한 쪽을 감추고 다른 카드를 첫 열로 옮기지 않는다.

저장된 원본의 자동·전체 경로 모두 두 카드와 여덟 수치가 일치했다. 최초 자동 판독은 5.88초, 같은 프로세스의 후속 전체 판독은 약 3.9초였다. 서로 다른 경로·초기화 상태의 측정이므로 일반적인 실전 응답 시간으로 확대하지 않는다. 이번 작업은 새 OCR 모델 학습이 아니라 기준점·입력 밝기·추적 범위 수정이다.

`artifacts/inventory-riven-ui-v4/checks.json`의 102개 검사에는 실제 어두운 전후 카드, 잠금·팩션 수치, 기존 한 카드 연속 화면, 목록 이탈, 좌우 비교 창과 배율을 포함한다. 원래 실전 연속 16프레임에서는 최초 판독 요청 1회, 이후 반복 요청 0회를 확인했다. 전체 정적 OCR 회귀는 45사례로 늘렸다. 640×360의 기존 압축 성유물 사례 한 칸은 미확인으로 남기는 원래 조건을 유지하며 이를 완전 일치로 표현하지 않는다.

원본과 결과는 `artifacts/riven-real-reroll-2026-10-25`, 최종 반복 회귀는 `artifacts/inventory-ocr-acceptance`에 보관한다. 실제 게임을 조작한 새 순환 종단 검사는 이번 작업에서 수행하지 않았다.
