# WF Labs 다음 기능 계획

2026-10-25 기준. 공개 버전은 `0.9.0-preview.1`이다. 성유물 보상 인식·시세 비교를 `0.10.0-preview.1` 로컬 개발본에 구현하고 계산·UI·실제 API 검사를 수행했다. [실제 한국어 화면 검수](RELIC_REAL_SCREENSHOTS_2026-10-25.md)를 추가했다. [FHD 최적화·오버레이 검수](RELIC_FHD_PERFORMANCE_2026-10-25.md)를 추가했다. FHD 합성 화면의 실제 API 시간을 측정했으며, 실제 게임 보상 선택 중 종단 검수·새 Windows 환경·API 공개 배포 조건은 별도로 남아 있다.

## 기준

2026-10-26 추가: 지역 주기·다음 S티어 중재·테넷/코다 판매 교체를 **일정** 탭에 구현했다. 현재 동작·자료 출처·검수 범위는 [일정 기록](WORLD_SCHEDULES_2026-10-26.md)을 따른다. 일정 화면을 닫으면 타이머와 정기 네트워크 갱신을 멈추며 시스템 알림·백그라운드 알림 서비스는 이번 UI에 포함하지 않는다.

모딩 → 수치 확인 → 빌드 비교의 정확도를 유지한다. 새 기능은 실제 게임 행동의 직전·직후에 연결하고, 최초 사용에 필요한 클릭과 입력을 줄인다. 확정값·시세·근사·인식 불확실성을 구분하며 상세 정보는 제거하지 않는다. 성능 최적화는 계산 동등성 검증 뒤 진행한다.

## 1. 성유물 보상 인식·시세 비교 — 로컬 개발본 구현·검수

사용 흐름: 보상 화면에서 단축키 → 최대 4개 보상 후보 자동 인식 → 플래티넘·듀캇 비교 → 보상 선택. 인식된 이름을 품목 ID에 연결하고 오인식 후보는 클릭·방향키로 수정할 수 있도록 한다. 사용자의 게임 내 보상을 자동 선택하거나 거래를 실행하지 않는다.

한국어 스크린샷·붙여넣기·게임 캡처, 보상 후보 수정, 큰 원본 영역 선택, v2 마켓 호가와 듀캇 비교, 게임 복귀 버튼을 연결했다. 품목 ID·접속 상태·플랫폼·거래 조건을 분리하고 캐시·오류·인식 취소를 처리한다. 공개된 실제 한국어 보상 장면 4개·16칸에서 15칸 자동 확정·오확정 0건을 확인했다. 실제 WPF 조작·Windows 입력·실제 마켓 응답도 검사했다. 특정 표본의 결과를 모든 실전 화면의 인식률로 확대해 표현하지 않는다.

배포 전 추가 환경 검증 기준:
- 1~4개 후보, 한글 긴 이름, 서로 다른 해상도·UI 배율·화면 비율에서 평가 데이터셋과 품목 ID 정답률을 공개한다.
- 낮은 인식 신뢰도와 미인식을 표시하고 수동 수정 이후까지 같은 흐름으로 진행한다.
- 각 후보의 가격·듀캇·조회 시각·표본/주문 수를 한 화면에서 비교하며 가격 없는 항목은 0원으로 표시하지 않는다.
- 캐시·오프라인·요청 제한·서버 오류·취소를 처리한다. 화면 인식은 사용자 요청 시점에 제한한다.
- 전역 단축키 충돌, 게임 전체화면/테두리 없는 창, 팝업 초점과 게임 복귀를 검수한다.

## 2. 인벤토리·마스터리 제작·랭작 계획 — 실제 게임 연동·획득처/추천 검수

사용 흐름: 숙련·보유 장비 표시 → 지금 제작할 수 있는 장비 보기 → 부족 재료·선행 장비 확인 → 제작/랭작 완료 처리.

인벤토리 보기, 과거 마스터리 이력과 현재 장비 랭크 분리, 제작 재료·설계도·부족 부품 구매비, 보유 성유물의 개봉/정련 계획을 연결했다. [구현·검수와 남은 범위](INVENTORY_AND_MASTERY_2026-10-25.md)를 참조한다. 로컬 게임 JSON 읽기·30초 동기화·JSON 가져오기·저장/복원 경로가 있다. 2026-10-26 실제 게임에서 동기화·검색·추천·내보내기·새 페이지 가져오기를 검수했다. 현재 기준은 [획득처·추천 기록](MASTERY_ACQUISITION_AND_RECOMMENDATIONS_2026-10-26.md)이다.

서로 다른 시점의 실제 목록에서 수량 종류 변화를 확인했고, 내보내기→새 페이지 복원도 검사했다. 읽은 시각과 서버 갱신 시각을 혼동하지 않고 오래된 JSON 사본·모듈 부품 ID·계정 변경을 검증한다. 복수 제작의 자원 배분과 중복 재료 사용 방지는 구현했다. 퀘스트·클랜 연구·평판 해금 여부 전체 연동과 거래 세트/낱개의 전역 최저가 조합은 별도 확장이다.

완료 기준:
- 보유·숙련·제작 중을 별도 상태로 관리하고 재시작 후 보존한다.
- 제작 재료로 소모되는 장비는 먼저 숙련할 수 있도록 안내한다.
- 조우·키트건·40랭크 장비 등의 마스터리 예외를 출처와 함께 검증한다.
- 추천 이유, 부족 재료, 해금 조건과 다음 행동을 같은 화면에서 확인할 수 있다.

## 3. 모딩 화면 인식·빌드 가져오기

사용 흐름: 게임의 모딩 화면 캡처 → 무기·모드·랭크·리벤 인식 후보 확인 → 사용자가 적용 → 현재 계산과 비교. OCR 결과가 기존 빌드를 즉시 덮어쓰지 않도록 미리보기와 취소를 제공한다. 성유물 OCR에서 확보한 캡처·언어 대응·신뢰도 표시를 재사용한다.

완료 기준은 무기/슬롯/랭크/극성의 항목별 정답률, 부분 인식·중복·미지원 표시, 적용 전후 비교와 되돌리기다. 게임 메모리 접근을 선행 조건으로 삼지 않는다.

## 병행 유지보수

게임 패치별 공식 자료·위키 개정 대조와 계산 회귀, 실제 사용 중 재현된 문제 수정, 근사 모델의 확정 근거 보강을 각 배포에 포함한다. 구형 리벤 파일은 원본과 당시 규칙을 보존한 이관 미리보기를 후속으로 검토한다. 변경 전 표시값을 현재 값으로 몰래 간주하지 않고, 환산 가능한 범위와 게임 수치 재확인이 필요한 항목을 구분한 뒤 사용자가 적용하게 한다. 물리적으로 서로 다른 DPI의 모니터 이동, 실제 IME 후보창, Windows 로그인/게임 실행 자동 시작 및 게임 병행 자원 사용은 자동 테스트와 구분해 검증 기록을 남긴다.

## 별도 후속 단계

익절티드·의사 익절티드와 워프레임 어빌리티 전체 시뮬레이션은 합의대로 뒤로 분리한다. 현재 로어·이클립스 같은 단순 외부 버프는 유지한다. 결과의 정확도와 세부 표현을 낮추는 최적화는 진행하지 않는다.
