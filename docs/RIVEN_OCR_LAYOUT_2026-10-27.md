# 리벤 첫 행 누락·부분 판독 수율·변경 감지 수정

대상은 로컬 검수 후보 `1.0.0-rc.4`다. 모델 가중치를 새로 학습하거나 인식 실패를 수치 범위에 맞춰 보정하지 않았다. 사용자 화면·게임 입력을 건드리지 않는 private desktop에서 저장 원본과 재구성 자료로 검사했다. 이전 RC3 및 Git 작업 상태는 보존한다.

## 반복 실패의 원인

사용자 제공 인노뎀 카드는 전기 +110.6%, 상태이상 피해 +110.1%, 강공격 효율 +76.9%, 베기 −117.5%의 3양1음이다. 첫 두 옵션이 흰색이지만 전기는 일반 잠금이고 상태이상 피해는 접합이므로, 흰색·자물쇠만으로 접합을 분류하면 안 된다.

1. 보라색 두 줄 제목의 마지막 `plagaus`와 흰색 첫 옵션의 세로 범위가 붙었다. 고정 빈 줄 기준으로 자르면 두 줄이 하나의 OCR strip에 들어갔다. 다른 경로에서는 첫 옵션의 윗부분을 잘랐다. 한 줄용 인식 모델에 잘못된 영역을 주어 첫 수치/이름이 훼손됐다.
2. 첫 옵션이 탈락했는데도 남은 2양1음을 완전한 카드로 간주해 범위를 계산했다. 3양1음의 양옵 가중치 .9375·음옵 .75가 2양1음의 1.2375·.495로 바뀌므로 제대로 읽힌 세 옵션까지 모두 범위 밖으로 보였다.
3. 이전 검수의 고정 자료만으로 새 잠금/배색/제목 조합까지 일반화됐다고 판단했다. 같은 카드의 전체 이미지·잘린 카드·자동/파일 경로·다른 배치를 모두 구분한 검수가 부족했다.

## 반영

- 첫 옵션의 실제 글자를 보존하도록 OCR 상단 여백을 글자 높이에 맞춘다. 미해결 행에서는 **원본 색상**의 중성 흰 글자를 분리하고 실제 잉크 범위로 자른다. 보라색 제목/아이콘과 흰 잠금 옵션의 간섭을 줄인다.
- 한국어 줄 모델의 판독은 기존 confidence 기준을 유지하고, Tesseract의 독립 숫자 판독과 부호·소수점·단위를 대조한다. 필요한 경우 영어 숫자 reader를 한정적으로 사용한다. 하나의 신경망 결과를 두 번 복제해 교차 확인한 것으로 세지 않으며, 최종 카드에는 별도의 전처리 판독 근거가 필요하다.
- 단위·이름 등 최초 파싱 오류가 있으면 읽힌 Options와 원문 오류는 보존하고 Values/Recipes를 비운다. 구성 확인 전에는 품질·등급·접합 예측을 계산하지 않는다. 범위만 얻으려는 구조화 입력과 실제 범위 밖 입력의 기존 계산은 유지한다.
- OCR에 제목이 함께 들어오더라도 **정확한 무기 이름 접두사**를 확인한 제목만 구분한다. 부호로 시작하는 실제 미확인 옵션을 제목으로 버리지 않는다. 긴 옵션이 줄바꿈되고 한 글자 잡음이 생긴 경우에는 기존의 유일한 긴 명칭 1-edit 정규화를 연결 단계에도 적용한다. 짧은 원소명이나 숫자는 추측하지 않는다.
- 다른 판독에 정밀한 추가 옵션이 남아 있으면, 범위가 우연히 맞는 일부 옵션만으로 카드를 확정하지 않는다.
- OCR 영역과 변경 감지 영역을 분리한다. 최종 옵션 전부와 key·숫자·부호·단위가 맞는 실제 행을 찾고, 옵션별로 가장 작은 완전한 관측 영역을 선택해 합친다. 제목·프레임까지 포함하는 여러 reader의 큰 박스를 합치지 않는다. 전체 대응이 없으면 기존 tracking 영역을 유지하며 감지 임계값은 낮추지 않는다.
- 해석되지 않는 작은 세로 카드에는 한 번의 제한된 384px locator 확대 경로를 제공한다. 보간은 잃은 문자를 복원하거나 합성하는 것이 아니며, 저해상도 게시물 전체 지원으로 표현하지 않는다.

## 공개 이미지의 무작위 검수

`E:/CODEX/Workspaces/WFLabsExternalRivenValidation-20261027`에 공개 한국어 카드 12장·독립 원본 10개·게시글 7개·옵션 44줄을 수집했다. 예시는 [버스튼 전후 카드](https://gall.dcinside.com/mgallery/board/view/?id=ordis&no=491146)다. 게시글/원본 URL·날짜·crop 좌표·SHA-256·수동 전사·원문 단위를 보존했고, 이미지는 학습·제품·공개 저장소에 넣지 않았다.

## 통합 검수 기록

첨부 원본·카드 crop·FHD/울트라와이드/4K 배치 등 현재 조합 8개를 포함한 56개 회귀 자료와, 실제 리벤 인식·오버레이 동작 검사를 추가했다. 실제 카드에서 첫 흰색 숫자/속성만 바꾸거나 두 카드의 왼쪽 첫 옵션만 바꾼 FHD 합성 장면도 검사한다. 동일 카드 애니메이션 16프레임은 최초 한 번만 읽어야 한다. 옵션 밖 변화는 추가 판독을 만들지 않아야 한다.
