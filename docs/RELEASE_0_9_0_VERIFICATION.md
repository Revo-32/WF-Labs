# WF Labs 0.9.0-preview.1 배포 검증

배포 소스: `7131a3995f847d9c6ed65516479d4e89089efe9b`. Windows x64, .NET SDK 8.0.424와 Velopack 1.2.161을 사용한다. 자체 소스는 공개 열람용이며 별도의 재사용 라이선스를 부여하지 않는다.

## 변경 범위

이전 공개 버전 0.8.0-preview.2 이후의 주무기·보조무기 계산과 특수 사건, 전체 무기군 리벤 분석, 44.1.3 리벤 배율, 저장·복원, 한국어 표시, 글꼴·카드·검색·드래그·리벤 표와 하단 상황 설정을 포함한다. [배포 노트](RELEASE_NOTES.md), [근사 모델](RANGED_APPROXIMATIONS.md), [원문 공백](RANGED_SOURCE_GAPS.md)을 함께 읽는다. 자료를 연결한 것과 모든 실전 상황이 확정된 것은 구분한다.

## 실제 설치 전이

실제 사용자 설치와 충돌하지 않는 `WFLabs.Verify` 식별자로 프로젝트 artifacts 내부에 설치했다. 같은 설치·업데이트·복구 코드로 로컬 feed에서 확인·자동 다운로드·적용·재시작·복구 후 제거를 수행했다.

1. 이전 공개 태그 `v0.8.0-preview.2` 소스의 QA 버전 `0.8.0-qa.5` → 새 소스 `0.9.0-qa.1`: 기존 근접 빌드·비교 기준·입력 중 리벤 텍스트·예산·활성 페이지 복원 성공.
2. 새 기능을 담은 `0.9.0-qa.3` → `0.9.0-qa.6`: 근접·주무기·보조무기 빌드와 비교 기준, 주무기 미채택 리벤 결과, 보조무기 입력 중 텍스트 복원 성공. 엔진 DLL이 달라진 이전 계산 결과는 현재 계산으로 표시하지 않으며 기준 빌드는 보존한다.
3. 두 경로 모두 시작 도우미 포함, 설치 전후 실제 사용자 자동 실행 항목·설정·작업 파일의 해시 보존, 검증용 설치 제거를 확인했다.

보고서: `artifacts/release-090-legacy-install/installer-verification.json`, `artifacts/release-090-upgrade-final/installer-verification.json`.

검사 개발 중 발견한 두 실패는 숨기지 않는다. 첫 시도는 유효 옵션 없이 비어 있는 리벤을 순환하는 테스트 준비 오류였으며 유효한 두 옵션을 채우도록 수정했다. 다음 시도는 엔진 변경 후에도 이전 결과 캐시를 그대로 복원해야 한다는 잘못된 검사 조건이었다. 실제 제품은 안전하게 캐시를 무효화하고 있었고, 검사를 '기준 빌드 보존 + 이전 결과 무효화'로 수정했다. 실패 기록은 `release-090-state-install`, `release-090-state-final`에 보존한다. 이 두 문제를 제품 계산 오류를 수정한 것으로 보고하지 않는다.

## CI에서 발견한 검수 환경 문제

첫 Windows CI는 1024×768 데스크톱에서 WPF 검수 창이 1044×788로 제한되어 보관함 두 줄 검사에 실패했다. 1760×920 PNG 안에 작은 창과 빈 픽셀이 들어간 이미지를 직접 확인했다. CI의 해상도 변경은 드라이버가 지원하지 않아 적용하지 않았다.

검사 전용 창의 최소 크기와 native 크기를 요청한 뷰포트에 맞추도록 수정했다. 큰 창에서 작은 창으로 바꿀 때 이전 최소 크기가 Width/Height 변경을 막고 요청값만 남기는 경우도 처리했다. 렌더링 뒤 실제 너비·높이와 요청값의 차이를 검사하고, 작은 데스크톱 제약 회귀 사례를 추가했다. 실제 사용자 창과 물리 모니터 검사는 기존 MonitorWorkArea 정책을 유지한다. UI 요소 자체의 크기를 줄이거나 보관함 두 줄 기준을 완화하지 않았다.

초기 CI: [40067353745](https://github.com/Revo-32/WF-Labs/actions/runs/40067353745). 화면 설정 대안 실패: [40068129653](https://github.com/Revo-32/WF-Labs/actions/runs/40068129653). 최종 소스 `7131a39`의 [Windows CI 40068661779](https://github.com/Revo-32/WF-Labs/actions/runs/40068661779)는 계산·WPF 화면 검증, 패키지 생성, 무결성 검사와 artifact 업로드까지 모두 성공했다. 로그는 `artifacts/release-090-final-ci.log`에 보관한다.

## 공개 배포·온라인 업데이트

2026-10-24 15:22 KST에 [v0.9.0-preview.1](https://github.com/Revo-32/WF-Labs/releases/tag/v0.9.0-preview.1)을 공개 미리보기로 게시했다. 태그는 배포 소스 `7131a3995f847d9c6ed65516479d4e89089efe9b`를 가리킨다. 배포 후 문서 기록은 별도 커밋이며 패키지의 소스 기준을 변경하지 않는다.

- 인증 토큰 없이 공개 Release를 조회했고, 설치 파일 URL의 HTTP 200과 7개 자산의 크기·SHA-256이 로컬 최종 검증본과 같은지 확인했다. 보고서: `artifacts/release-090-public-release.json`.
- 클라이언트와 같은 Velopack `GithubSource`를 사용하는 `tools/UpdateProbe`로 `0.8.0-preview.2` → `0.9.0-preview.1` 탐색과 82,628,803바이트 full.nupkg 다운로드·SHA-256 검증을 통과했다. 최신 `0.9.0-preview.1`에서는 업데이트 없음으로 판정했다. 보고서: `artifacts/release-090-online-update.json`.
- 온라인 검사의 설치 버전 정보는 `TestVelopackLocator`로 주입했다. 실제 사용자 설치를 변경하지 않았으며, 실제 설치·적용·재시작은 위의 격리 설치 QA 두 경로에서 별도로 검증했다.
- [설치 파일](https://github.com/Revo-32/WF-Labs/releases/download/v0.9.0-preview.1/WFLabs-win-Setup.exe) SHA-256: `42a159bb0509348a2526009f8df78ca70f997f232014a709b1fca512187d7802`.

## 검증 한계

- 물리적으로 서로 다른 DPI 모니터 이동, 실제 Windows IME 후보창, Windows 로그아웃/로그인과 실제 게임 실행 자동 시작, 게임 병행 성능은 이번 자동 검증에 포함하지 않는다.
- 이전 시각 검수의 검색 조합 종료/Escape 단계 단발 실패는 원인 미확정이다. 같은 빌드 후속 두 실행과 이번 배포 후보의 407개 검색 검사는 통과했다. 원인 규명 없이 해결된 것으로 표시하지 않는다.
- 44.1.3 이전 규칙의 리벤을 포함한 파일/업데이트 작업은 유효성 검사에서 거부하며 원본을 보존한다. 해당 작업의 자동 복원이 중단될 수 있고, 게임의 패치 후 수치를 다시 입력해야 한다. 위 구버전 설치 시험은 리벤 세션이 없는 빌드와 입력 중 초안의 호환 경로다. 구형 리벤의 자동 수치 변환까지 검증했다고 해석하지 않는다.
- 설치 파일에 Authenticode 서명은 없다.
- 위키의 개별 사건 시간·확률 등 원문 공백을 채운 근사와 표본 오차는 서로 다른 불확실성이다. 자세한 조건은 결과와 근사 문서에서 확인한다.
