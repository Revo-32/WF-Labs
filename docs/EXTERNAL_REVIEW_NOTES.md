# 외부 서비스 연동 확인용 자료

2026-10-27에 준비한 확인 자료이며 운영자에게 전송한 문의가 아닙니다. 기존 협의·승인 기록은 저장소에서 확인되지 않았습니다.

## 게임 연동 설명

- 이름: WF Labs. Windows x64, PC 한국어 사용자를 위한 빌드·DPS/TTK·파밍 분석 앱.
- 성유물·리벤: 화면을 로컬 OCR로 읽고 클릭 통과 창에 분석 결과를 표시합니다. 게임 선택·리벤 채택·거래·키 입력을 자동 실행하지 않습니다.
- 인벤토리: Warframe 프로세스에 Query/VM_READ 권한으로 접근해 인벤토리 JSON 사본을 찾습니다. 프로세스 쓰기·주입은 사용하지 않습니다. 이 방식이 공식적으로 승인되었다고 표시하지 않습니다.
- 게임 실행 여부와 일부 로그 신호를 관찰하며, UI가 바뀔 때 판독합니다. 사용자가 자동인식을 끌 수 있습니다.
- 확인할 사항: 현재 인벤토리 읽기 방식과 화면 오버레이를 공개 배포할 때 운영자가 요구하는 검토 절차·제약이 있는지.
- 참고: https://support.warframe.com/hc/en-us/articles/360030014351-Third-Party-Software-and-You

## warframe.market 연동 설명

- 공개 v2 품목·호가 API를 사용하며 실제 버전이 포함된 `WF-Labs/<version> (+https://github.com/Revo-32/WF-Labs)`로 식별합니다.
- 프로세스 내 공통 요청 시작 간격은 400ms이며, 응답 캐시·중복 조회 병합·제한 응답 대기를 사용합니다. 보상 선택 시에는 저장 가격을 우선 사용합니다.
- 품목 ID·플랫폼·크로스플레이·거래자 상태 조건으로 공개 가격을 조회합니다. 계정 토큰·자동 거래·주문 등록은 사용하지 않습니다.
- 재고/개인 목표의 원본 JSON, 화면 이미지, 리벤 원문은 API에 전송하지 않습니다.
- 확인할 사항: 공개 앱 사전 문의 기록·현행 약관 적용과 추가 식별/요청 정책이 필요한지.
- 참고: https://docs.warframe.market/docs/rules/overview/ 및 https://warframe.market/tos

문의를 보낼 때는 검수한 버전과 공개 소스 URL·설치 파일 해시를 함께 제공할 수 있습니다. 계정 정보나 인벤토리를 첨부할 필요는 없습니다.
