# 장비·일정 대시보드 UI 개편

2026-10-26 KST. 사용자가 요청한 70:30 장비 화면과 일정 화면의 가독성 개선을 반영했다.

## 레퍼런스와 배치

- Microsoft Fluent 2 Layout: https://fluent2.microsoft.design/layout
- IBM Carbon Dashboards: https://v10.carbondesignsystem.com/data-visualization/dashboards/

Fluent의 4단위 간격과 인접성 원칙을 참고해 8·12·16·20·24 간격을 사용한다. Carbon의 전체 현황 → 비교 → 선택 상세 순서에 맞춰 핵심 숫자를 상단에, 목록과 상세를 아래에 둔다. 웹 페이지 코드를 옮기지 않고 기존 WPF와 검정/노랑 테마로 구현했다.

## 장비

인벤토리·마스터리·성유물의 하위 탭을 제거했다. 기존 인벤토리 데이터 수집·보유 재료 계산·가져오기/내보내기는 유지한다.

- 왼쪽70%: 마스터리 완료 도넛, 전체/완료/남은 종류 수, 진행중·미시작·보유 종류,6개 분류별 완료 막대, 장비 검색·필터, 추천 목록과 선택 상세.
- 오른쪽30%: 보유 성유물 추천을 세로로 표시한다. 장비 검색/분류 필터가 성유물 목록을 비우지 않는다.
- 전체·완료·남은 지표를 누르면 해당 장비 목록으로 바뀐다. 완료 목록에는 판매한 장비의 과거 이력도 표시한다.
-40랭크 장비는40까지 완료해야 숙련 완료다. 중복 보유는 종류당1회 집계한다. 이력이 연동되지 않은 경우에는0%로 가정하지 않는다.
- 선택 장비의 ‘필요한 부품의 성유물 찾기’는 화면 이동 없이 오른쪽 추천 대상을 바꾼다.
- 보유 장비에 불필요한 비활성 버튼과 반복 안내를 줄였다. 현재 랭크·포르마·도금 상태, 부족 재료와 원문은 상세에서 확인한다.
- 동기화 정보는 하단의 접을 수 있는 영역으로 표시하여 상단 명령 버튼을 크게 늘리지 않는다.
- 동일 목록이 갱신될 때 기존 선택과 스크롤 위치를 보존한다. 데이터 갱신만으로 성유물 상세를 자동으로 펼치지 않는다.

## 성유물의 가치 확률

‘이득’을 순이익이나 수익 보장으로 정의하지 않는다. 기본값은10P 이상 보상을 받을 확률이며5/10/20/50P 기준, 플래티넘 기댓값, 두캇 기댓값으로 바꿀 수 있다. 한 명 또는 같은 성유물·정련도의2~4명 분대를 선택한다.

희귀 단일 보상10%의4인 확률은1−0.9⁴=34.39%다. 보상 수량과 등급별 개봉 확률을 반영하고, 분대 보상을 모두 더하지 않는다. 누락된 호가는0P가 아니다. 확인된 보상만으로 계산한 확률 하한은 ‘최소’로, 판단할 수 없는 경우는 ‘시세 확인 필요’로 표시한다.

기본 목록은 같은 성유물 계열의 후보를 합쳐 가장 높은 점수를 가진 정련도 하나를 보여준다. ‘모든 정련도 비교’를 켜면 기존 상세 후보가 표시된다. 추천 조건과 선택 보상 상세는 동시에 펼쳐 목록을 밀어내지 않는다. 잔영 비용·보유 수량·기댓값·조회 범위·개별 보상 확률을 보존한다.

## 일정

상단에 다음S티어 중재와 테넷/코다 교체 타이머, 다음 행에 지역5종의 주기, 하단에 중재/무기 상점 목록을 배치했다. 각 영역의 제목·보조 설명·숫자 크기를 구분한다. 필터와 상세 출처·찜하기·모딩 연결은 유지한다.

지역 주기는 현재 상태 → 큰 남은 시간 → 전환 막대 → 다음 상태/시각 순서다. 원문 기준 시각은 툴팁에, 월드 상태·공식 자료·저장 자료 예상은 작은 출처 표시로 구분한다. 상점 보너스의 긴 설명은 상세/툴팁으로 옮기되 제보 기준 표시는 남겼다. 자료 기준 영역은 높이를 제한해 스크롤하며, 해당 영역을 열 때 선택 상세와 공간이 경쟁하지 않게 한다.
