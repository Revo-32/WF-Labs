# 주무기·보조무기 모딩 → 교전 계산 → 비교 검수

## 변경한 사용 흐름

1. 무기 검색어를 입력하고 화살표·Enter로 원하는 후보를 확정한다. 입력만으로 무기나 계산 조건을 바꾸지 않는다.
2. 모드 보관함에서 장착하고 선택 슬롯의 랭크·극성을 조정한다. 치명타 확률·배수, 상태 확률, 멀티샷은 결과 상단에 유지한다.
3. 아래 상황 설정에서 대상·레벨·난이도·교전 구간을 정하고 완료로 닫는다.
4. `DPS · TTK 계산`이 끝나면 `비교 기준 지정`으로 A를 남긴다.
5. 모드나 무기를 변경하고 다시 계산해 B의 DPS·TTK·처치 비율과 비교한다. 상세 그래프에서 같은 축의 A/B 시간별 누적 평균 DPS를 확인한다.
6. `기준 빌드 복원`은 대상·모드·무기·추가 조건을 복원한다. `비교 해제`는 기준을 지운다.

비교 기준은 주무기·보조무기 페이지마다 현재 실행 중 메모리에 보존한다. 앱 재시작 뒤 비교 결과 자체를 복원하는 파일 포맷은 이번 변경에 포함하지 않았다. 기존 빌드 저장·복원 기능은 유지한다.

## 근사와 결과 상태

- 고정 결과 헤더에서 `근사 예정`, `근사 포함`, `기록된 근사 없음`, `입력·규칙 확인 필요`를 문자로 구분한다. 근사 적용 상태는 스크롤로 사라지지 않는다.
- `가정 보기`에서 적용 수치·근거·영향 범위를 펼친다. 정적 수치와 교전 결과마다 동일한 안내를 중복 표시하지 않는다.
- `기록된 근사 없음`은 기록된 근사 가정이 없다는 뜻이며, 모든 메커니즘의 실측 검증을 보증하는 표시는 아니다.
- 모드·조건 변경 시 진행 중 계산을 취소하고 이전 교전 결과를 제거한다. 이전 비동기 작업이 새 상태를 덮어쓰지 못하게 한다. 최신 결과가 없으면 비교 기준 지정은 비활성이다.
- A/B 대상·거리·입력 조건·교전 구간이 다르면 조건 불일치를 표시하고 증감률을 숨긴다. 첫 발사 피해와 지속 교전 DPS를 같은 단위로 비교하지 않는다.
- 95% 통계 오차는 표본 평균의 오차이며 근사 모델 자체의 오차가 아니다. 결과에 이 구분을 명시한다.

## 함께 바로잡은 동작

- 전역 설정의 전투 표본 수가 총기 계산에도 전달된다. 종전 총기 계산 내부의 고정 256회가 설정값을 무시하던 연결 누락을 수정했다.
- 미장착 엑실러스의 랭크, 미장착 아케인의 랭크·중첩은 비활성으로 표시한다. 빈 슬롯의 극성은 설정할 수 있다.
- 오류 안내가 비어 있을 때 해당 행을 접어 결과 상단의 불필요한 공백을 줄인다.
- 기존 글꼴과 안티앨리어싱 설정을 유지한다.

## 검수 방식과 범위

`--ranged-workflow-check`는 브래튼 프라임·라토 반달을 실제 검색 입력과 키 이벤트로 고르고, WPF UI Automation Invoke/Value/SelectionItem으로 모드 장착·적 선택·계산·기준 지정·복원·취소를 실행한다. 256표본의 실제 비동기 교전 결과와 화면의 증감 수치를 비교한다. 이 검사 전용 표본 수를 실제 앱 기본값과 혼동하지 않는다.

다크·라이트, 1760×920 및 1920×1080 논리 크기, 100/125/150% DPI를 조합한다. 긴 모드 이름은 일반 진단에서 제외되는 말줄임도 별도로 측정한다. 보관함 두 줄 확보, 끝까지 스크롤한 상태, 그래프 펼치기를 검사한다. OS 다중 모니터 사이의 실제 창 이동이나 사용자의 모니터 픽셀을 이 렌더링 검사로 대체해 검증했다고 주장하지 않는다.

`--interaction-check`는 모드·엑실러스·아케인의 랭크/극성/중첩, 하위 팝업, 카탈리스트 수용량, 정렬 아이콘과 목록의 실제 반전을 검사한다. `--approximation-ui-check`는 팬타즈마와 보조 키트건의 충전 입력·전체 공격 연결·근사 상태/상세 표시를 검사한다. `--smoke`는 기존 근접·리벤 등 전체 화면 회귀를 실행한다.

이번 추가 UI 자동화는 Windows 기본 파일 선택창의 사용자 조작이나 설치·배포를 포함하지 않는다. 계산 규칙의 추가 변경 없이 전체 엔진 회귀도 별도로 실행했다. 이전의 전체 무기 경로/원문 감사 근거는 [기존 계산 검증 보고서](RANGED_VERIFICATION_2026-10-24.md)에 보존한다.

주무기·보조무기 각각 5초 / 헤비 거너 Lv.200 / 강철의 길 / 256표본으로 실제 계산했다. 브래튼 프라임에 서레이션·스플릿 체임버를 넣은 B는 A의 87.3 DPS에서 461.7 DPS로, 라토 반달에 호넷 스트라이크·배럴 디퓨전을 넣은 B는 39.8 DPS에서 295.3 DPS로 바뀌었다. 화면의 증감 표시를 결과 객체의 실제 평균과 대조했다. 이는 해당 고정 입력과 표본의 회귀 사례이며 모든 대상에 적용되는 무기 고정 DPS가 아니다.

`longest-eight` 화면은 긴 이름을 동시에 배치하는 레이아웃 전용 스트레스 장면이다. 동시 장착 가능한 실전 빌드나 그 피해 검증 결과로 사용하지 않는다. 실제 계산 비교 장면은 `comparison` 파일이다.
