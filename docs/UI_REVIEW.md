# 2026-10-12 UI 재검수

## 수정한 문제

- 리벤 장착·불러오기 버튼이 붙던 문제를 수정했다. 작업 버튼은 8–12 DIP, 관련 작업 그룹은 16–20 DIP 간격으로 구분한다. 고정 높이 모드 슬롯과 압축 도구 모음은 기존 공간 배분을 유지한다.
- 리벤 기준/후보 결과를 중앙 열로 옮기고, 긴 출처·계산 조건은 펼쳐 보기로 분리했다. 최소 창 크기에서 두 결과가 오른쪽 작업 버튼 아래로 밀리지 않는다.
- 수용량 설정의 두 랭크 입력칸을 같은 높이로 맞췄다. 거리/관통, 리치 원소/추가 피해, 직접 피해 배율/간격의 입력칸 사이에도 간격을 넣었다.
- 자료 목록의 기본 Windows 선택 색과 컨텍스트 메뉴의 기본 배경을 테마에 맞췄다. 자료 검색창에는 검색 대상을 표시했다.
- 가로 스크롤바의 페이지 이동 명령을 좌우 방향으로 수정했다. 가로·세로 스크롤바가 만나는 기본 흰색 모서리를 제거했다.
- 긴 무기 드롭다운에 스크롤을 명시하고, 검색 가능한 ComboBox에 실제 편집 입력 부분을 연결했다. 비활성 드롭다운도 구분한다.
- 앱 실행/업데이트 창은 긴 오류 메시지를 스크롤할 수 있다. 진행 표시와 다운로드/설치 확인창도 같은 테마를 쓴다.
- 스탠스 상세의 중첩된 둥근 테두리를 구분선으로 정리하고, 하단 원문 버튼과 출처 문구 사이에 간격을 추가했다.

## 검수 범위

`--ui-audit-check <폴더>`가 다음 화면을 다크/라이트, 100/125/150% 시각 트리 DPI로 렌더링한다. 각 배율에 54개 상태를 기록하며, 긴 화면은 끝 위치도 별도 기록한다.

- 모드 탭 기본/설정 펼침/포르마, 상황 설정의 중간 스크롤 위치
- 리벤 편집/미채택 순환 결과, 옵션·무기 드롭다운
- 자료 5개 분류와 검색 결과 없음, 개발 탭
- 설정 팝업, 수용량, 조우 조립, 엑실러스/근접 아케인/조우 아케인 선택창
- 모드 우클릭 메뉴, 스탠스 상세 최소 크기
- 실행/업데이트 기본·다운로드·긴 오류, 업데이트 확인창
- 가로/세로 스크롤바 동시 표시와 페이지 이동

스크롤이 필요한 영역의 끝 도달, 스크롤바 크기/존재, 위아래 인접 버튼 간격, 방향별 페이지 이동 명령을 검사한다. 실제 리벤 버튼 흐름은 `--riven-smoke`로, 모딩 레이아웃·드래그·툴팁·차트·무기별 조건은 기존 `--smoke`로 별도 회귀 검사한다. `tools/validate.ps1`과 GitHub 검증에도 UI audit를 포함했다.

렌더링 이미지에서 버튼·입력칸 간격, 배경, 선택 표시, 내용 줄바꿈과 마지막 항목 접근을 확인한다. PNG 생성 자체를 시각적 통과로 취급하지 않는다.

## 범위의 한계

- 저장/불러오기의 Windows 공용 파일 선택창은 OS가 관리하는 UI다. 앱의 커스텀 테마 대상으로 분류하지 않았다.
- DPI 검사는 WPF 시각 트리에 배율을 적용한 렌더링이다. 서로 다른 배율의 실제 모니터 사이에서 창을 옮긴 검증과는 구분한다.
- 업데이트 다운로드/오류 화면은 UI 상태를 주입해 검사한다. 실제 설치→업데이트→재시작은 별도 로컬 QA feed 검증이며, 아직 생성하지 않은 GitHub 저장소의 온라인 업데이트가 검증됐다는 뜻은 아니다.
- 이번 재검수는 UI 변경이다. 기존 계산 범위나 미확정 원문 데이터를 새로 구현 완료했다고 주장하지 않는다.


## 2026-10-13 검색 확정 방식 · 리벤 그래프

배포·GitHub 공개·설치파일 생성은 사용자 요청으로 중지했다. 이번 변경은 앱 소스와 로컬 Release 빌드에 한정한다.

- 모딩과 리벤 무기 선택에 `WeaponSearchBox`를 공유한다. 검색어, 목록에서 강조한 후보, 확정된 무기를 분리한다.
- 한국어·영문 부분 검색, 공백/하이픈 무시, 정확히 일치/앞부분 일치 우선 정렬을 제공한다. 방향키는 후보만 이동하며 Enter 또는 클릭으로 확정한다. Esc·Tab·외부 클릭은 검색을 취소한다.
- 검색 중에는 계산 generation, 리벤 작업, 비교 기준이 유지된다. IME 조합 중 Enter는 후보를 확정하지 않는다. 조합 완료 이벤트가 처리된 경우에도 탐색을 복구한다.
- 리벤은 옵션별 최소/최대, 현재 값, 반올림 구간, 범위 내 위치를 표시한다. 음옵은 수치가 낮아지는 방향을 최소 불이익 방향으로 표시한다. 이를 획득 확률이나 종합 성능 점수로 환산하지 않는다.
- 기준과 후보를 같은 조건으로 계산해 직접·상태 피해를 누적 막대로 비교한다. 양쪽 막대는 0부터 동일한 축척이며 DPS는 실제 교전 시간을 분모로 한다. 첫 접촉은 DPS 대신 피해량으로 표시한다. 표본 수와 95% 오차폭을 유지하고 입력 변경 시 오래된 비교 그래프를 제거한다.
- 비교 그래프는 오른쪽 비교 버튼 바로 아래에 두며 세부 TTK와 계산 근거는 펼쳐 확인한다. 접합의 무작위 결과를 확정 결과로 표시하지 않는다.

검증 자료:
- `artifacts/search-riven-release-build.log`: Release 빌드, 경고 0 / 오류 0.
- `artifacts/search-riven-core.json`: 기존 계산 엔진 918개 통과.
- `artifacts/search-riven-final-check/riven-workshop-check.json`: 검색·리벤 37개 통과. 실제 WPF 입력/방향키/클릭 이벤트, 선택 횟수, 미확정 입력 중 상태 보존, IME 이벤트 순서, 음옵 반올림, DPS 분모를 검사했다.
- `artifacts/search-riven-final-audit/`: 각 배율 58개 상태, 총 174개 다크/라이트 UI 상태. 배율별 스크롤 43/42/43건, 인접 버튼 간격 각 70건 통과. 검색 목록 및 결과 없음 화면을 포함한다.
- `artifacts/search-riven-final-check/WF-Labs-riven-workshop.png`: 최소 1760×920 DIP에서 범위·DPS 그래프 배치 검토.

한계: IME는 WPF 조합 이벤트를 재현했으며 실제 사용자의 모든 Windows IME와 물리 다중 모니터 이동을 실기 검증한 것은 아니다. 실제 게임 RNG 분포가 검증되지 않아 획득 확률/백분위는 제공하지 않는다.

최종 전체 UI 회귀 검사도 완료했다. `artifacts/search-riven-final-smoke/`의 10개 검증 보고서 모두 통과, PNG 153개를 생성했다. 변경 영역의 검색 목록·빈 결과·최소 창 리벤 그래프 및 라이트 테마를 실제 이미지로 검토했다. 전체 결과는 `artifacts/search-riven-final-summary.json`에 모았다.


## 2026-10-13 모딩 → 능력치 → DPS 사용 흐름 재평가

평가 결과: 계산식이 결과의 최상단을 차지하고 치확·상확이 접힌 세부 영역에 있어, 모드를 바꾼 뒤 효과를 바로 읽기 어려웠다. 적 설정과 교전 구간 사이에 주변 적·대상 효과 설정이 끼어 있었으며, 비교 기준 버튼의 결과는 긴 결과 목록 맨 아래에 표시됐다. 기본 첫 타격 모드는 처음 실행했을 때 DPS를 보여 주지 않아 목적과도 맞지 않았다.

참고한 공식 UI 문서:
- [Microsoft Power BI 대시보드 설계](https://learn.microsoft.com/en-us/power-bi/create-reports/service-dashboards-design-tips): 핵심 지표를 먼저 배치하고 수치의 맥락·축척·시간 범위를 명확히 한다.
- [Grafana 대시보드 설계](https://grafana.com/docs/grafana/latest/visualizations/dashboards/build-dashboards/best-practices/): 요약에서 상세로 이동하는 계층과 실제 작업 흐름에 맞는 순서를 사용한다.

적용:
- 1:1:2 레이아웃, 최소 1760×920 DIP, 모드 슬롯·장비 슬롯·보관함은 유지했다.
- 오른쪽 상단에 치명타 확률·치명타 배수·상태이상 확률·공격 속도를 26px로 고정했다. 교전 시작 시점의 콤보·활성 버프를 반영한 값임을 명시한다. 시간 구간 평균이나 종료 시점 수치로 오인시키지 않는다.
- 적 선택 → 교전 구간 → 공격 동작 → 시작 콤보 → 버프·추가 조건 순서로 배치했다. 5개 교전 구간은 버튼으로 선택하며 처음 실행할 때는 5초 교전을 사용한다. 저장된 빌드는 기존 모드를 복원한다.
- 주요 결과는 교전 DPS/첫 타격 피해 → 누적 피해·상태 종류 → 정밀도 → 처치 시간·시간별 그래프 순서다. 표본 수와 오차, 원문 미기재·조건부 계산 안내는 숨기지 않는다.
- 계산식은 상단에서 펼칠 수 있으며, 펼친 상태에서 기존 모드·아케인·스탠스 호버 강조와 스크롤 고정 동작을 유지한다.
- 빈 오류 문구는 공간을 차지하지 않는다. 비교 기준 지정 결과는 결과 상단에서 확인한다.
- 교전 계산 범위에 추가 설명이 없는 경우 빈 펼침 항목도 숨겨, 처치 시간과 그래프가 바로 이어지게 했다. 미지원 결과의 계산 범위는 펼쳐 표시하고 조건부 계산 경고는 접기와 관계없이 유지한다.
