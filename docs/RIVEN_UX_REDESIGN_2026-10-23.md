# 리벤 UI 개편 — 2026-10-23

## 설계 기준과 벤치마크

공식 제품 문서와 디자인 시스템의 정보 구조를 참고했다. 아래 기관에서 WF Labs 자체를 인증하거나 사용자 테스트를 수행한 것은 아니다.

- [Nielsen Norman Group — Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/): 자주 사용하는 입력과 결과는 바로 보이고, 장착 메타데이터·계산 근거는 이름이 명확한 펼침 영역으로 분리한다. 상호 의존하는 입력과 결과를 서로 다른 단계의 마법사로 강제하지 않는다.
- [IBM Carbon — Data visualization](https://www.carbondesignsystem.com/building-blocks/data-visualization/overview): 정확한 수치·단위와 일관된 비교 표현을 우선한다. 색상만으로 상태를 전달하지 않는다.
- [Grafana — Bar gauge](https://grafana.com/docs/grafana/latest/visualizations/panels-visualizations/visualizations/bar-gauge/): 최소·최대와 현재 위치를 한 축에서 읽도록 한다. 값의 범위를 확률 분포처럼 표현하지 않는다.

## 최종 사용 흐름

왼쪽의 내 리벤 입력은 탭을 전환해도 유지한다. 오른쪽은 다음 작업별로 나눈다.

1. **수치 확인**: 현재 값, 최소·최대, 범위 내 위치, 상한/하한과의 차이(퍼센트 수치의 차이는 %p), 표시 반올림 구간을 함께 보여준다. 값이 비어 있어도 구성만 유효하면 범위가 보인다.
2. **접합**: 소비되는 두 옵션 → 계승 결과 → 무작위 대체 옵션 순서로 보여준다. 근접의 기존 접합 예시 작업은 그대로 연결하며 예시 생성 후 수치 확인으로 이동한다.
3. **옵션 도감**: 양옵 2/3개, 음옵 0/1개 구성과 일반 양옵/음옵/접합 옵션을 선택한다. 처음에는 내 리벤의 구성을 따라가고, 사용자가 도감 구성을 직접 선택한 뒤에는 그 선택을 유지한다. 현재 랭크로 전체 옵션의 최소·최대를 확인하고 한국어·영문 식별자로 검색한다. 이 탐색은 실제 리벤 입력을 변경하지 않는다. 전체 접합 조합표는 목록 위에서 펼친다.
4. **비교·순환**: 기존 근접의 기준/후보 DPS·TTK 비교, 쿠바 예산, 옵션 고정, 순환 예시, 채택/유지, 저장/복원을 보존한다. 총기 화면은 기존 지원 범위대로 수치·접합·도감을 제공한다.

최소값/최대값 입력은 사용자가 버튼을 눌렀을 때만 반영한다. 무기 검색 입력·방향키 탐색 중 실제 선택이 바뀌지 않는 기존 동작을 보존했다. 선택하지 않은 옵션의 빈 범위 설명과 경계값 버튼을 숨겨 입력 영역의 높이를 줄였다. 코스트·극성·장착 슬롯은 한 단계의 장착 설정에 모았다. 접합·순환 예시와 작업 저장에는 코스트·극성을 강요하지 않으며, 실제 장착·빌드 비교 때 요구한다. 미입력 장착 정보를 임의로 채우지 않는다.

근접·총기에서 범위 시각화, 접합 표현, 도감, 탭 컴포넌트를 공유한다. 네이비·시안 팔레트와 Wanted Sans를 유지하고 큰 패널의 반복 중첩을 피했다. 총기 모딩 화면의 리벤 팝업도 같은 구성으로 변경했다. 테마/작업 탭 전환은 비교 결과를 보존하며 실제 리벤 입력 변경 때만 기존 비교를 무효화한다.

## 계산과 표현의 경계

- Hotfix 44.1.3의 공통 1.2와 기존 범위·접합 엔진을 호출하며 게임 계산식을 새로 만들지 않았다.
- 범위 위치를 획득 확률·백분위·빌드 점수로 부르지 않는다.
- 음옵 막대는 절대 크기를 나타낸다. 줌 등 옵션별 실제 유불리를 일괄적으로 평가하지 않는다.
- 접합의 대체 옵션은 무작위이며, 표시된 계승 구간은 반올림된 입력에서 유도되는 구간이다.
- 첫 개편은 범위/조합 탐색까지였다. 이후 총기 순환·접합 작업대와 DPS 비교는 아래 후속 구현에서 추가했다.

## 후속 구현: 총기 작업대·전투 비교와 검정/노랑 UI

사용자의 후속 요청에 따라 소총·산탄총·권총 리벤에도 근접과 같은 작업 흐름을 연결했다. 기존 소스 코드와 데이터의 미커밋 변경은 유지했다.

### 기능

- 공통 1.2 배율과 무기 분류별 옵션 기준값을 사용한다. 모든 수치는 기존 범위·반올림 구간 검증을 통과해야 한다.
- 접합 계승 범위, 대체 양옵/음옵, 접합 예시 생성, 접합기 소비를 연결했다. 기존 옵션 순서를 보존한다.
- 일반 옵션 하나 고정, 접합 옵션 유지/해제, 현재 옵션 유지/새 결과 채택, 순환 횟수와 쿠바 예산을 제공한다. 고정 옵션이 있으면 구성과 고정 수치를 유지하며 쿠바 비용은 2배다. 미채택 상태에서는 재순환·편집을 막는다.
- 저장 파일은 현재 리벤·미채택 결과·비교 기준·소비 기록·고정을 포함한다. 기존 단일 총기 리벤 JSON도 읽는다. 코스트·극성 없이 분석·순환은 가능하지만 장착과 DPS 비교에는 실제 장착 정보를 요구한다.
- 업데이트 복원은 무기별 작업, 미완성 입력 문자열, 비교 기준, 선택 슬롯, 현재 페이지를 보존한다.
- DPS/TTK 비교는 현재 모딩을 복제하고 같은 슬롯에서 리벤만 교체한다. 대상·거리·모드·아케인·버프·공격 구성·탄약 설정을 유지한다. 기준과 후보에 동일한 전투 시간·표본 수·시드를 적용한다.
- 비교 전투 시간은 5/10/30/60초, 사용자용 표본 수는 256/1,024/4,096회다. 미채택 결과도 후보로 비교할 수 있다. 취소, 진행 상태, 입력 변경 시 결과 무효화를 지원한다.
- 직접+상태 DPS 막대, 누적 피해 곡선, TTK 중앙값·P10·P90·처치 비율, 95% 통계 오차폭, 치확·상확·멀티샷, 수용량 초과와 원문 기반 계산 범위를 제공한다. 전투 시간 내 미처치는 0초가 아닌 시간 상한 초과로 표시한다.

### UI와 참고 기준

- 배경 `#101112`, 본문 `#F4F4F2`, 보조 본문 `#B8BABC`, 강조 `#F2CB57`을 기본 다크 테마에 적용했다. 라이트 테마는 밝은 노랑 글자 대신 대비가 확보되는 짙은 금색 `#795900`을 사용한다.
- 피해 속성·치명타 단계·모드 등급의 의미 색은 변경하지 않았다. Vector Core 심볼은 유지하고 앱 내부 강조색을 새 테마에 연결했다.
- Wanted Sans를 유지하면서 제목과 핵심 숫자를 Semibold로 구분하고 숫자 폭을 맞췄다. 입력칸 경계, 본문 대비, 키보드 포커스를 강화했다.
- 총기 모딩은 계산 버튼을 결과 영역 상단에 고정하고 치확·치피·상확·멀티샷을 먼저 보여준다. 결과 그룹은 구분선으로 나눈다. 정보와 기존 계산 범위는 삭제하지 않았다.
- 리벤 화면은 수치 확인/접합/옵션 도감/비교·순환의 4탭으로 통일했다. 총기 옵션 입력의 중복 번호 라벨을 제거해 최소 창에서도 네 옵션과 장착 설정이 보인다. 넓은 화면은 비교와 순환을 나란히 배치하고 좁은 모달은 세로로 배치한다.
- [Microsoft Windows 타이포그래피](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography): 본문/제목 위계, 작은 크기에서의 가독성, 좌측 정렬을 참고했다. 폰트 자체는 사용자 지정 Wanted Sans를 유지한다.
- [NN/g 시스템 상태 표시](https://www.nngroup.com/articles/visibility-system-status/): 미채택 결과·계산 중·취소·입력 오류를 명확하게 드러내는 흐름을 참고했다.
