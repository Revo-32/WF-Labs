## 설치·업데이트

Windows x64용 `WFLabs-win-Setup.exe`로 설치합니다. .NET 8 런타임을 포함하며, 설치 시 OCR에 필요한 Microsoft Visual C++ x64 런타임을 확인합니다. 압축 배포본은 필요한 Visual C++ 런타임을 사용자가 설치해야 할 수 있습니다.

기존 설치본은 공개 배포 후 상단 **업데이트 → 확인/다운로드 → 설치 후 다시 시작**으로 갱신할 수 있습니다. 자동 확인·다운로드와 Windows 로그인/워프레임 시작 시 자동 실행은 설정에서 조정합니다. 적용 시점은 사용자가 선택하며 작업 중 강제 재시작하지 않습니다. GitHub의 비공개 릴리즈 초안은 기존 클라이언트에 노출되지 않습니다.

## 확인 범위와 제한

- 개발 미리보기입니다. OCR은 게임 UI 배율·글자 크기·배경·동시 표시 상태에 따라 실패하거나 지연될 수 있습니다. 실제 화면 사례와 합성 화면 검사를 구분해 기록했으며 모든 해상도·모든 테마의 인식을 보장하지 않습니다.
- 시세는 거래 체결가가 아닌 등록 호가입니다. 첫 시세 준비에는 시간이 필요하고, 네트워크 실패 시 저장 자료와 조회 시각을 유지합니다.
- 인벤토리 직접 읽기는 시험 지원입니다. 실제 계정의 연속 갱신·모든 게임 클라이언트 환경은 검증되지 않았으며 수동 입력·지원 파일 불러오기로 보완할 수 있습니다.
- 중재 등급은 커뮤니티 판단, 상점 교체와 미래 인카논은 자료 기준 예상입니다. 미래 상점의 무작위 원소·보너스를 확정하지 않습니다.
- 리벤 등급·접합 가능성·순환 예시는 조건에 따른 분석입니다. 구형 리벤 규칙의 값을 임의로 새 값으로 변환하지 않으며 원본을 보존합니다.
- 계산 근사와 원문 공백은 `docs/RANGED_APPROXIMATIONS.md`, `docs/RANGED_SOURCE_GAPS.md`에서 확인할 수 있습니다.
- UI·설치 검수는 격리된 Windows 환경에서 진행합니다. 물리적 다중 DPI 모니터 이동, 실제 로그인·로그아웃과 게임 실행 자동 시작, 게임 병행 성능은 별도 환경 검증이 필요합니다.
- 설치 파일에 Authenticode 서명은 없습니다. 자체 소스 코드는 공개 열람용이며 별도의 재사용 라이선스를 부여하지 않았습니다. 데이터·폰트·OCR 모델과 런타임은 각 원본 라이선스를 유지합니다.
