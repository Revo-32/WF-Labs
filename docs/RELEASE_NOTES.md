# WF Labs 0.9.0-preview.1

2026-10-24 · 주무기·보조무기 모딩, 전체 무기군 리벤 분석과 가독성 개선

- 주무기·보조무기의 모딩, 공격 방식, 아케인, 인카논, 키트건과 베일런스 원소·수치를 연결했습니다. 근접과 같은 흐름으로 DPS·TTK 및 같은 조건의 A/B 빌드를 비교할 수 있습니다.
- 팬타즈마 빔·충전·유도 자탄을 포함한 총기 후속 사건과 빔 데이터를 보완했습니다. 원문에 세부 수치가 없는 경로는 결과에 근사 여부·가정·영향을 표시합니다. 모든 기믹이 실측 확정되었다는 뜻은 아닙니다.
- 소총·산탄총·권총·근접 리벤의 공통 배율 1.2와 종류별 옵션 범위, 접합·순환, 쿠바 예산, DPS·TTK 비교를 제공합니다. 수치 범위 내 위치와 실제 추첨 확률을 구분합니다.
- 검정·노랑 테마를 적용하고 모딩과 결과를 5:5로 배치했습니다. 상황 설정은 하단 손잡이로 여는 패널에 모았습니다.
- 장착 모드의 이름을 크게 표시하고 효과는 호버에서 확인합니다. 주·보조·근접 카드의 코스트·극성·장식선 여백과 선택·드래그 표시를 통일했습니다.
- 더잠실체·Pretendard·Wanted Sans를 설정에서 선택할 수 있습니다. 글자 렌더링, 긴 이름, 리벤 옵션 표의 수치 정렬을 개선했습니다.
- 무기 검색은 후보를 확인하고 방향키·Enter 또는 클릭으로 확정합니다. 검색창의 안내 문구·커서·지우기 동작과 드롭다운 상태 표시를 다듬었습니다.
- 앱 종료·재실행 및 업데이트 시 근접·주무기·보조무기 빌드, 비교 기준과 리벤 초안을 보존합니다. 계산 규칙이 달라진 결과는 이전 캐시를 최신 계산으로 표시하지 않습니다.
- 상단 업데이트 버튼에서 확인·다운로드·설치 후 재시작이 가능합니다. 자동 확인과 자동 다운로드는 설정할 수 있으며 설치 시점은 사용자가 선택합니다.

## 확인 범위와 제한

- 개발 미리보기입니다. 알려진 근사와 원문 공백은 저장소의 `docs/RANGED_APPROXIMATIONS.md`, `docs/RANGED_SOURCE_GAPS.md`에 공개합니다.
- 리벤 순환 예시는 가정에 따른 시뮬레이션이며 실제 게임의 획득 확률을 보장하지 않습니다.
- 44.1.3 이전 규칙의 리벤이 포함된 파일/업데이트 작업은 자동 변환·적용하지 않습니다. 원본은 보존하며 패치 후 게임 표시 수치를 다시 입력해야 합니다. 해당 작업의 자동 복원이 중단될 수 있습니다.
- UI 검수는 100/125/150% WPF 배율과 실제 컨트롤 조작을 포함합니다. 서로 다른 실제 DPI 모니터 이동과 실제 Windows IME 후보창은 별도 환경 검증이 필요합니다.
- 이전 검색 검사의 조합 종료/Escape 단계에서 1회 실패가 있었고 같은 빌드의 후속 두 실행은 통과했습니다. 최초 실패 원인은 아직 확정하지 못했습니다.
- 설치 파일은 Authenticode 서명이 없습니다. 소스 코드는 공개 열람용이며 자체 코드의 재사용 라이선스는 부여하지 않았습니다. 타사 자료의 기존 라이선스는 유지합니다.
