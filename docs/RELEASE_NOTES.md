# WF Labs 0.8.0-preview.2

- 치확·치피·상확·공속을 상단에 고정하고, 교전 구간을 버튼으로 선택하도록 모딩 사용 흐름을 정리했습니다. 계산식·브라켓·상세 정보는 그대로 유지합니다.
- 무기 검색은 후보만 표시하며 방향키로 고른 뒤 Enter 또는 클릭으로 확정합니다.
- 상단 업데이트 버튼에서 새 버전 확인·다운로드·설치 후 재시작을 할 수 있습니다.
- 앱 시작 시 및 사용 중 4시간마다 새 버전을 자동 확인하며, 자동 확인·자동 다운로드는 설정에서 끌 수 있습니다. 설치 시점은 직접 선택합니다.
- 설정창을 닫아도 다운로드를 유지합니다. 실패·취소 시 다시 받을 수 있으며, 설치 전 모딩·리벤 작업과 비교 기준·화면 상태를 보관하고 재시작 후 복구합니다.

- 근접 리벤의 기질·랭크·옵션 구성별 수치 범위와 접합 계승 구간을 표시합니다.
- 접합·순환 작업대, 옵션 고정, 쿠바 예산, 현재 옵션 유지/새 결과 채택, 작업 파일 저장/복원을 추가했습니다.
- 같은 모딩·적·교전 조건에서 리벤 후보의 직접/상태 피해, DPS와 지원되는 시간 경로의 TTK를 비교합니다.
- Windows 설치 프로그램, 앱 내 업데이트, Windows 로그인/Warframe 실행 자동 시작 설정을 추가했습니다.
- 네이비·시안 브랜드와 인게임 피해 속성 색상을 유지합니다.
- 리벤 작업 버튼 간격과 비교 결과 배치, 자료 선택 표시, 창·팝업 스크롤 및 업데이트 확인창을 재검수했습니다. 다크/라이트와 100/125/150% 배율 검사를 배포 검증에 추가했습니다.

순환 예시는 옵션·구성·롤의 균등 추첨을 가정합니다. 실제 게임 추첨 확률이나 획득 확률 예측이 아닙니다. 접합 계승 수치는 표시값 반올림으로 인한 범위입니다.

개발 미리보기입니다. 코드 서명이 준비되지 않은 설치본은 서명되지 않습니다. GitHub에 공개된 Release와 연결된 설치본에서만 실제 업데이트를 받을 수 있습니다.
