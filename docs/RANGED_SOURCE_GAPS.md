# 총기 원문 불확실성·충돌 기록

2026-10-24 최신 사용자 지시로 [명시적 근사 계산](RANGED_APPROXIMATIONS.md)을 추가했다. 아래의 계산 거부·입력 필요 설명은 **엄격 모드 또는 아직 직접 경로 입력이 필요한 특수 배치** 기준이다. 근사 구현이 원문 공백 자체를 해소하는 것은 아니므로 원본 근거·충돌 기록은 보존한다.

이 문서는 실제로 확인한 출처의 공백/충돌만 기록한다. 아래 항목을 제외한 미연결 메커니즘은 계속 구현해야 하는 작업이며, 자료가 없다는 의미가 아니다. 2026-10-23 확인. 고정 출처의 상세 개정·해시는 `data/ranged-expansion-sources.json`과 `data/ranged-sources/manifest.json`에 보존한다.

- 몸통/지형의 즉시 61 Toxin 폭발, 약점의 1.1초 지연 953 Toxin 폭발과 최초 탄환당 포자 6개, 숙주가 먼저 죽어도 포자 생성, 20m 표적 제한을 연결했다. 포자 직격은 상확 0%이며 숙주에서 7m 초과 시 강제 Impact를 부여한다. 관통 모드는 적용하지 않는다.
- 333 Toxin 포자 폭발에서 기본 피해 모드를 제외하고 원소·팩션은 유지한다. 치피 모드 제곱과 고정 치확 이중 적용은 연결했지만, 원문에서 HTML 주석 처리된 일반 치확 모드 제곱 식을 현재 규칙으로 사용하지 않는다. 최초 탄환의 구체 버프는 포자에 자동 상속하지 않는다.
- 원문이 UpdateMe이며 ‘포자 폭발이 발생하지 않는다’는 Bugs와 본문의 333 폭발이 충돌한다. UI에서 본문/버그 시나리오를 선택한다. 굴착 지속 피해의 시간·속성·배율과 포자 속도·무작위 표적 가중치는 수치가 없어서 지정 사건 또는 제외 시나리오와 6개 포자 경로가 필요하다.
- 기절 면역에서는 포자가 발생하지 않는 것은 확정이다. 이때 953 약점 폭발의 대체 여부는 원문 미기재이므로 오버가드/데몰리셔의 약점 교전은 몸통 폭발로 조용히 대체하지 않는다. 위치별 초기 약점 폭발은 숙주에만 2배 피해·2배 치명 배율을 적용하는 선택 조건으로 분리한다.
- 고정 출처: `data/ranged-zymos.json`. 포자가 별도로 통과하는 감염 구체와 굴착 피해 사건의 시간·속성·출력 입력 UI를 연결했다.


## 애드히시브 블래스트 · 네이팜 신관과 장판

일반 4초·자르 3초·톤코어 발사 후 약 7초, 일반 펜타 무한 신관과 수동 기폭을 연결했다. 네이팜은 애드히시브 문서의 4초와 네이팜 문서의 약 5초가 충돌한다. 토리드·테넷 페록스의 장판 생성 지연은 일반 유탄 신관 설명만으로 확정할 수 없어 별도 입력한다. 출처와 개정·해시는 `data/ranged-adhesive.json`에 보존했다.

## 네이팜 그레네이즈 · 별도 100 Heat와 장판

펜타 3종의 직격·폭발 325 Heat, 최종 상확 가산, 직격 추가 Heat 100, 장판 진입 Heat 상태를 분리했다. 추가 100의 모드·치명 배율과 장판 상태 피해 수치는 원문에 없다. 장판의 직접 피해를 임의로 50/s로 만들지 않는다. 일본 위키의 약 2m 반경은 근삿값으로 명시하며 수정 가능하다. 출처와 보조 원문 해시는 `data/ranged-napalm.json`에 있다.

## 스포어레이서 · 보조 자탄 피해

주무기의 두 번 도탄과 각 충돌 폭발, 보조의 주탄 폭발·3개 자탄 생성 경로는 연결했다. 보조 자탄의 그립별 직격·폭발 피해가 모듈에 0으로 비어 있고 본문에도 없어 해당 출력은 계산하지 않는다. 자탄이 모두 적 밖에 떨어지는 배치를 선택하면 알려진 주탄 폭발은 계산한다. 깁버의 0 직격 운반체도 폭발까지 유지한다.

## 고르곤 인카논 · 충전 시간 분리

일반/레이스/프리즈마의 직격 후 폭발은 각각 1.1/0.9/0.8초로 연결했다. 모듈에 ChargeTime이 없어 FireRate의 역수를 충전 시간으로 확정하지 않는다. 모드 적용 후 충전·회복 시간을 명시한 시나리오로 전체 공격을 계산한다.

## 팍스 시커 · 챔버별 식과 유도 경로

Gaze/Rattleguts/Tombfinger/Catchmoon의 위키 식, 그립 보너스의 브라켓, 50% 베기·50% 관통, 후가산 원소, 치확·치피 모드 보너스 2배, CO 곱연산, 멀티샷 정수 확률 배수, 강제 Impact, 캐치문의 약점 배율 제외를 연결했다. 유도탄 수는 랭크 + 1이다.

Sporelacer/Vermisplicer의 피해식은 본문에 없다. 유도 속도·무작위 대상 선택 가중치와 시커 자체 처치의 재발동 규칙도 확정하지 못해 경로·재발동 조건을 지정한다. 최초 탄환에 지정한 외부 구체 경로는 유도탄에 자동 상속하지 않는다. 출처는 `data/ranged-pax-seeker.json`이다.


## 2026-10-23 후속 조사에서 분리한 실제 공백

- **Azima**: 본문은 기본 탄창의 지속을 약 10초로만 설명한다. 정확한 4방향 발사 주기·회전각속도·착지 시간·만료 폭발 반경/감쇠는 수치가 없다. 이 값은 명시한 시나리오로 계산한다. 아지마 페이지의 무한 탄약 무료 투척 설명과 피스톨리어 페이지의 탄창 소비 설명은 상충하므로 선택이 필요하다. 일반 탄약 효율 75% 상한은 44.1.3 공식 패치로 확정이다.
- **Residual 4종**: 생성 20%, 3/6/9/12초, 두 키트건 공통 최대 2개, Boils 80 Heat/10m, Malodor 40 Cold/s/9m, Shock 200 Electric/10m, Viremia 40 Toxin/s/9m를 연결했다. 정확한 발동·틱 시점, 피해 모드/치명 브라켓, 처치 귀속, Boils 접근 반경 및 ‘약 90%’ 감쇠, Viremia 원소 결합 규칙은 미기재다. 이 부분은 별도 고정 출력 시나리오를 요구한다. Viremia 상태 확률은 위키의 버그 기록(0%) 기준이다.
- **일반 Simulor**: 멀티샷의 발사 지점 합체, 4중첩 특이점, 합체 때 20초 갱신, 3특이점·4구체 한도는 연결했다. 중간 중첩별 증가량/반경, 미합체·한도 시 단축 수명, 특이점 틱 수치는 미기재여서 별도 표를 요구한다. 이동 중 틱의 정확한 위치와 여러 합체 후보가 겹칠 때의 충돌 순서는 임의로 정하지 않는다.
- **Spontaneous Singularity**: 18% 생성/5초, 생성 구체의 폭발 제외, 합체·도탄 제거, 아군 부착 후 이동을 연결했다. 피해 증가의 브라켓, 모드 특이점 피해/반경/주기, 활성 수 한도, 아군 접촉에서 생성 실패 시 폭발 여부는 미기재다. 이동 아군을 따라 계속 끌리는 적의 물리 추적 규칙도 확인되지 않아 아군 이동 시 끌어오기 제외 또는 위치 고정 조건을 요구한다.
- **Cannonade(구형)**: 30%·250 Blast·10m는 확인되나 피해 브라켓·감쇠 곡선·방사 피해 발동은 미기재다. 해당 값을 고정 시나리오로 지정하며 획득 불가/기존 보유분이라는 설명을 유지한다.
- **Nullifier**: 한 프레임의 비치명 피해 합산, 100~400 제한, 자성 3배, 현재 반경 비율 감소, Neutralizing Justice의 최대 90% 영구 생성기 파괴는 연결했다. 정확한 붕괴 경계·재생 지연/속도·폭발 중심의 막 안팎은 별도 설정이다.
- **Penta 물 표면**: 일반 펜타 본문에 ‘정지’와 ‘즉시 폭발’ 서술이 동시에 있다. 선택 시나리오로 구분한다. Tether의 물·타르 즉시 기폭은 확정이며 일반 펜타 선택값과 분리한다.
- **서로 다른 구체의 치피 버프**: 각 종류 안의 치피 +25% 1회는 확인되지만 Mutalist Quanta와 Simulor를 함께 통과할 때 같은 버프를 공유하는지는 미기재다. +25% 공유/+50% 각각 적용 시나리오를 구분한다.

## 44.1.3 공식 변경과 범위

[공식 Hotfix 44.1.3](https://www.warframe.com/en/patch-notes/pc/44-1-3)을 구형 위키 데이터보다 우선한다. 모든 리벤의 범위 계산은 공통 1.2 배율이며 과거 파일을 현재 값으로 조용히 재해석하지 않는다. 탄약 효율 75% 상한, 의도된 무한 탄약의 별도 분류, AX-52·Brain Storm·Skull Shots·Pistoleer·Bronco·Dera/Boltor 진화와 Acid Shells 10m를 반영했다.

공식 패치의 처치 폭발 재귀 제한은 **Elemental Ammo가 폭발에 만든 상태 피해의 재발동**에 관한 것이다. 기존 일반 처치 폭발 전체를 금지하는 것으로 확대하지 않는다. 워프레임 어빌리티의 Elemental Ammo 생성/전파 시스템은 합의된 이번 범위 밖이며, 현재 입력 UI에도 없다. 로어·이클립스와 외부 탄약 무한 등 단순 버프는 별개로 지원한다.

## Aksomati Prime — 가속 구간의 정량 규칙

본문은 가속 중 명중률 증가를 서술하지만 연사 가속의 시작 비율·증가 간격을 확정할 수 있는 수치가 없다. 다른 무기의 가속 계수를 복사하지 않는다. 정적 탄환 피해는 계산하되 이 가속을 포함한 발사 주기는 보류한다.
