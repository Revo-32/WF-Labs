# 극성·카드 장식·조작 상태의 시각 검수 — 2026-10-24

## 문제와 이전 검사의 공백

사용자 스크린샷의 갈바나이즈드 리플렉스에서 오른쪽 코스트·극성이 위쪽 장식선과 붙어 보였다. 카드 바깥으로 잘리지는 않아도 시각적으로 잘못된 배치였다. 기존 검사는 메타정보의 좌우 범위만 확인했으며 상단 대각선/모서리 장식과의 간격은 검사하지 않았다.

기존 위쪽 6 DIP 여백을 실제 카드에 다시 적용해 새 검사에서 실패하는지 확인하고, 수정 여백을 복원하면 통과하도록 회귀 사례를 추가했다. 동일한 카드의 전후 이미지는 `artifacts/visual-detail-verified/cards/reported-old-inset.png`, `reported-fixed-inset.png`에 있다. 원본 사용자 스크린샷을 합성한 이미지가 아니라 WPF 카드의 실제 렌더링이다.

## 변경

- 근접·주무기·보조무기·보관함·드래그가 공유하는 카드에서 위쪽 14 DIP, 아래쪽 12 DIP를 확보했다. 장착 카드 92 DIP, 보관함 카드 86 DIP로 필요한 만큼 높이를 늘렸다.
- 코스트 행은 18 DIP, 극성은 16×16 DIP의 공통 영역에 놓고 수직 중심을 맞췄다. 숫자와 극성 사이 5 DIP, 이름 행과는 별도 간격을 둔다. 모드 이름 크기 18/15 DIP는 유지했다.
- 갈바나이즈드 모서리 장식을 테두리 쪽으로 옮겼다. 등급별 게임 색과 프레임은 유지한다.
- 포르마 편집 버튼의 음수 여백을 제거했다. 편집 중에는 그 행에 필요한 높이를 확보해 이름·코스트와 겹치지 않게 했다.
- 주무기·보조무기의 선택·드래그 강조는 테두리 색만 바꾼다. 두께 변경으로 이름·극성이 1 DIP 움직이던 현상을 없앴다.
- 총기 모드를 보관함으로 끌어 해제할 때 남아 있던 고정 시안색을 현재 테마의 `AccentSurfaceBrush`로 바꿨다.
- 움브라·제누릭·유나이루·펜자가를 대시나 일반 문자 대신 위키 SVG 문양으로 표시한다. 문자열 식별자와 AP_* 식별자 모두 지원한다. SVG viewBox와 그룹 이동도 반영해 자산별 크기·위치 차이를 보존한다.
- 리벤 옵션 도감의 행별 최소·최대 위치가 달라 보이는 문제를 공통 열을 가진 하나의 표로 변경했다. 표 머리글에 최소/최대를 표시하고 숫자는 오른쪽으로 정렬한다. 모든 행의 수치 열 끝이 일치하는지 배치 검사에 추가했다.
- 실제 드롭다운의 제누릭 일반 문자 대체도 공통 문양으로 통일했다. 기존 글꼴·Ideal/ClearType 렌더링은 바꾸지 않았다.

극성 원본: [움브라](https://wiki.warframe.com/w/File:Umbra_Pol(xBlack).svg), [제누릭](https://wiki.warframe.com/w/File:Zenurik_Pol(xBlack).svg), [유나이루](https://wiki.warframe.com/w/File:Unairu_Pol(xBlack).svg), [펜자가](https://wiki.warframe.com/w/File:Penjaga_Pol(xBlack).svg). 원본 SVG와 출처/해시는 `src/TennoForge.Desktop/Assets/Polarities`에 보관했으며 고지를 갱신했다.

## 검수 방법

### 카드

실제 그려지는 장식선의 두께와 대각선을 포함한 Geometry를 계산해, 이름·코스트·극성·포르마 버튼이 장식선과 최소 2 DIP 떨어지는지 검사한다. 화면 DPI에서 발생하는 최대 1 물리 픽셀의 레이아웃 반올림은 텍스트 높이 검사에만 반영하며, 장식과의 여백 검사를 생략하지 않는다.

더잠실체·Pretendard·Wanted Sans × 다크/라이트 × 100/125/150%, 등급별 프레임·긴 이름·여러 카드 폭, 최소 1760×920/넓은 2560×1080 창을 렌더링한다. 근접 포르마 편집 전후에도 최소 두 줄의 보관함 카드가 완전히 보이는지 확인한다. SVG 원본의 실제 채움·선 영역이 viewBox 안에 들어가는지도 검사한다.

### 실제 조작과 전체 화면

UIA Invoke/ExpandCollapse/SelectionItem을 사용해 장착·랭크·극성·메뉴·엑실러스·아케인·정렬을 검사한다. 카드 선택을 바꾸고 돌아와도 이름 영역의 좌표와 크기가 유지되는지 추가했다. 드래그 중 테두리 두께와 해제 영역의 실제 테마 Brush도 확인한다.

모딩·상황 설정·리벤 입력/접합/도감/비교·자료·설정·수용량·조우·장비 팝업·업데이트 화면의 배치와 스크롤 끝, 버튼 간격을 검사한다. 카드 확대 렌더링, 주/보조 최소 창, 포르마 편집, 극성 표, 다크/라이트 장비 선택창 및 주요 페이지 이미지를 직접 확인한다. 스크롤 영역 끝의 부분 카드와 실제 텍스트/버튼 잘림은 구분한다.

배율 검사는 WPF 시각 트리 DPI를 적용한 렌더링 검사이며 서로 다른 배율의 물리 모니터 사이 이동 검사가 아니다. 전체 UI 검사 통과를 모든 가능한 입력 조합의 시각적 완전성으로 표현하지 않는다.

배율별 배치·리벤 열 정렬 검사는 `tools/validate.ps1`에도 연결했다.

## 검증 산출물

최종 소스와 빌드 해시, 각 검사 결과는 `artifacts/visual-detail-verified/verification.json`에 기록한다. 이번 작업은 UI와 표시 자산의 변경이며 계산식과 게임 데이터 수치는 변경하지 않았다. 설치 파일 생성·공개 업데이트는 수행하지 않았다.
