# WF Labs v0.5.2 UI 변경·검증 — 2026-10-11

사용자가 제공한 InsightFlow 검정·금색 대시보드 이미지의 시각 언어를 WF Labs에 적용했다. 로고나 이미지 자산을 복사하지 않고 WPF 벡터·컨트롤과 계산값으로 구현했다.

## 적용한 변화

- 왼쪽 메뉴를 제거하고 64 DIP 상단에 모드·리벤·자료·개발 탭을 배치했다. 활성 탭은 금색 밑줄로 표시한다. 테마와 경량 모드는 설정 버튼에서 연다.
- 큰 둥근 패널을 제거했다. 제목·간격·얇은 구분선으로 작업 영역을 나누며 입력·모드 카드·버튼에는 4~6 DIP 모서리와 조작 경계를 유지한다. 외곽 창은 기존 둥근 형태다.
- 기본 배경 #0D0F11, 본문 #F0F0EE, 보조 #A6AAAF, 금색 #E6BE5A. 리벤 보라색과 피해 속성·치명타 단계의 의미 색은 유지했다.
- 무기/스탠스/수용량 설정은 98 DIP. 보관함 카드 68 DIP, 장착 카드 104 DIP. 보관함 내부만 스크롤하며 슬롯은 고정한다.
- 결과 영역 폭에 따라 주요 지표 4개를 한 줄 또는 2×2로 표시한다. 아케인을 한 줄 요약/펼치기로 바꿨다.
- 방어력-DPS는 얇은 금색 선과 옅은 면, 타격별 피해는 금색 막대, 피해 구성은 얇은 도넛과 범례, 치명타 단계는 의미 색 수평 막대로 그린다. 현재 방어력은 점과 가이드로 표시한다.
- 그래프는 실제 엔진 결과를 사용한다. 타격별 피해의 가로축은 타격 순서이며 임의 시각을 만들지 않는다. TTK는 기존 콤보 시간 범위를 유지한다. 상시 렌더링 루프를 추가하지 않았다.

## 검사 결과

Release 빌드 경고 0·오류 0, 계산·저장 검사 141개 통과, 배포 EXE `--smoke` 종료 코드 0. WPF 컨트롤의 탭 이동·복귀·테마/경량 전환·모드 드래그 처리·정렬·랭크·포르마·수용량·저장 복원과 그래프 수치 일치를 확인했다.

아래 수치는 실제 렌더링 가시 영역과 카드 경계를 교차해 센 값이다. 최소 창 목록 끝은 총 122개 항목의 마지막 줄이 두 항목이므로 5개/2줄이다.

| 렌더링 조건 | 보관함 열 | 온전한 카드 | 온전한 줄 |
|---|---:|---:|---:|
| 1520×1000 | 4 | 20 | 5 |
| 1240×730 · 최소 창 | 3 | 6 | 2 |
| 1240×730 · 보관함 끝 스크롤 | 3 | 5 | 2 |
| 1366×768 | 3 | 6 | 2 |
| 1536×816 · 125% 이미지 | 4 | 12 | 3 |
| 1280×760 · 150% 이미지 | 3 | 6 | 2 |

설정·장착 슬롯·보관함이 작업 영역을 벗어나지 않는지, 무기군/무기가 한 줄인지, 스탠스가 편집 도구 옆에서 충분한 폭을 갖는지, 모드 보관함의 손잡이가 최소 28 DIP인지 검사했다. 상단 탭/작업/설정/창 버튼의 겹침과 선택 상태를 추가 검사했다.

배포 EXE의 화면 밖 실제 HWND에서도 확인했다. 전체 창/본문 1520×1000, PerMonitorV2=true, 검사 환경 96 DPI, 비레이어드 창. 창 이동 판정 2, 우측 리사이즈 11, 닫기/상단 탭/설정은 모두 클라이언트 클릭 판정 1. 기본 크기에서 실제 HWND의 보관함 20개/5줄을 확인했다.

## 시각 검토와 한계

기본·최소·전체 폭·125%·150%·목록 끝 스크롤·다크/라이트·리벤·자료·포르마·아케인 렌더링에서 카드 이름, 내용의 겹침, 구분선, 범례와 축을 검토했다. 기본 1520×1000은 주요 수치와 도넛·치명타 분포·선/막대 그래프까지 보여준다. 작은 창에서는 결과 영역을 스크롤해서 아래 그래프와 상세 조건을 본다. 장착 영역은 함께 스크롤되지 않는다.

125%/150% PNG는 배율별 이미지 렌더링 검사다. 실제 사용자 모니터에서의 폰트 품질, 여러 DPI 모니터 사이 이동, 게임 병행 CPU/GPU/FPS는 이번 검사로 확정하지 않는다. UI smoke는 실제 OS 마우스 드래그 전체 경로 대신 컨트롤 이벤트/데이터 경로와 네이티브 히트 테스트를 검증한다.

계산 지원 범위와 자료 버전은 기존 v0.5를 유지한다. 전체 자료 등록이 모든 효과의 실전 DPS 지원을 뜻하지 않으며 리벤 자동 상·하옵 판정·접합 수치 시뮬레이션도 후속 구현이다. DATA_COVERAGE.md와 IMPLEMENTATION_STATUS.md를 함께 따른다.
