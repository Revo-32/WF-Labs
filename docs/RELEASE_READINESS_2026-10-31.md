# 1.0 출시 전 남은 작업 · 2026-10-31

신규 대형 기능을 더 넣기보다 현재 변경을 하나의 최종 후보로 묶어 배포·복원·외부 환경을 확인하는 단계다. [2026-10-30 사용자 테스트](USER_ACCEPTANCE_2026-10-30.md)에서 `1.0.0-rc.6-ocr.1`의 성유물 오버레이를 강철의 길 범람 적 레벨 9,999까지 안정적으로 사용한 사실은 통과로 유지한다.

## 현재 확인과 구분

- 공개 GitHub 릴리즈를 2026-10-31 읽기 전용으로 확인: `v0.10.0-preview.1`이 최신 공개 버전이며 정식 1.0은 아직 발행되지 않았다.
- 최근 원격 Windows workflow는 2026-10-27 실행 [40484857343](https://github.com/Revo-32/WF-Labs/actions/runs/40484857343)이 성공했다. 그 후 로컬 OCR 학습·UI·재료 변경까지 포함한 성공 기록으로 확대하지 않는다.
- 후속 UI 자동 검수는 `1.0.0-rc.6-ui.1`, 이번 [재료 상세화](MASTERY_MATERIALS_2026-10-31.md)는 `1.0.0-rc.6-materials.1` 로컬 후보다. 기존 사용자 실전 승인과 구분한다.
- 이번 재료 후보는 Core 1,788개·native 인벤토리 UI 568개·강화 UX 245개 통과, 전체 WPF smoke PNG 153개·종료 0을 확인했다. 기존 OCR 모델·사용자 승인 실행본은 보존했다.
- 후속 [카테고리별 단일 재료 페이지](MASTERY_MATERIAL_GALLERY_2026-10-31.md)는 `1.0.0-rc.6-materials.2`다. 최종 native 인벤토리 UI 620개·강화 UX 251개·smoke PNG 153개·종료 0을 확인했으며, Core 1,788개와 기존 모델을 유지한다. 설치·공개 업데이트 검증과 구분한다.
- 설치·업데이트 전이는 기존 QA ID·로컬 feed에서 통과한 기록이 있다. 최신 후보와 실제 공개 feed의 검증이 남아 있다. [기존 준비 이력](RELEASE_READINESS_2026-10-27.md)을 참조한다.

## 우선순위

| 순서 | 남은 작업 | 완료 판단 |
|---|---|---|
| 1 | 최종 소스·데이터·모델을 고정하고 후보 하나로 통합 | OCR·계산·전체 UI 회귀, 변경 파일과 배포 DLL·모델 해시 일치. 기존 사용 자료·복구 이력 보존 |
| 2 | 최신 설치·압축본 및 앱 내 업데이트 재검증 | 설치/더블클릭/재시작/제거, 이전 공개 버전에서 업데이트, 빌드·비교 기준·리벤·목표·인벤토리·설정 복원, 실패 시 복구 |
| 3 | 현재 PC의 격리 검사로 대체할 수 없는 환경 확인 | 깨끗한 Windows에서 OCR native 의존성 포함 실행, 실제 로그인·게임 실행 자동 시작, 물리 다중 DPI·HDR/전체화면 등 지원 환경 확인 |
| 4 | 최종 공개 배포 마감 | 최종 소스의 GitHub Actions 성공, 릴리즈 자산·해시·안내·제3자 고지, 정식 채널 업데이트 조회·다운로드 확인 |

코드 서명은 별도 인증서가 필요하며 현재 인증서가 없어 미서명이다. 서명 여부를 출시 방침에서 명확히 결정한다. 미서명 후보를 서명 완료로 표시하지 않는다.

인벤토리 연동은 읽기 전용 프로세스 접근이라는 현재 지원 범위, 근사 계산 표시, 저장 시세 기준, OCR 불확실성 처리와 정보 수집 범위를 문서·UI에서 일치시킨다. 외부 서비스의 공식 승인·운영자 협의가 확인되지 않은 상태를 승인 완료로 표현하지 않는다.

이번 작업에서는 사용자 앱을 종료·업데이트하거나 공개 릴리즈·설치 파일을 만들지 않았다. 새 PC·물리 모니터·로그인 조작은 자동 검사 통과로 대신 기록하지 않는다.
