# 오버레이 UI 정리·강철의 길 빠른 필터·게임 얼럿

## 사용자 흐름과 배치

오버레이 설정을 `표시 / 알림 / 스타일` 세 탭으로 나눴다. 오버레이 전체 켜기와 위치·크기 조정은 공통 상단에 고정한다. 각 탭은 제목/항목 간격 8·16·24 DIP, 최소 34 DIP 컨트롤 높이, 얇은 구분선과 일관된 정렬을 사용한다. 버튼 초점은 노랑 사각 테두리 대신 하단 선으로 표시한다.

- **표시**: 성유물 표시, 경로 선택, 함께 표시할 타이머, 현재 게임 얼럿 표시, 개별 균열 고정, 위치 복원.
- **알림**: 성유물 조건 등록, 게임 얼럿 켜기/보상 이름 필터, 팝업·소리·음량, 현재 얼럿 목록.
- **스타일**: 배경 투명도·글자 그림자/진하기·글자 크기와 미리보기.

강철의 길을 선택하려고 긴 설정 목록을 스크롤할 필요가 없다. 표시 탭의 `강철의 길만`을 한 번 선택한다. 편집 중에는 오버레이 제목줄에도 같은 체크박스가 있다. 양쪽 설정은 같은 FissureView 값에 연결하며, 필터가 걸리면 구역 제목에 `강철의 길`이 나타난다. 일반/폭풍/알림 대상 선택도 유지한다.

## 성유물 행 두 줄

오버레이의 각 행을 다음 구조로 바꿨다.

1. 성유물 등급·미션 유형 / 경로 표시 / 남은 시간.
2. 행성·노드.

경로는 첫 줄의 작은 표기로 옮겼다. 강철의 길 등 특정 경로만 볼 때는 구역 제목에서 한 번 표시하고 각 행에서 반복하지 않는다. 알림 대상은 수치 색과 툴팁으로 구분한다. 타이머의 ‘예상’과 자료 기준도 두 번째 줄에 합쳐 세 번째 줄을 만들지 않는다.

기본 글자 크기에서 성유물 행 29개가 각각 55 DIP 이하인지 실제 측정한다. 긴 이름은 행을 늘리지 않고 말줄임으로 처리하되 전체 명칭·위치·경로·시간은 툴팁과 앱 목록에서 확인할 수 있다. 현재 앱 목록도 두 줄로 표시한다. 타이머가 많아도 성유물 구역이 밀려나지 않으며 양쪽 스크롤을 독립 유지한다.

보상 이름 필터는 입력 도중에 알림 조건을 임의 확정하지 않는다. `적용`, Enter, 입력 필드에서 이동할 때 확정한다. 같은 성유물 알림 조건을 다시 추가하면 중복 행을 만들지 않고 기존 조건을 켠다.

## 게임 얼럿

성유물 알림과 별도로 게임의 일반/이벤트 얼럿을 읽는다. 표시를 켜면 오버레이의 일정 영역에 미션·위치·보상·남은 시간이 나오며, 알림 탭에서 현재 얼럿을 확인할 수 있다. `새 게임 얼럿 알림`을 켜면 기존 팝업·전용 알림음 설정을 공유한다. 보상 이름을 비우면 모든 얼럿, 입력하면 해당 문자열을 포함한 보상만 알린다. 알림은 기본 꺼짐이다.

안정된 원본 ID에 `alert:` 접두어를 붙여 중복을 제거한다. 성유물 `fissure:` ID와 충돌하지 않으며 앱 재시작·연결 복구에서도 같은 얼럿을 반복하지 않는다. 만료/시작 전 얼럿과 캐시·3분 이상 지연된 자료에서는 알리지 않는다. 새 기능만으로 별도 네트워크/OCR 루프를 만들지 않고 기존 1분 월드 상태 갱신을 재사용한다. 켜 놓은 알림은 다른 앱 탭에서도 계속 확인한다.

자료 연결:

- PC API: https://api.warframestat.us/pc?language=ko — `alerts`, `mission`, `reward`, `countedItems.uniqueName`.
- 공식 원문: https://api.warframe.com/cdn/worldState.php — `Alerts`, `MissionInfo`, `missionReward`, `Activation`, `Expiry`.
- 구조 대조: https://github.com/WFCD/warframe-worldstate-parser/blob/master/lib/models/Alert.ts . 원문 구조를 확인하고 C# 파서는 자체 작성했다.
- 노드·미션은 기존 한국어 Public Export 정규화 자료, 보상은 인벤토리 카탈로그의 내부 ID로 한국어 명칭을 연결한다. 이름을 확인할 수 없는 보상을 임의 값으로 대체하지 않는다.

실제 온라인 검사에서는 공식 보완 자료의 활성 얼럿 3개와 균열 28개를 읽었다. `월육 ×50 · 17,000 크레딧`, 에리스/Xini와 미션/활성 시각 연결을 확인했다. 원본 시각·개별 자료 신선도는 검사 결과에 기록한다.

## 검수 기록

- 집중 검사: `artifacts/schedule-ux-focused.json` — 44개 통과.
- 전체 계산 회귀: `artifacts/schedule-ux-full.json` — 1,689개 통과.
- 기능/화면: `artifacts/schedule-ux-delivery-ui/checks.json` — 409개 통과. 실제 탭/경로 선택, 슬라이더·조건 등록·얼럿 필터·편집 제목줄·저장 복원, 두 줄 밀도 및 잘림 확인.
- 온라인 자료: `artifacts/schedule-ux-live/live.json` — 공개 데이터만 기록.
- 전체 UI smoke: `artifacts/schedule-ux-verified-smoke` — 재검사 통과.

각 설정 탭을 다크/라이트 × 100/125/150% × 실제 창 1100×780/960×650으로 검수한다. 오버레이는 좁은/넓은 창과 일정 9개·성유물 29개도 검사한다. 화면은 전환하지 않는 별도 Win32 데스크톱에서 BelowNormal로 검사하며 실제 게임 키·마우스와 포커스를 건드리지 않는다. 자동 검수에서는 알림음을 재생하지 않는다.

첫 smoke 실행의 수식 강조 복귀 확인이 고정 230ms 대기 후 실패했다. 검수 코드는 최대 1.8초 안에서 실제 강조 상태·글자 크기가 목표에 도달했는지 연속 확인하도록 바꿨다. 목표에 도달하지 않으면 여전히 실패하며 실제 크기·강조 상태를 기록한다. 제품의 수식 계산이나 애니메이션은 바꾸지 않았다.

실제 게임의 독점 전체화면 합성·물리적 모니터 이동, 새 얼럿이 실제 발생하는 순간의 게임 화면 실전 재생은 이번 검수에 포함하지 않았다. 공개 실데이터 파싱과 재현 데이터 기반 알림·창 조작을 구분한다.

최종 실행 경로는 `artifacts/riven-auto-side-app/WFLabs.exe`다. 이전 버전을 보존하고 513개 파일의 해시를 대조한다. 배포 기록은 `artifacts/schedule-ux-deployment.json`이며 자동 실행하거나 공개 릴리스를 발행하지 않았다. 검사와 배포의 Core SHA-256은 `11F6442AC79C85DA69E2FE3A263F30B9DBB3B479A6528C0E7A080794D867BD48`로 일치한다.
