2026-10-26 KST. 기존 작업 트리와 데이터를 보존하고 다음 사용자 요청을 함께 반영했다.

- 실제 게임 인벤토리 수집 실패 수정.
- 일정 화면을 통합 대시보드로 변경하고 중재 미션·팩션 필터 추가.
- 일정 탭을 맨 앞으로 이동.
- 설계도·부품의 구체적인 획득처와 구매 비용 보강.
- 추가 재화를 우선하고 제작시간의 비중을 낮춘 마스터리 추천.

## 데이터와 획득처

`data/inventory-acquisition.json`은 내부 ID로 연결한 2,601개 항목이며, 현재 카탈로그의 마스터리 대상 809개 모두 획득 경로가 있다. WF Wiki 고정 개정 996개, WFCD 고정 커밋, 게임 상점 등록표 및 공식 동반자 안내를 사용했다. 본체 설계도와 부품 설계도, 완성품 가격을 구분한다. 값은 미션 드롭·퀘스트·도장 연구·평판/재화 교환·상점·성유물·동반자 조립 등으로 정규화했다.

예시 검증:

- 라이노 본체 설계도: 상점 35,000크레딧. 부품: 금성 Fossa 자칼. 부품에 본체 상점 경로를 복사하지 않는다.
- 헤마: 도장 바이오 연구소. 다크 스플릿 소드: 텐노 연구소 설계도 15,000크레딧, 완성품 225P는 별도.
- Cyte-09: 본체 50,000평판/랭크4와 부품 20,000평판/랭크2를 분리.
- 단테: 본체 270 그릇 모세혈관, 부품은 해당 ID의 상점 등록표.
- 본위도우·보이드리그 설계도의 평판 비용을 크레딧으로 환산하지 않는다. 보이드리그는 데이모스의 심장 완료 보상도 표시한다.
- 바로 키 티어는 크레딧+두캇의 복합 가격과 판매 회차를 함께 표시한다.
- 뉴로드·루비도·오로킨 셀 등 기본 자원의 수집 지역, 텔루륨의 잠수정 태그, 아르곤 크리스탈의 감소 조건을 보강했다.

출처 URL·개정·원문 SHA-256은 데이터와 `data/inventory-acquisition-provenance.json`에 있다. 자동 생성에 사용한 원문·API 응답은 로컬 `artifacts/acquisition-research`에 보관한다. `tools/import_acquisition.py`는 이 원문 캐시를 정규화한다. 인물/지명은 공식 한국어 사전과 기존 카탈로그로 연결하며, 별도 펼치기에서 영어 원문도 확인할 수 있다.

공개 Export에는 일반 획득 경로가 확인되지 않는 자원 설계도 ID 5개가 남아 있다: 큐빅 다이오드, 아이소, 카바이드, 갈로스 로드, 컨트롤 모듈의 내부 제작식이다. 이를 실제 판매 설계도라고 가정하거나 구매를 권하지 않는다. 해당 자원은 직접 수집 요구로 남기고 실제 자원 획득처를 제공한다. 일반 장비·부품 설계도의 획득처 누락과 구분한다. 나머지 미해금 퀘스트·클랜 연구·평판 등급과 이벤트 운영 여부도 계정에서 확인한 것처럼 표시하지 않는다.

## 추천 방식

1. 추가 포르마 없이 현재 열린 랭크에서 점수를 얻을 수 있는 보유 장비.
2. 이미 주조소에서 제작 중인 장비.
3. 크레딧 구매 후보: 라토10,000/브래튼25,000크레딧 등 완성품 직접 구매와 설계도 구매를 구분.
4. 미션·퀘스트·평판/이벤트 교환 등 직접 획득 후보.
5. 플래티넘 구매 후보. 부족한 거래 부품의 호가가 모두 확인되면 구매 비용을 계산해 이 그룹에서 비교한다. 획득처에는 무료 경로도 보존한다.
6. 획득 MR 제한·현재 획득 제한·추가 포르마 없이는 점수가 없는 후보는 뒤로 보낸다.

동일 그룹은 제작 준비 여부, 플래티넘/마스터리1,000, 추가 획득이 필요한 항목 종류, 크레딧/마스터리1,000을 우선한다. 제작시간/점수는 마지막 보조 기준이다. 종류가 다른 재화를 임의 환율로 합산하지 않는다. 거래 부품 호가가 모두 확인되는 후보는 플래티넘 구매 그룹에서 비교한다. 보유 부품을 소모하는 기회비용은 추가 구매비와 별도로 보인다.

동시 제작 제안은 최대12개이며 앞 후보부터 가용 재료·크레딧을 예약한다. 같은 재료를 두 번 사용하는 후보는 제외하고, 아직 랭작을 마치지 않은 장비를 재료로 소모하는 후보도 자동 제안에서 제외한다. 재사용 설계도는 유지한다. 일반적인 주조소의 동일 제작 대상 순차 처리와 중간 부품 선행 관계를 반영하고, 서로 다른 제작은 병렬로 계산한다. 부분 보유 중간 부품도 실제 재고에서 예약하며, 묶음 제작에서 남는 생산품은 완료 시점을 기다린다. 별도 후보 사이의 묶음 생산 잔여물까지 재배분하는 전역 최적화는 하지 않아, 배치 제안은 보수적이다. 독립 제작시간을 전부 더하지 않는다.

이 추천은 알려진 재화와 제작식으로 실행 가능한 순서를 만드는 방식이다. 전역 조합 최적해, 미션 파밍 시간, 실제 경험치 획득 속도, 다음 마스터리 시험까지 필요한 계정 총 경험치를 확정하는 모델은 아니다. 해당 값들을 임의로 만들어 시간 점수에 넣지 않는다.

## 시세 UI

- 상점 설계도 비용, 제작 크레딧, 완성품 상점 표준가, 플레이어 판매 최저 등록 호가를 구분한다.
- 프라임뿐 아니라 프리즈마·신디케이트·일반 거래 부품을 포함한1,594개 품목을 v2 gameRef로 연결했다. 세트/묶음은 완성품 가격으로 매핑하지 않는다.
- 저장 호가는 기존12시간 공유 캐시와 조회 시각을 사용한다.
- 선택 장비의 부족한 거래 부품만 최신 조회하는 버튼과 취소를 제공한다.
- 판매자가 없거나 조회가 실패한 항목은 무료0P로 처리하지 않는다. 오류 시 기존 호가를 보존한다.
- 장비 변경 시 이전 장비의 조회 문구가 남지 않도록 표시 범위를 제한했다.
- 부품의 성유물 찾기는 해당 부족 부품이 성유물 보상에 존재할 때만 활성화한다.

## 실제 인벤토리 수집

읽기 전용 Win32 조회/메모리 읽기만 사용한다. 전체 문자열 상수 대신 실제 JSON 속성을 검사하고, 시작 헤더가 손상된 경우 필수 배열을 모두 가진 연속 JSON 꼬리만 복구한다. 서로 다른 응답 조각이나 임의 품목/수량을 합치지 않는다. 수락 전 동일 바이트를 다시 읽어 변경 중인 응답을 거부한다.

작은 할당 영역마다 반복하던 대기를 제거하고 데이터 영역을 우선 탐색한다. 응답 일부가 빠진 갱신은 마지막 정상 스냅샷을 삭제하지 않는다. 저장·내보내기에는 품목, 수량, 마스터리/장비 이력 등 허용 필드만 남는다. 계정 인증값·사용자명·메모리 원문은 저장하지 않는다.

실제 게임에서 MR26, 장비292개, 마스터리 이력400개가 읽혔다. 세 차례 시점의 품목 종류는1,984→1,985→1,990으로 변했다. 첫 성공 탐색은 약2.51초였고, UI 동기화→추천→검색→실제 내보내기→새 페이지에서 가져오기 전체 흐름은 병행 검수 중 약6.36초였다. 고정 성능 보장 수치가 아니다. 개인 스냅샷/추천 결과는 Git에서 제외된 artifacts 경로에만 둔다.

## 일정 UI

일정 → 모드 → 리벤 → 성유물 → 내 장비 → 자료 → 개발 순서다. 기존 내부 탭 ID는 유지하여 저장 작업과 업데이트 복원을 보존했다. 시작 화면 강제 변경은 하지 않았다.

통합 대시보드에서 다음S,5개 지역 주기,중재 목록,테넷/코다 상점을 동시에 본다. 중재의 미션/팩션 필터는 다음S 타이머에도 적용한다. 혼합 팩션은 각 구성 팩션 필터에 포함한다. 결과 없음과 필터 초기화 버튼을 제공한다. 커뮤니티 등급, 위키 예상 주기, 현회차 제보, 저장 자료 예상을 구분하는 기존 표시를 보존했다.
