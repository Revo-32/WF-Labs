설치 전이는 별도 `WFLabs.Verify` ID·로컬 feed·비활성 private Win32 desktop에서 실행했습니다. QA의 앱 DLL·Core DLL·학습 모델은 정식 파일과 SHA-256이 같고 설치 메타데이터만 분리합니다. 경로는 `0.10.0-qa.21 → 1.0.0`, `1.0.0-qa.2 → 1.0.0`이며 빌드·비교 기준·리벤, 후자의 개인 목표·예약 재계산·오버레이 설정을 확인했습니다. 실제 사용자 설정·작업 파일 해시와 자동 시작 설정이 보존됐습니다.

## 공개 온라인 업데이트

클라이언트와 같은 Velopack 1.2.161 `GithubSource`로 토큰 없이 `0.10.0-preview.1 → 1.0.0`을 조회하고 **131,894,547바이트** 업데이트 패키지를 실제 다운로드했습니다. SHA-256은 `ca5133595ce00f219156cf6dd9c96da2262c585761a502386aa7b966e4fa665a`이며 공개 자산·로컬 검수본과 일치합니다. 미리보기 포함 채널과 정식 채널이 모두 1.0.0을 찾고, 이미 1.0.0이면 추가 업데이트가 없음을 확인했습니다.

온라인 진단은 `TestVelopackLocator`로 설치 버전 정보만 주입했습니다. 사용자 설치본을 대신 업데이트한 시험은 아닙니다. 실제 적용·재시작·복원은 앞선 격리 설치 전이와 구분합니다.

## 환경상 제한

깨끗한 새 Windows 전체 환경, 실제 Windows 로그인·게임 실행 자동 시작, 물리 모니터 이동·서로 다른 DPI·HDR·독점 전체화면은 별도 실환경 검증 범위입니다. 격리 창·시각 트리 배율 검사를 해당 시험의 완료로 표시하지 않습니다. 인벤토리 직접 읽기는 게임 변경에 영향을 받는 시험 지원이고, 시세·일정·계산 근사는 각 표시 범위를 따릅니다. 설치 파일은 Authenticode 미서명입니다.
