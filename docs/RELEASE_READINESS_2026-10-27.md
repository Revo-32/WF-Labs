RC4의 최신 설치·업데이트·원격 CI 준비와 검수 결과는 [RC4 출시 검수 기록](RC4_RELEASE_CHECK_2026-10-27.md)을 따른다. 아래 RC1~RC3의 과거 통과를 최신 배포본의 통과로 대체하지 않는다.

현재 리벤 OCR 후속 로컬 검수본은 `1.0.0-rc.4`다. 첨부된 두 잠금 인노뎀의 네 옵션을 수정했고, 최종 native OCR 56개 계약·리벤 동작 121개·전체 계산 1,770개를 통과했다. 외부 한국어 카드 12장의 최종 원문 전사는 7장만 완전 일치하여 광범위한 OCR 지원 완료나 정식 출시 승인으로 표시하지 않는다. 실패 5장과 검사 한계는 `docs/RIVEN_OCR_LAYOUT_2026-10-27.md`, 실행본 결과는 `E:/CODEX/Workspaces/WF-Labs-Test-RC4/검수 결과.json`을 따른다.

사용자 조작 없이 가능한 코드·CI·문서·설치 전이 검수를 진행한다. 초기 전수 검수 후보는 `1.0.0-rc.1`, 후속 성유물 OCR 수정 후보는 `1.0.0-rc.2`, OCR 자원·첫 사용 흐름 개선 후보는 `1.0.0-rc.3`이며 정식 공개 발행과 구분한다. 기존 복구 저장소의 HEAD·인덱스·미커밋 변경은 보존한다.

## 준비한 변경

- 장비 탐색·획득·구매 추천, 인벤토리, 성유물 자동 감지, 리벤 캡처 검사를 공통 `tools/validate.ps1`에 편입했다.
- 정식 앱 버전은 설정 파일에 미리보기 허용이 잘못 들어가도 정식 릴리즈만 조회한다. RC/미리보기는 설정에 따라 미리보기와 정식 전환을 허용한다. 패키지와 채널 일치는 별도 검사한다.
- 앱 설정의 진단 정보 저장은 계정·인벤토리·이미지·OCR 원문·프로필 경로를 제외한 상태만 저장한다. 실제 버튼과 취소, 출력 파일을 검수한다.
- 설치·업데이트 검사에 개인 목표·예약 재계산·일정 오버레이 설정의 파일 복원을 추가했다. 실제 사용자 설정 파일의 해시 보존 범위도 넓혔다.
- 네트워크 User-Agent에 실제 빌드 버전을 표시한다. 기존 요청 간격·캐시·제한 응답 처리를 유지한다.
- 도움말·데이터 처리 문서·오류 제보 양식을 추가했다. 문서를 설치 파일에 포함하고 개인 작업·인벤토리·검수 fixture가 패키지에 들어가지 않도록 검사한다.

### 후속 실패와 RC2 수정

같은 날 다음 실전에서 `스티아낙스 프라임 섀시 설계도`가 끝까지 미확정으로 남았고, 사용자가 첨부한 오버레이에는 전체 작업 시간 6.0초가 표시됐다. 첫 성공 한 판을 모든 성유물 보상에 대한 통과로 해석하지 않는다.

확인한 원인은 축소된 한글의 획 손실, 그림과 연결된 글자 상자로 인한 두 줄 이름의 분리, 여러 패스의 조각을 합칠 때 일반 설계도 후보가 실제 부품 이름을 앞서는 문제다. RC2는 원본 이름 행 재판독, 금색 글자 분리, 단일 카드의 행 단위 읽기, 위치가 같은 독립 판독의 우선순위를 추가한다. 확정 신뢰도 기준과 시세 캐시는 유지한다.

`tests/fixtures/relic/styanax-three-rewards.png`는 원본 글자 픽셀만 보존하고 계정 이름·기존 오버레이를 제거한 위치 재구성 자료다. 원본 해시·준비 방식은 같은 이름의 JSON에 기록한다. 전체 게임 캡처 또는 새 실전의 처리 시간으로 표시하지 않는다. 원본 첨부 화면의 사본·실패 재현·개선 과정·수정 전후 측정은 로컬 `artifacts/relic-styanax-20261027`에 보존한다.

RC2 테스트 사본은 `E:\CODEX\Workspaces\WF-Labs-Test-RC2`에 별도로 준비하며 RC1과 공개 릴리즈를 덮어쓰지 않는다. 원격 발행·설치 업데이트 검수는 이번 OCR 수정 범위와 구분한다.

RC2 Release 빌드와 Core 검사 1,765개, 개발 빌드·자체 포함 native 실행 파일의 성유물 UI 검사 각각 78개가 통과했다. 같은 입력·모델·진행 콜백을 사용해 수정 전후 실행 순서를 번갈아 2회씩 측정했다. 새 실패 화면은 이름 행 위치를 재구성한 동일 입력에서 수정 전 OCR 4.23–4.69초·가운데 미확정, 수정 후 2.318–2.319초·세 보상 정확 자동 확정이었다. 기존 실전 3개 화면의 수정 후 범위는 각각 1.54–1.57초, 1.236–1.237초, 0.943–0.944초이며 잘못된 중간 품목 게시가 없었다. 이 수치는 OCR 및 이름 매칭만 포함하고 게임 캡처·시세·오버레이 전체 시간은 포함하지 않는다.
