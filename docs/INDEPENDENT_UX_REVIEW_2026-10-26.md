# 독립 UI·UX 검토와 수정 — 2026-10-26

## 검토 방식

사용자 요청에 따라 구현을 맡지 않은 별도 검토자가 처음 사용하는 사람의 관점에서 기존 화면과 소스를 읽었다. 검토자는 코드를 변경하거나 게임·사용자 화면에 접근하지 않았다. 아래는 그 검토에서 확인된 문제를 구현 담당자가 수정하고 별도의 Win32 데스크톱에서 실행 검증한 기록이다. 취향 차이를 결함으로 세지 않았고, 엔진의 계산 규칙·근거·표본 수는 변경하지 않았다.

개발 계획에 이미 구현된 마스터리 기능을 ‘다음’으로 소개하던 문구도 현재 기능으로 정정했다.

수정 후 같은 독립 검토자에게 소스와 새 화면을 다시 확인받았다. 이 과정에서 랭크 변경 시 기본 코스트가 달라지는 회귀를 추가 발견해 수정했다. 초기화·파일·draft·순환 작업 복원 중에는 자동 환산을 억제한다. 실제 UIA로 랭크 8→7→8을 선택해 표시 18→17→18 및 BaseDrain 10 보존을 확인했다.

작업표시줄 높이를 포함한 최종 화면과 소스를 다시 검토한 결과, 독립 검토자가 추가로 확정한 P1/P2는 없었다. 이는 검토한 소스·저장 화면과 실행 검사 범위의 결과이며 모든 실제 사용 환경의 무결점을 의미하지 않는다.

작은 창에서만 모드 이름을 한 줄로 표시하고 긴 이름은 말줄임·전체 이름 툴팁으로 제공한다. 큰 창에서는 기존 두 줄 이름과 카드 크기를 유지한다. 수치·효과·설정 항목을 삭제하지 않았다.

추가로 배율·줄바꿈에 따라 남은 보관함 높이가 달라지는 총기 화면은 실제 보관함 공간이 부족할 때에도 압축 배치를 선택한다. 작은 헤더의 높이에 Windows caption hit-test를 맞춰 무기 탭 위쪽이 창 이동 영역에 포함되지 않게 했다. 일정은 작은 높이에서 여백을 줄이고 중재·상점 목록 영역을 스크롤할 수 있게 해 필터 아래의 목록에 계속 접근할 수 있게 했다.

## 일정 오버레이 투명도 결함

화면에 흰 불투명 판이 나타나는 문제를 재현했다. WPF 콘텐츠의 배경 Brush만 검사하면 반투명으로 보였지만, 위치 편집을 끝낼 때 WindowChrome 해제 경로가 실제 HwndTarget의 합성 바탕을 시스템 창 색으로 되돌렸다.

- 수정 전: 최초 표시 `#00FFFFFF`, 첫 편집 완료 후 `#FFFFFFFF`.
- 수정 후: 편집·크기 변경·완료·숨김·재표시를 6회 반복해도 native 합성 바탕의 alpha는 0.
- WindowChrome을 반복 부착·해제하는 구조를 제거했다. LayeredOverlayFrame에서 Windows의 제목줄 이동·가장자리 크기 조절 hit-test만 제공한다.
- WS_EX_LAYERED를 유지하고 편집 외 상태의 클릭 통과·비활성 표시를 보존한다. 완료 버튼과 필터는 실제 컨트롤로 조작한다.
- 배경 불투명도 0 / 25 / 50 / 82 / 100%와 밝은·어두운 합성 바탕을 확인했다. 글자는 배경과 독립된 불투명도를 유지한다.

일정 메인 화면의 오버레이 체크박스와 중복 스위치는 제거했다. 표시할 항목과 세부 스타일은 오버레이 설정에서만 관리한다. 미션 유형 선택 메뉴 내부의 다중 선택 체크박스는 사용자 요청에 따른 필터 기능이므로 유지했다. 찜 필터는 체크박스 대신 선택 상태가 드러나는 칩으로 표시한다.

## 검증의 한계

사용자 게임·포커스·입력을 방해하지 않도록 전환하지 않은 전용 데스크톱에서 실행했다. 배율 검사는 WPF 시각 트리 DPI를 적용한 렌더링이며 실제 모니터 사이의 물리 이동을 재시험한 것은 아니다. 오버레이는 실제 HWND의 합성 상태와 콘텐츠 픽셀을 검사했지만, 게임 위에서 표시되는 실제 모니터 화면을 캡처하지 않았다. 사용자 게임 화면·알림 소리를 강제로 띄우거나 재생하지 않았다.

## 실행 파일

검증한 앱을 기존 실행 경로 `artifacts/riven-auto-side-app/WFLabs.exe`에 교체했다. 이전 실행 폴더는 `artifacts/riven-auto-side-before-independent-ux-20261026-081901`에 보존했고 배포 파일 513개의 SHA-256을 모두 대조했다. 실행 중인 사용자 앱을 강제 종료하거나 자동으로 전경 실행하지 않았다. 설치 파일 생성·GitHub 게시·온라인 배포는 이 변경 범위에 포함하지 않는다.

로컬 실행본은 `artifacts/ux-review-local-app`에서 준비한다. 이전 실행본과 같은 Windows x64·.NET 8.0.30 포함 방식이며 별도의 .NET 설치에 의존하는 70개 파일의 개발용 publish 결과로 대체하지 않는다. 파일 교체·백업 경로와 해시 검증 결과는 `artifacts/independent-ux-deployment.json`에 기록한다.

교체된 `WFLabs.dll`의 SHA-256은 `439E65B468BFB6D3A674A1414A76364166A45078AA843D85B6B35A53DD2C9358`이다. 이전 실행 폴더와 비교한 변경 파일은 `WFLabs.dll`과 `WFLabs.pdb`이며 런타임·OCR 모델·데이터 파일은 동일하다.
