# 실제 리벤 순환 화면의 자동 감지 실패 수정

## 재현한 원인

사용자가 띄운 전경 워프레임에서 입력·포커스 변경 없이 3440×1440 원본 1장과 가로 640px 미리보기 16프레임을 확보했다. 기존 자동 인식 설정은 켜져 있었고 실행 파일도 이전 제출본과 일치했다.

보라색 배경 애니메이션이 후보 영역과 비교용 픽셀에 포함되면서 인접 프레임의 차이가 약 0.3~0.7로 측정됐다. 기존 안정화 조건 0.12를 계속 초과하여 16프레임 모두 OCR 시작 요청이 발생하지 않았다. 정지 이미지 반복 검사로는 발견할 수 없었던 실패다.

## 수정

- 서로 다른 크기의 글자 후보 영역을 탐색하고 어두운 배경 비율을 강화했다. 작은 카드가 보이는 울트라와이드 화면에서도 옵션 영역을 포함한다.
- 첫 진입은 연속 두 번의 시각 후보 감지로 한 번 판독할 수 있게 했다. 배경 전체가 정지할 때까지 기다리지 않는다.
- 첫 판독 후에는 OCR이 확인한 옵션 사각형만 비교한다. 기존의 비율 단위 여백으로 카드 테두리 애니메이션이 다시 포함되던 문제도 제거했다.
- 판독 전후 결과 유효성 검사도 옵션 사각형으로 한정한다. 옵션이 실제로 바뀌면 오래된 결과를 버리고 새로 읽는다.
- 숫자처럼 보이는 배경 장식이나 카드 코스트가 OCR 영역을 넓히지 않도록 옵션 이름과 숫자의 인접 관계를 검사한다. 숫자와 설명이 나뉜 행, 소수점 뒤 공백도 위치 탐색에서 처리한다. 수치와 부호를 임의로 채우지 않는다.
- 자동 감지 상태를 앱에 표시하고 `%LOCALAPPDATA%/WF Labs/riven-capture-status.json`에 마지막 상태를 덮어써 기록한다. 일반 실행에서 화면 이미지를 저장하지 않는다.
- 좌우 오버레이·하단 쿠바 영역 비움·클릭 통과·게임 비활성화 시 닫힘을 유지한다.

## 검수

- 실제 16프레임 순서를 재생하고, 실전과 동일하게 두 번째 네이티브 미리보기에서 얻은 영역으로 원본을 잘라 OCR했다.
- 네 옵션 `+118.8% / +108.1% / +106.4% / -100%`의 이름·값·부호와 두 전처리 결과가 일치했다. 해당 최종 단독 실행 OCR 시간은 3.34초이며 감지 대기와 화면 캡처 비용은 제외한다.
- 첫 OCR 요청 1회, 같은 옵션이 유지되는 나머지 프레임에서 추가 요청 0회. 실제 값 변경·이탈·재진입은 Core 상태 전이 검사로 별도 확인했다.
- 전체 Core 회귀 1,575개 통과, 0개 실패.
- 리벤 UI 검사에 실제 애니메이션 프레임 회귀를 추가했다. 최종 publish 파일에서 44개 항목 통과. 결과는 `artifacts/riven-auto-fix-2026-10-25/verified/checks.json`에 기록했다.
- 기존 첨부 화면, 여러 크기의 시험 캔버스, 두 장의 한국어 시험 카드, 교정·가져오기 버튼 및 좌우 배치 회귀를 유지한다.
- 전체 WPF smoke 통과(종료 코드 0). 기록: `artifacts/riven-auto-fix-2026-10-25/smoke/`.

## 확인 범위와 사용

실제 게임에서 실패 원인을 캡처해 재현하고 그 연속 프레임으로 수정 경로를 검증했다. 수정 후 실시간 오버레이 검사 시에는 게임이 전경이 아니어서 해당 검사가 대기 상태로 끝났다. 수정본의 실제 연속 순환·옵션 채택까지 확인했다고 표현하지 않는다.

실행 중인 기존 WF Labs와 게임은 종료하지 않았다. 수정본을 사용하려면 기존 WF Labs를 종료하고 아래 실행 파일을 연다. 기존 자동 인식 설정은 그대로 읽는다.

- 실행 파일: `artifacts/riven-animated-verified-app/WFLabs.exe`
- WFLabs.dll SHA-256: `56C0A1C28B9C00CD46EE6F367DB10F9AE2CE10FB3AFCF414E496EB076BF8867D`
- 실제 실패 프레임: `artifacts/riven-auto-fix-2026-10-25/live-ready/`
- 네이티브 프리뷰 기준 재생 검수: `artifacts/riven-auto-fix-2026-10-25/native-final/`

진단 실행은 명시적인 `--riven-probe-live-check`, `--riven-auto-live-check`일 때만 전경 게임을 읽고, 제한된 횟수 이후 종료한다. 창 활성화·키 입력·네트워크 업로드는 없다. 실제 캡처 자료는 로컬 artifacts에만 보관한다.
