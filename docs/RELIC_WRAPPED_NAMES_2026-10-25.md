# 첫 보상 줄바꿈 누락 수정

사용자 화면의 첫 보상은 오르도스 프라임 블레이드다. 품목 목록에는 존재하며, 첨부 화면의 오버레이에서는 첫 카드만 확인 필요로 남았다. 첨부 원본은 1991×1258의 부분 화면이므로 실제 자동 캡처 당시의 전체 프레임과 구분한다.

기존 빠른 인식은 고정된 상단 영역을 검사하고, 미확정 항목은 이미 발견한 글자 경계만 잘라 재검사했다. 첫 줄이 영역 밖에 있거나 잘렸을 때 아래 부품 이름만 반복해서 읽는 문제가 있었다. 부분 화면은 보상 줄의 상대 위치도 달라 기존 고정 영역에서 찾지 못했다.

## 수정 내용

- 보상 줄을 찾지 못하면 위쪽 후보 영역을 제한적으로 탐색한다.
- 주변 보상의 아래 기준선과 글자 높이로 두 줄을 포함하는 영역을 구한다. 최초 탐색 또는 카드별 탐색에서 줄을 찾은 시점에 적용한다.
- 이미 네 보상의 위치를 찾았다면 넓은 영역의 중복 탐색을 건너뛴다. 미확정 이름만 추가 전처리로 확인한다.
- 한 줄짜리 이름은 단일 행 인식도 사용한다. 듀얼의 글자를 여러 문단으로 나누던 경우를 검수에서 발견해 보강했다.
- 서로 다른 전처리 결과의 일치 조건, 시세 스냅샷 사용, 실시간 OCR 읽기 예산은 유지한다. 특정 보상 이름을 강제로 확정하는 예외는 추가하지 않았다.
