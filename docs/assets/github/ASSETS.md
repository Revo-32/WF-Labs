# GitHub 메인 페이지 자산

2026-10-26. 기존 WF Labs Vector Core 로고를 유지한 README용 자산이다.

- `hero-dark.svg`, `hero-light.svg`: `src/TennoForge.Desktop/Assets/Brand/wf-labs-horizontal.svg`의 자체 제작 로고 경로를 재사용했다. README에 한해 현재 앱의 검정·노랑 테마에 맞춰 강조색을 바꿨다. 앱 아이콘과 원본 SVG는 수정하지 않았다.

- `modding-preview.png`, `riven-preview.png`, `rotations-preview.png`: 0.10.0-preview.1 개발본의 실제 WPF 렌더링이다. 예시 빌드·리벤 입력과 고정 시각의 일정 검수 데이터를 사용했다. 실제 계정 정보·인벤토리·게임 캡처는 포함하지 않는다.
